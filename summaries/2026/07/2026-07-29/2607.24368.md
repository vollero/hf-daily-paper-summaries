# Keep It InMind: Benchmarking the Implicit-Association Blind Spot in Agent Memory

> [← Daily summary](../2026-07-29.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2607.24368) · [arXiv](https://arxiv.org/abs/2607.24368)


## One-sentence takeaway

InMind shows that long-term-memory agents can recall stored facts directly yet rarely apply them when relevance depends on unstated world knowledge, whereas keeping the facts visible before the query recovers much of the lost performance.

## Problem and motivation

Retrieval-based agent memory assumes that a needed memory resembles the query sufficiently to be retrieved. The authors identify an “implicit-association blind spot”: a personal fact may matter only through external world knowledge—such as an allergy becoming relevant to an ingredient—while sharing no lexical, topical, or embedding cue with the query (Sections 1 and 2.1–2.3).

This matters because direct-recall tests can create false confidence: an agent may accurately state what it remembers but fail to use that information in a later safety- or decision-relevant response. Existing evaluations also conflate storage failure, missing bridging knowledge, and failure to surface a stored fact (Section 1).

## Approach and contributions

- **Failure-mode formulation:** The paper defines implicit associations through necessity, semantic distance, and an external knowledge bridge, and formalizes the hidden “retrieval hypothesis” behind query-conditioned memory (Sections 2.1–2.2).

- **Diagnostic benchmark:** InMind contains 125 expert-verified tasks across ten life domains. Of these, 113 have bridges grounded in public sources and 12 are expert-authored (Sections 3.1–3.3).

- **Paired evaluation:** Each task includes a stored personal fact, a direct naive query, and an indirect query. Direct recall tests storage, an in-context control tests the answer model’s bridging ability, and answer-blind target recall tests whether the memory reached its context (Sections 3.2 and 3.4).

- **Cross-architecture study:** Six vector-, graph-, and agentic-memory systems are evaluated with two embedding configurations after the fact undergoes 38 subsequent sessions of interference (Sections 3.4 and 4.1).

- **Routing diagnosis:** A minimal always-in-state profile probe substantially improves indirect application, motivating routing—which facts remain visible—as the central open problem rather than proposing the probe as a deployable architecture (Sections 5.2–5.3).

## Evidence and main results

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| The answer model can usually apply the bridge when the fact is visible. | GPT-5-mini scored **84.0% (105/125)** with the target memory directly in context; 95% Wilson interval **[76.6, 89.4]**. | Section 4.3; Table 1 |
| Query-time memory configurations perform poorly on indirect application. | Across the same 125 tasks, all retrieval configurations scored **3.2%–16.0%**; the six memory systems reached at most **14.4%**, while Naive RAG reached **16.0%**. | Section 4.2; Table 1 |
| Poor application is not explained simply by failure to store the fact. | Direct naive recall reached as high as **100.0%** after 38 intervening sessions; A-Mem attained that maximum. | Sections 3.4 and 4.4; Table 1 |
| The decisive fact rarely reaches the answer context for an indirect query. | Target recall was **0.8%–5.6%** with MiniLM and **2.4%–12.0%** with text-embedding-3-large. | Section 4.4; Table 1 |
| A larger embedding improves retrieval but does not close the gap. | Moving from 384 to 3,072 dimensions raised target recall for every system—for example, A-Mem **2.4%→12.0%** and A-RAG **5.6%→11.2%**—but application remained low; HippoRAG 2 declined **8.8%→5.6%**. | Section 4.5 |
| Persistent visibility recovers much of the deficit. | The 200-line always-in-state diagnostic achieved **68.8%** indirect application and **98.4%** direct recall on the same 125 tasks, versus at most **16.0%** application for query-time configurations. | Section 5.2; Table 2; Appendix 17 |
| Automatic application scores have meaningful label error. | In a 100-record expert audit, target-recall judgment accuracy was **97.0%** and context-aware application accuracy **85.0%**; all 15 application errors were false positives. Answer-only accuracy was **91.0%**. | Appendix 14.2; Table 5 |

The results strongly support the authors’ claim that the dominant failure occurs before answer generation: stored facts are often directly retrievable and useful once visible, but seldom surfaced by indirect queries. They do not establish that every possible query-conditioned retrieval design must fail, that always-visible profiles are deployment-ready, or that the full measured application gap is exact; the application judge’s false positives may inflate some absolute scores.

## Limitations and validity risks

- **Author-stated:** The 125 tasks lean toward health, wellness, and safety, leaving areas such as humor, etiquette, long-term goals, and institutional policy uncovered (Section 7).

- **Author-stated:** At this sample size, differences of a few percentage points may be sampling noise; the conclusions instead rely on effects of roughly 60–70 points (Section 7).

- **Author-stated:** GPT-5-mini acts as both answerer and judge, creating self-preference risk. The expert audit finds only 85% accuracy for the context-aware application judge, with exclusively false-positive errors (Section 7; Appendix 14.2).

- **Author-stated:** Tasks assume factual, uncontested bridges, whereas real relevance can be probabilistic, disputed, or jurisdiction-dependent. The rubric also lacks negative controls penalizing unnecessary warnings (Section 7).

- **Author-stated:** The always-in-state probe is not a controlled ablation: it changes both state format and updater. Its 200-line state requires continual rewriting, cannot scale indefinitely, and may increase privacy exposure (Section 5.2; Ethics Statement).

- **Analyst inference:** Results use one answer backbone and one fixed conversation trace, so robustness across answer models, user histories, languages, and interaction distributions remains untested in the supplied text.

- **Analyst inference:** Although two embedding sizes are compared, the A-RAG indices were built separately; its result cannot be interpreted as a strict embedding-only ablation (Section 4.5; Appendix 15.4).

- **Analyst inference:** Public release is promised rather than demonstrated in the supplied text, so current artifact availability and independent reproducibility are not established (Reproducibility Statement).

## Open research questions

1. **Can routing retain decision-critical facts without keeping an entire profile visible?**  
   The probe shows sufficiency but not a scalable selection rule. A next experiment could compare learned write-time routing, recency/frequency policies, and oracle routing under equal context and privacy budgets.

2. **Can knowledge-aware retrieval bridge distant associations efficiently?**  
   Larger embeddings improve target recall only modestly, while exhaustive model scoring would undermine retrieval’s cost advantage. A next experiment could test bridge-hypothesis generation followed by targeted retrieval, measuring recall, latency, and token cost.

3. **How can evaluation distinguish personalized memory use from generic caution?**  
   The application judge sometimes credits warnings generated without retrieving the personal fact. Paired positive and negative user profiles, judged by independent models and humans, could measure both appropriate application and over-warning.

4. **Does the blind spot generalize beyond the benchmark’s safety-heavy English setting?**  
   Coverage outside the listed life domains and fixed LME-s history is not established. A next experiment could construct multilingual, non-safety, and naturally collected longitudinal tasks using the same paired-control design.
