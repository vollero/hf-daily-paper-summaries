# Agent Memory Distillation: Empowering Small LLM Agents with Hierarchical Teacher Memory

> [← Daily summary](../2026-08-11.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2608.07169) · [arXiv](https://arxiv.org/abs/2608.07169)


## One-sentence takeaway

Agent Memory Distillation improves small tool-using LLM agents without parameter updates by converting successful teacher trajectories into complementary task-, subtask-, and function-level memories.

## Problem and motivation

Small LLM agents often fail too frequently to build useful memories from their own trajectories. Transferring a stronger teacher’s memories directly is also insufficient: high-level guidance may omit procedural knowledge that a small student cannot reconstruct, while limited instruction-following and in-context learning can make rich memories difficult to apply.

The authors identify a gap between prior agent-memory work, which mainly evaluates large models or same-model self-improvement, and knowledge-distillation methods, which generally require parameter updates rather than direct memory transfer (Sections 1 and 2).

## Approach and contributions

- **Hierarchical memory distillation:** AMD derives three banks from successful teacher trajectories: Workflow memory for task-level plans, Subtask memory for concrete intermediate execution examples, and Function memory for individual tool conventions and corrections (Section 3.2).
- **Granularity-specific delivery:** Workflow and retrieved Subtask memories are placed in the initial prompt; Function memory is retrieved only after a tool error, using the failed function’s name (Section 3.3; Figure 2).
- **Training-free transfer:** The student’s parameters remain unchanged; knowledge is transferred through retrieval and contextual injection (Sections 1 and 3).
- **Empirical analysis:** The paper evaluates four 4B–8B students on three tool-use benchmarks and studies memory components, teacher choice, student scale, retrieval count, representation format, disjoint evaluation, and repeated-run stability (Sections 4–5; Appendix B).

The results support the authors’ claim that AMD improves the tested small agents and that memory granularity, representation, retrieval count, and teacher compatibility matter. They do not establish generalization beyond text-based structured tool environments, online adaptation, or universally superior performance for hierarchical memory. Student–teacher comparisons also do not prove that students acquire capabilities beyond the teacher: students receive memories aggregated from successful teacher trajectories, and the supplied text does not give uncertainty estimates for those specific comparisons.

## Limitations and validity risks

The authors state that evaluation is confined to text-based Python/API and structured function-call environments; multimodal agents and open-ended coding remain untested. Memory is created offline and frozen, so AMD cannot learn from student outcomes at test time or respond to distribution shift. Its value also depends on teacher trajectory quality and compatibility, with stronger teachers not always transferring better.

Additional analyst inferences:

- The main experiments build and apply memory within each benchmark. Disjoint protocols reduce the risk of same-task reuse, but their exact results are missing from the retrieved text, limiting quantitative assessment (Appendix B.3).
- Main results average only two runs. Five-run evidence exists for Qwen3-4B, but the numerical table contents are unavailable and robustness for the other students is not established (Section 4.1; Appendix B.4).
- GPT-5-mini serves both as teacher and as ToolSandbox’s simulated user, creating a possible model-family interaction; the paper does not report an alternative user simulator (Section 4.1).
- Function documentation differs by benchmark—rich schemas on AppWorld, concrete examples only on BFCL V3 and ToolSandbox—so cross-benchmark performance differences cannot be attributed solely to task difficulty (Appendix C).
- The supplied text does not report statistical significance, memory-generation cost, prompt/context token overhead, similarity threshold values, or memory-bank sizes.
- Component ablations are incremental rather than a complete factorial analysis in the supplied narrative, although some extra combinations are mentioned in Appendix B.1.

## Open research questions

1. **Can AMD adapt online without accumulating unreliable student memories?** Frozen memory is an explicit limitation. A next experiment could compare static AMD with confidence-filtered updates from student successes and corrected failures under distribution shift.

2. **How should teachers be selected for each student or task?** Table 3 shows that teacher accuracy and transfer quality can disagree. A next experiment could predict transfer utility from teacher–student trajectory similarity, then compare adaptive selection with always choosing the most accurate teacher.

3. **Does hierarchical memory transfer beyond structured text tools?** Multimodal environments and open-ended coding are untested. A next experiment could adapt the hierarchy to visual observations or unrestricted code generation and compare it against flat teacher memory under matched context budgets.

4. **Can retrieval remain effective with larger memory stores?** Increasing \(k\) harms Qwen3-4B, but scaling in the number and diversity of stored trajectories is not reported. A next experiment could vary bank size and retrieval precision while measuring accuracy, latency, and context usage.

## Confidence and missing information

**Confidence: medium.** The retrieved text includes the complete narrative, experimental setup, and many explicit numerical findings, but the actual cells of Tables 1, 2, 5, and 6 are absent. Consequently, full per-model baseline comparisons, exact disjoint-evaluation results, exact five-run means and deviations, statistical significance, memory sizes, generation/inference costs, similarity thresholds, and complete reproducibility settings cannot be verified from the supplied content.
