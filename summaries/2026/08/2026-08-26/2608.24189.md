# MemUse: Moving Memory Evaluation from Direct QA to Natural Integration in Long-Term Human-AI Conversation

> [← Daily summary](../2026-08-26.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2608.24189) · [arXiv](https://arxiv.org/abs/2608.24189)


## One-sentence takeaway

In a four-month diary-chatbot deployment, increasing memory capacity substantially improved direct factual recall but not satisfaction, while the system’s ability to naturally integrate user-cued memories showed a moderate observational association with satisfaction.

## Problem and motivation

Conversational memory is usually evaluated with direct, fact-seeking questions about previous dialogue. The authors argue that this measures **elicited retrieval**—recalling information when explicitly asked—but not **natural integration**—recognizing an implicit memory cue and weaving relevant prior context into a conversational response.

This distinction matters because better benchmark recall is commonly assumed to improve real user experience, yet that assumption had not been tested longitudinally. In the authors’ deployment, Direct QA accuracy varied widely across memory configurations while satisfaction remained effectively flat, motivating an integration-focused evaluation (§§1, 4; Table 13).

## Approach and contributions

- **Longitudinal randomized deployment:** Forty proficient English speakers used a GPT-4.1-mini diary companion for four months, producing 1,872 sessions and 21,575 turns. Sessions rotated among Summary-only, three long-context capacities, and three RAG capacities (§3).

- **MEMUSE benchmark:** The authors detected and human-verified real moments in which users or the system invoked prior conversations. The released benchmark contains 72 reactive, user-cued instances—62 re-provisions and 10 probes—with 316 fact questions (§§5.1–5.2; Tables 6 and 9).

- **Integration-aware evaluation:** Each reconstructed instance is scored for Natural Integration, Direct QA, and fact-level Reference in the natural response, allowing retrieval and conversational use to be compared under the same model and context (§5.2; Tables 3 and 10).

- **Retrieval–integration diagnosis:** Cross-condition, cross-model, memory-system, and prompting experiments test whether improved access to facts produces greater conversational integration (§6.2; Figures 1–3; Tables 18–25).

- **Released assets:** The deployment corpus, satisfaction ratings, benchmark instances, judgments, prompts, and evaluation/analysis code are reported as released under research-oriented licenses (Ethics Statement; Appendix H).

## Evidence and main results

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| More memory capacity improved conventional recall without improving satisfaction. | Across seven randomized conditions, existing-benchmark QA rose from 19.7% for Summary-only to 70.1% for LC-100%, while every condition differed from Summary-only by under 0.06 within-user SD; all pairwise effects had \|d\| < 0.06. Satisfaction analysis used 1,270 sessions from 29 users after filtering. | §4; Tables 13 and 15; Figures 7–8 |
| Direct retrieval did not imply natural use. | With GPT-4.1-mini and LC-100%, MEMUSE Direct QA was 78.8%, Reference was 7.9%, and Natural Integration was 22.2%. Direct QA versus Reference therefore differed by about 71 percentage points under the same reconstructed contexts. | §6.2; Figure 1; Table 13 |
| Fact retrieval and fact use were uncorrelated in deployed memory moments. | Across 207 paired question judgments from 55 instances in 48 sessions, per-fact Direct QA correctness versus Reference had Spearman ρ = −0.009. | §6.2; Table 7; Appendix C.7 |
| Natural Integration, but not Direct QA, was associated with satisfaction in user-cued moments. | Across 48 sessions from 16 users, Natural Integration had ρ = +0.29, p = .046; successful integration corresponded to +0.56 within-user SD with clustered-bootstrap 95% CI [+0.12, +0.98]. Direct QA had ρ = +0.03. However, the LMM p = .082, the result did not survive Bonferroni correction, and a permutation test gave p = .23. | §6.1; Tables 7 and 16; Appendix C.7 |
| The dissociation appeared across stronger models. | For GPT-4.1-mini, GPT-5.5, and Gemini 3.1 Pro, Direct QA spanned approximately 33–34 points across capacity, while Natural Integration varied by at most 8.2 points within a model and did not track capacity. | §6.2; Figure 2; Table 18 |
| Dedicated memory systems raised holistic integration but retained fact-level gaps. | Mem0 achieved 58.3% Natural Integration, 41.5% Direct QA, and 7.3% Reference; Letta achieved 56.9%, 61.4%, and 10.8%, respectively. This was an offline evaluation, not a satisfaction experiment. | §6.2; Table 19 |
| Supplying extracted facts did not ensure their use. | In the LC-100% two-step ablation, generation omitted successfully extracted ground-truth details in 37 of 48 cases (77%). | §6.2; Appendix E.3.5, Table 23 |
| Proactive recalls showed no reliable positive satisfaction association. | Grounding and appropriateness each had \|ρ\| < 0.1. Eight mistimed recalls in rating-valid sessions averaged −0.48 within-user SD, but the corresponding interval straddled zero. Users continued the recalled topic in 19/64 cases. | §6.3; Figure 4; Appendix F.6, Table 27 |

The randomized deployment strongly supports the narrow conclusion that adding LC/RAG capacity above the shared summary baseline did not materially improve satisfaction in this setting. It also provides strong evidence that factual availability and conversational surfacing are different behaviors.

The evidence does **not** establish that Natural Integration causally increases satisfaction: integration success was not randomized, involved only 48 memory-moment sessions, and produced mixed inferential results. Offline gains from Mem0, Letta, stronger models, or prompt interventions likewise do not demonstrate gains in actual user satisfaction.

## Limitations and validity risks

- **Author-stated:** Every condition included a prior-conversation summary, so the randomized null concerns additional LC/RAG capacity, not memory versus no memory (Limitations).

- **Author-stated:** Explicit linguistic detection misses implicit cases where memory matters; the observed 1.4% of user turns and approximately 3.5% of sessions are lower-bound prevalence estimates (Limitations; §5.1).

- **Author-stated:** The integration–satisfaction analysis is small and observational: 48 sessions across 16 users, with only 11 successful-integration sessions. Its Spearman result is nominally significant, but the LMM, Bonferroni-adjusted analysis, and permutation test do not reach conventional significance (Limitations; Appendices C.4 and C.7).

- **Author-stated:** Automated constructs introduce measurement risk. Natural Integration is binary and sensitive to rater strictness; initial human agreement was poor before recalibration, and LLM–human agreement remained asymmetric (Limitations; Appendix B.4, Table 12).

- **Author-stated:** The sample was 92.5% female and limited to proficient English speakers using a diary companion, restricting generalization to other populations and task-oriented assistants (Limitations; §3).

- **Author-stated:** Privacy-driven replacement of some raw content with summaries may limit reproducibility (Limitations; Appendix H).

- **Analyst inference:** Comparisons with Letta are not fully controlled because Letta uses its own agent loop and prompting; the paper explicitly identifies Mem0 as the cleaner like-for-like comparison (Appendix E.2).

- **Analyst inference:** Some prompt experiments can inflate holistic Natural Integration even in Summary-only settings without increasing fact-grounded Reference, indicating that the main metric may partly reward recall-style wording rather than substantive memory use (Appendix E.3.8).

## Open research questions

1. **Does improving Natural Integration causally improve satisfaction?**  
   The current association is observational and underpowered. A next experiment could randomize, within identical user-cued moments, whether a system receives an integration intervention while holding retrieved evidence and response length constant.

2. **How should partial or subtle integration be measured?**  
   The binary judgment is sensitive to rater calibration, while Reference and the failure taxonomy were not validated as ordinal measures. A next study could develop a graded human rubric covering correctness, specificity, naturalness, and relevance, then validate it across independent annotator populations.

3. **How common are implicit memory needs?**  
   MEMUSE detects explicit probes and re-provisions by construction. A next experiment could sample ordinary turns and have multiple humans annotate whether access to earlier dialogue would materially improve the response, without requiring surface-level cue phrases.

4. **Do integration-focused systems generalize beyond diary dialogue?**  
   The deployment covers one persona and interaction setting. A next experiment could compare the same systems and metrics in task-oriented assistance, coaching, customer support, and multi-party conversation.

## Confidence and missing information

**Confidence: high** for the reported design, measurements, numerical results, and stated limitations because the supplied text includes the main paper and extensive appendices.

Material missing or unresolved:

- No raw instance-level data are present in the supplied text, so statistical analyses cannot be independently recomputed.
- Exact full prompts for some variants, per-instance outputs, and all released code are referenced but not reproduced.
- Participant-level subgroup analyses beyond the reported demographics are limited.
- The paper does not provide a randomized test of Natural Integration’s effect on satisfaction.
- The user-experience effect of Mem0, Letta, GPT-5.5, Gemini 3.1 Pro, and prompt interventions was not evaluated in live deployment.
