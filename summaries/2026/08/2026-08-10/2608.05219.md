# When Privileged Guidance Misaligns: State-Matched Routing and Contextualized Self-Distillation for Multi-Turn Agents

> [← Daily summary](../2026-08-10.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2608.05219) · [arXiv](https://arxiv.org/abs/2608.05219)


## One-sentence takeaway

The authors show that successful trajectories can misguide agents after state divergence and propose SMRC-SD, which applies privileged self-distillation only when the current state supports a grounded reference continuation, improving success on ALFWorld and WebShop.

## Problem and motivation

Privileged on-policy distillation can provide dense, token-level supervision by letting a synchronized teacher evaluate student-generated responses using successful training trajectories. However, earlier student actions alter the environment, so the student may reach a state from which the reference trajectory is no longer locally applicable. The authors call this **state–reference mismatch**: a reference may solve the overall task yet provide unsuitable guidance for the current state.

They argue that prior methods regulate rollout states or select and weight teacher signals without directly checking whether the privileged reference contains a compatible transition for the state reached on policy (Introduction). This matters because indiscriminate full-path conditioning can lower the teacher’s score for valid recovery actions (Figure 1; Table 1).

## Approach and contributions

- **State-matched routing:** SMRC-SD reconstructs compact signatures for the student’s current execution state and each reference pre-action state. It routes reference-conditioned distillation only when the current state directionally satisfies a reference state and the corresponding next action can be grounded in the current admissible actions (Equations 9–13).

- **Contextualized self-distillation:** On a matched turn, the teacher receives the complete reference path, a summary of the reached state, and the grounded next action or compatible action set. GRPO still trains every rollout, including unmatched turns (Equations 14–15; Table 10).

- **Operational validation:** Fixed-state teacher interventions, routing and context ablations, matcher comparisons, and candidate-plus-suffix replay test whether matching identifies locally useful guidance (Tables 1 and 3–6).

- **Training-only mechanism:** References, signatures, matching, and teacher context are removed at inference, so the deployed policy uses the ordinary agent prompt without added inference components (Integration with On-Policy Learning; Appendix C).

Together, these results support the authors’ claim that locally compatible routing is the main contributor and that combined state-and-candidate context provides a further gain under that route. Replay validates sampled matched continuations, and fixed-state interventions demonstrate changes in teacher preference.

The evidence does **not** establish perfect matcher recall, the true incidence of state–reference mismatch, or that unmatched actions are incorrect. The teacher interventions also do not by themselves prove how a single distillation update changes the learned policy (Appendix B and J).

## Limitations and validity risks

- **Author-stated boundary:** “Matched” and “unmatched” are operational labels, not correctness labels; replay measures successful continuation among sampled matches but not recall over unmatched states (Appendix J).

- **Author-stated boundary:** The fixed-state intervention measures teacher preference while holding responses fixed; it does not directly establish the optimization effect of a training update (Appendix B and J).

- **Environment specificity:** State signatures and parsing rules are hand-engineered separately for ALFWorld and WebShop rather than learned or universal (Reconstructing State Signatures; Appendix D).

- **Limited model and environment coverage:** Evaluation covers two Qwen model sizes and two interactive benchmarks. Generalization to other model families, continuous environments, or less structured action spaces is not established.

- **Single-run uncertainty:** Learning curves are described as single runs, and controllable seeds are fixed to 0; variance across training seeds is not reported (Figure 4; Appendix I).

- **Comparison caveat:** Some Qwen2.5 baseline values come from prior work rather than aligned local runs, whereas FullPath-SD and SMRC-SD are local (Baselines and comparisons; Table 2).

- **Control caveat:** The random same-count ablation matches turn count but not selected-token mass, K3 values, task mix, outcomes, or gradient mass (Appendix D, Table 14).

- **Reproducibility gap in supplied text:** Exact adapter rules, package pins, launch scripts, and several numerical tables are deferred to supplements or future code release; some referenced table contents are absent from the retrieved Markdown.

## Open research questions

1. **Can state matching be learned without losing executability guarantees?**  
   The paper relies on hand-engineered, environment-specific adapters. A next experiment could compare these adapters with a learned matcher on held-out state–reference pairs, measuring match precision, recall, replay success, and policy performance.

2. **What happens when no exact-task successful reference exists?**  
   Training assumes one stable-identity reference per task. A next experiment could retrieve references from related tasks and test whether state-conditioned transfer remains beneficial under controlled task-distance levels.

3. **How robust are the gains across random seeds and reference variants?**  
   The reported runs fix seed 0 and use one canonical reference per training task. Multiple training seeds and several valid references per task could separate method effects from optimization and reference-choice variance.

4. **Can routing account for degrees of compatibility rather than making a binary decision?**  
   SMRC-SD uses a binary route, although unmatched references are not uniformly harmful. A calibrated soft-routing experiment could compare binary matching with confidence-weighted distillation while retaining executable-continuation audits.
