# LatentPort: Beyond KV Cache - Cross-Model Transfer of Recurrent Memory in Hybrid Language Models: A 4B-to-9B Hybrid-State Handoff Without Target Prefix Replay

> [← Daily summary](../2026-09-23.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2609.25053) · [arXiv](https://arxiv.org/abs/2609.25053)


## One-sentence takeaway
For one geometry-matched Qwen3.5 Base model pair, transferring translated attention KV plus directly copied recurrent and convolution state, with a learned correction, lets 9B outperform continued 4B on teacher-forced continuation without replaying the historical prefix, but fails the paper’s near-native criteria.

## Problem and motivation
Switching language models usually requires the receiver to process the historical context again. KV transfer addresses attention memory, but hybrid models also retain recurrent matrices and convolution history. The paper asks whether this additional persistent state remains useful when installed in a differently sized model with different weights (§1).

The identified gap is cross-model transfer of built-in, prefix-conditioned recurrent inference state without receiver prefix replay. The author’s priority claim is qualified; the supplied text does not independently establish historical precedence (§5.6).

## Approach and contributions
- **Hybrid-state handoff:** Capture the source’s KV, recurrent matrices, convolution buffers, and bookkeeping. Install target-compatible state into fresh receiver caches, then feed a real next-token bridge before scoring continuation. Offline training uses native target traces; deployment avoids historical target-prefix processing (§§2.1–2.2).
- **Component selection:** Fit ridge-based component maps and compare direct versus translated components. The selected configuration translates KV and directly copies recurrent and convolution state, using exact layer/head correspondence (§2.3).
- **Behavioral correction:** Train identity-anchored residual updates through the frozen receiver using native-target distribution matching. The selected correction has 434,176 trainable parameters, excluding the existing KV translator and fixed bases (§2.4; Appendix C).
- **Controlled evidence:** Fixed-KV interventions, component factorials, wrong-donor controls, restoration checks, and paired document uncertainty support a bounded demonstration of useful state portability (§§3–4).

## Evidence and main results
All continuation results below use 4,096-token prefixes and 64 teacher-forced targets per document. Reported confidence intervals are 95% paired document bootstrap intervals.

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| GDN package adds substantial information beyond KV | On 64 PG19 documents, adding translated GDN state to fixed translated KV reduces NLL by **0.7473 nats/token**, CI **[0.6921, 0.8047]**; every document improves. | §4.1; Figure 3 |
| Direct GDN reuse beats tested GDN maps | On the same PG19 test, translated KV plus copied GDN gives NLL **2.2913**, versus **2.3679 nats/token** for full translation. | Table 3 |
| Factorial supports recurrent copying | On 64 fresh FineWeb-Edu test documents, recurrent translation increases NLL by **0.020753 nats/token**, CI **[0.007905, 0.034039]**, averaged over other component choices. | Appendix F; Table 10 |
| Corrected handoff beats continued source | On 64 fresh FineWeb-Edu documents, corrected-minus-source NLL is **−0.0521 nats/token**, CI **[−0.0843, −0.0185]**. | §4.3; Table 8 |
| Correction improves the selected base | In that same test, base-minus-corrected NLL is **0.029022 nats/token**, CI **[0.022828, 0.035413]**. Corrected excess NLL is **0.076367**, JS **0.022067**, and NCR **0.917755** relative to native 9B. | Figure 5; Table 8 |
| Correct donor context matters | In that same test, corrected state yields NLL **1.989399**, versus **3.177764 nats/token** with shuffled complete donor state; corrected-minus-shuffled CI is **[−1.296, −1.085]**. | §4.4; Table 8 |
| Near-native gate fails | Corrected excess NLL **0.076** exceeds **0.05**, NCR **0.918** falls below **0.95**, and top-1 agreement **0.864** falls below **0.90**. | §4.3; Appendix D |

These results establish useful, document-specific hybrid-state transfer under the tested conditions. NCR measures recovered prefix-derived loss improvement, not accuracy. The primary intervention bundles recurrent matrices, convolution history, and initialization semantics; it does not isolate recurrent memory alone. Different test corpora prevent attributing differences between experiments solely to method changes. No production speedup or free-generation equivalence is established.

## Limitations and validity risks
- **Author-stated scope:** One transfer direction and one exactly matched Base sibling pair; cross-family, instruct-model, and mismatched-geometry transfer remain untested (§7).
- **Teacher-forcing dependence:** Ground-truth inputs may stabilize continuation. The longer-context branch was not run; secondary state tracking does not establish longer-horizon quality (§7).
- **Incomplete component isolation:** The frozen installer cannot independently activate fresh recurrent state with restored convolution state, or vice versa. Separating their contributions requires a validated alternative intervention (Appendix A).
- **Conditional uncertainty:** Bootstrap intervals exclude model-pair and training-seed variation. Post-verdict correction removals reuse test documents and lack independent confirmation (§7; Appendix G).
- **Efficiency accounting:** Prototype timings omit translation and other costs and combine primitive medians; they do not measure end-to-end deployment savings (Appendix H).
- **Analyst inference:** Successful copying supports behavioral compatibility, but does not establish identical internal representations or explain how compatibility arose; shared training history remains an untested hypothesis (§6).

## Open research questions
- **Does the benefit survive free generation?** Teacher forcing may suppress accumulated errors. Compare source, native target, base handoff, and corrected handoff on unconstrained continuations over increasing generation lengths (§6).
- **Does portability replicate across model pairs and directions?** Only one directed sibling pair is tested. Repeat the frozen protocol on an independent matched-geometry pair and reverse-direction transfer (§7).
- **Which GDN elements carry the original benefit?** The main contrast bundles matrices, convolution history, and initialization. Develop restoration-validated interventions that separate these components while controlling runtime branch semantics (Appendix A).
- **Does replay avoidance reduce actual serving latency?** Current accounting excludes material costs. Measure complete handoff latency, including translation, extraction, installation, and scheduling, against native target prefill (Appendix H).

## Confidence and missing information
**Confidence: high** in the bounded interpretation of the reported results, not in broader portability or efficiency claims.

Material missing evidence includes free-generation and downstream-task evaluations, longer-context quality, independent model-pair and training-seed replication, isolated GDN presence ablations, and complete serving benchmarks. The text describes extensive reproduction artifacts but does not establish a public access location or independent reproduction.
