# S3Gym: Can LLMs Turn Self-Testing and Self-Judging into Self-Improvement?

> [← Daily summary](../2026-09-03.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2608.31100) · [arXiv](https://arxiv.org/abs/2608.31100)


## One-sentence takeaway

S3Gym shows that LLMs can sometimes improve from self-generated interaction experience, but gains depend strongly on the task and reuse mechanism, while self-judgment accuracy alone does not predict improvement.

## Problem and motivation

Existing agent benchmarks mostly evaluate a fixed policy, leaving unclear whether an LLM can explore an environment, assess its own actions, and convert that experience into better behavior on new conditions. This matters for agents operating through repeated observation–action–feedback loops, where accumulating trajectories is useful only if feedback can be interpreted and transferred. The authors identify a missing unified protocol that separates experience collection, self-judgment, and reuse while preserving verifier-computed outcomes as external ground truth (§1, §3.3).

## Approach and contributions

- **Unified self-improvement protocol:** S3Gym decomposes adaptation into Self-Testing, Self-Judging, and Self-Improvement, organized as Explore → Judge → Consolidate → Update → Evaluate (§4.1, Eq. 1).
- **Controlled transfer evaluation:** Agents explore permissive configurations, then face stricter held-out configurations with disjoint seeds; evaluation trajectories cannot enter memory or training data (§4.4).
- **Three experience pathways:** The benchmark compares raw History ICL, score-conditioned Summary Memory, and supervised parameter Training under matched seeds, budgets, and decoding settings (§4.5).
- **Explicit judgment audit:** Model-reported immediate scores are compared against hidden verifier rewards, separating perceived action quality from actual outcomes (§4.2, §6.2).
- **Seven executable environments:** Chess, Minesweeper, Nullify, Tetris, Snake, Plants-vs-Zombies, and Trust Evolution cover several interactive reasoning regimes (§5.1; Appendix A).

The evidence establishes heterogeneous adaptation under this benchmark: neither summary compression nor parameter updating is uniformly beneficial, and locally accurate scores are insufficient for reliable transfer. It does not establish that self-judgment is causally irrelevant, that these patterns generalize beyond the seven games, or that the pathways are optimal implementations of memory and training.

## Limitations and validity risks

- **Author-stated constraints:** History ICL is limited by context length; Summary Memory can discard state-specific evidence or retain incorrect judgments; parameter training adds optimization variables and may amplify noisy experience (§1, §4.5).
- **Author-stated scope:** Raw AUC+ values are not comparable across games because their score scales differ (§5.2).
- **Author-stated uncertainty:** The proposed explanation that sparse successful trajectories prevent training gains on Minesweeper, Nullify, and Tetris requires trajectory-level verification (§6.1).
- **Analyst inference:** Parameter-training evidence uses only Qwen3-8B, whereas the principal context experiments use seven different models; this limits model-level generalization of the training conclusions (§5.2, §6.1).
- **Analyst inference:** The retrieved text omits the numerical contents of Tables 2–7 and the runtime values in Table 3, preventing independent checking of most aggregate claims and resource parity.
- **Analyst inference:** The supplied experiments do not report a causal ablation replacing self-scores with verifier rewards, random scores, or no scores, so the incremental contribution of Self-Judging is unresolved.
- **Analyst inference:** Reported evaluations are confined to textual games and largely synthetic transfer from permissive to stricter variants; applicability to deployed tool-using agents is not demonstrated.

## Open research questions

1. **Would ground-truth or calibrated judgment improve transfer?** Correlations between self-judgment quality and improvement are near zero, but no intervention isolates judgment quality. Compare self-scores, verifier rewards, randomized scores, and calibrated scores under identical trajectories.

2. **Can adaptive memory choose between summaries and raw evidence?** Each representation wins in different task regimes. Test a retrieval policy that preserves state-critical trajectory fragments while summarizing reusable strategic rules.

3. **How can training avoid negative transfer?** Qwen3-8B’s persistent PvZ degradation shows that self-generated SFT can overwrite useful behavior. Evaluate confidence-gated trajectory filtering, replay of baseline behavior, and per-game validation checkpoints.

4. **Do improvements transfer beyond related game configurations?** Evaluation uses held-out seeds and stricter variants but retains each game’s core structure. Test cross-game transfer or non-game interactive tasks using the same exploration–judgment–evaluation protocol.

## Confidence and missing information

**Confidence: medium.** The supplied text fully describes the conceptual protocol and provides several numerical results, but the actual cells of Tables 2–7, complete checkpoint trajectories, detailed runtime configuration, training hyperparameters, statistical uncertainty, repeated-run variance, and artifact licensing or release contents are unavailable.
