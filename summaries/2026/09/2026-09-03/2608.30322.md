# Ignorance or Incompetence? Constructing Knowledge-Gated, Verifiable Tasks for LLM Agents

> [← Daily summary](../2026-09-03.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2608.30322) · [arXiv](https://arxiv.org/abs/2608.30322)


## One-sentence takeaway

The paper introduces an auditable protocol for constructing agent tasks whose success depends on a supplied private-convention artefact, yielding a 68.0% versus 0% pass-rate gap for one frontier configuration across 15 tasks, but it does not test whether these tasks improve training.

## Problem and motivation

Professional tasks often rely on conventions absent from public data, making failures hard to attribute: an agent may lack required knowledge, fail to apply it, or face an underspecified task. Existing benchmarks may provide helpful context but rarely make access to that context a controlled construction variable.

The authors seek tasks that simultaneously require specialized knowledge and remain exactly verifiable. Their identified gap is a construction protocol that separates instructions from private specifications, audits information leakage, and tests whether access to the specification is operationally necessary (§1).

## Approach and contributions

1. **Knowledge-gated construction contract.** A human curator separates each task instruction from a reusable, kilobyte-scale artefact containing private conventions, reference tables, formulas, or utility operators. Instructions remain byte-identical with and without the artefact (§3.1, Figure 1).

2. **Two gate types.** Convention gates encode non-derivable choices such as private thresholds or normalization tables; operator gates provide difficult but potentially re-derivable algorithms. This distinction limits claims about what kind of knowledge is necessary (§3.3).

3. **Auditing and verification.** Static leak audits search instructions and environments for exposed gated content. Structured outputs are checked against deterministic witnesses; the proposed extension for open-form outputs uses named binary criteria with strict all-pass rewards (§§3.4, 3.6).

4. **Configuration-relative calibration.** Candidates are retained when five-trial pass rates satisfy: frontier configuration with artefact ≥60%, the same configuration without artefact =0%, and a second configuration with artefact ≤40% (§3.5, Equation 1).

5. **Calibration assets.** Seven of 15 tasks pass this screen, while five representative retained tasks and supporting tooling are publicly released (§§4.2, 5.4).

## Evidence and main results

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| The artefact produced a 68-point pooled gap. | Across 15 tasks and five trials per task-condition cell, the frontier configuration passed 68.0% with the artefact and 0% without it; the second configuration passed 22.7% with it. | §4.2, Figure 2, Table 1 |
| Seven of 15 candidates met the retention rule. | Required frontier +A ≥60%, frontier −A =0%, and second-configuration +A ≤40%; several retained tasks lay exactly on a boundary. | §3.5, Equation 1; §4.2, Figure 2 |
| A wrong artefact did not merely provide a prompting benefit. | On BOM costing, the frontier configuration scored 100% with the correct artefact but 0% with a plausible perturbed artefact and 0% without one, using five trials per condition. | §4.2 |
| Some apparent knowledge failures arose in the full agent harness. | Qwen passed 20/20 reduced, single-conversation probes across BOM costing and legal clauses after correctly reciting every convention, despite scoring 0/5 on each task in the sandboxed agent harness. | §4.3; Table 1 |
| Selection did not materially increase observed mixed-outcome frequency. | Across +A cells, all candidates had 40.0% mixed cells and mean empirical variance 0.088; retained tasks had 42.9% and 0.091, computed from the selection data itself. | §4.5 |
| Paper-index retained performance after manual shortening. | Full 4,379-byte and minimal 1,078-byte artefacts each yielded 100%, versus 0% at 0 bytes, with five trials per condition. | §7, Figure 3 |

These results support the authors’ claim that supplied artefacts can create a strong, auditable dependency under particular agent configurations. The perturbed control also suggests that correctness—not mere document presence—mattered for one task.

They do not establish improved post-training, generalization to unseen tasks or models, statistical stability at the task level, or a clean model-capability comparison. The harness probe further shows that full-agent failures cannot automatically be interpreted as ignorance.

## Limitations and validity risks

- **Author-stated:** The pool contains only 15 tasks with five trials per cell; one outcome changes a task-level estimate by 20 percentage points (§§3.5, 5.3).
- **Author-stated:** Automated leak audits cover nine tasks, and static scans cannot rule out semantic or indirect leakage (§§3.4, 5.3).
- **Author-stated:** The two configurations differ in both model and harness, preventing controlled model-level attribution (§§4.1, 5.3).
- **Author-stated:** All reported tasks use deterministic verification; the proposed rubric path is unevaluated and would introduce judge bias (§§3.6, 5.3).
- **Author-stated:** Retained tasks are selected using the same outcomes used to describe them, so retained-set statistics are not independent validation (§§3.5, 4.5).
- **Author-stated:** No training experiment was conducted, so learning utility remains unknown (§§1, 5.1).
- **Author-stated:** Only five of seven retained tasks are released; trajectories, reference solutions, and some source materials are absent, so the full reported matrix cannot be reconstructed from the release (§5.4).
- **Analyst inference:** The single-task perturbed control and single-task compression study are too narrow to establish general robustness to misleading artefacts or general artefact-size requirements.
- **Analyst inference:** Because several tasks sit exactly at retention thresholds, reruns could materially alter the retained set.

## Open research questions

1. **Do calibrated knowledge-gated tasks improve agent training?** The paper performs no post-training. A next experiment could compare matched training sets—gated and screened, gated but unscreened, and ungated—using disjoint held-out task families.

2. **How stable is retention across configurations and repeated samples?** Five-run estimates are coarse and model–harness effects are confounded. A common-harness study with more trials and held-out agent configurations could measure retention stability.

3. **Which artefact elements actually cause success?** The compression study compares only two successful non-empty sizes on one task. Per-rule and intermediate-size ablations across convention and operator gates could locate load-bearing content and failure points.

4. **Can exact attribution extend to open-form work?** No reported task exercises rubric verification. A next experiment could compare named-rubric judgments with expert adjudication and measure judge agreement, bias, and reward sparsity.

## Confidence and missing information

**Confidence: high** for the protocol and reported aggregate results because the supplied text is detailed and includes experimental conditions and limitations.

Materially unavailable information includes the numerical per-task rows and Wilson intervals from Table 1, verifier implementation details beyond the summary, inherited token and turn budgets, full artefacts and reference solutions, evaluation trajectories, results for unreleased tasks, and any post-training or held-out generalization evidence.
