# Knowing What Not to Answer: Selective Non-Compliance in Vision-Language Models

> [← Daily summary](../2026-09-07.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2609.04720) · [arXiv](https://arxiv.org/abs/2609.04720)


## One-sentence takeaway

KoNA training substantially improves two small VLMs’ ability to reject invalid components while answering valid ones, with transfer beyond generated queries but some loss of fully answerable-query accuracy (Tables 2–3; Appendix K).

## Problem and motivation

A visual request can combine answerable content with false assumptions, inaccessible information, unsafe instructions, or impossible actions. The authors argue that existing evaluations mostly assess whether an entire query warrants compliance, overlooking the need to correct, abstain, or refuse selectively while preserving useful answers (§§1–2).

## Approach and contributions

- **Paired benchmark:** KoNA covers False Premise, Visual Inaccessibility, Universal Unknown, Task Feasibility, and Safety. Each image has a single non-compliance query, a compound query adding answerable content, and a fully answerable contrast. It contains 3,100 image-level instances and 9,300 QA pairs, split into 1,300 training, 300 validation, and 1,500 test instances (§3; Table 1).
- **Construction pipeline:** GPT-5 and Gemini-2.5-Flash generate examples from MS COCO and Open Images V7 images. Automatic filtering checks grounding and task validity; human verification reviews test compound queries and answers (§§3.2–3.3; Appendix A.3).
- **Training recipe:** InternVL3-2B and Qwen2.5-VL-3B receive SFT on 1,200 examples, followed by GRPO on 100 disjoint examples. Both stages include fully answerable examples. GPT-5-mini supplies rewards prioritizing non-compliance correctness with a 0.3 factual-error penalty (§4.1). The contribution is this training application and benchmark, rather than a new optimization algorithm.
- **Validation assets:** Ablations, compound extensions of existing benchmarks, an image-source shift, and unchanged human-originated questions test behavior beyond the main benchmark. The authors report public code and dataset availability (Abstract; §6; Appendices H–K).

## Evidence and main results

All values below are reported proportions or benchmark scores; main non-compliance metrics use GPT-5-mini PASS judgments.

| Fine-tuning produces large targeted gains | Base → KoNA compound accuracy: InternVL3-2B 0.10 → 0.90; Qwen2.5-VL-3B 0.11 → 0.87. Single accuracy: 0.25 → 0.92 and 0.29 → 0.91, respectively. | Table 2 |
| Fully answerable performance is imperfectly preserved | Base → tuned Answerable Average: InternVL3 0.77 → 0.70; Qwen 0.73 → 0.71. Factuality Average improves 0.84 → 0.88 and 0.84 → 0.89. | Table 3 |

| Transfer extends across evaluation sources | Extended MM-SafetyBench compound accuracy, base → tuned: InternVL3 0.17 → 0.60; Qwen 0.06 → 0.62. On 750 CC3M instances using the same generation pipeline: 0.11 → 0.88 and 0.07 → 0.86. | Table 5; Appendix H, Table 8 |
| Human-originated queries also improve | On 250 selected, unrevised VizWiz-VQA questions, selective non-compliance rates rise 0.32 → 0.72 for InternVL3 and 0.39 → 0.73 for Qwen. | Appendix K |

These results support substantial improvements under the evaluated rubrics and some transfer beyond generated wording. They do not establish unchanged helpfulness or unrestricted real-world generalization. **Analyst interpretation:** the single–compound gap also reflects a stricter compound criterion requiring a correct answer to the valid component, so it cannot isolate non-compliance recognition alone (§4.3).

## Limitations and validity risks

- **Author-stated scope:** No open-source models above 80B parameters were evaluated because of computational constraints; audio and image-generation models are excluded. Task feasibility depends on the evaluated model’s capabilities (Limitations; §3.1).
- **Author-observed failures:** Tuned models still over-refuse, omit answerable details, make incorrect corrections, and invent explanations for visual uncertainty (§6.4; Appendix G).
- **Author-qualified transfer:** Compound benchmark extensions and CC3M reuse the construction pipeline. VizWiz questions retain human wording but are deliberately selected, so results do not represent the full VizWiz distribution (§6.2; Appendices H, K).
- **Analyst inference—judge dependence:** GPT-5-mini supplies training rewards, evaluation labels, and VizWiz selection. Human and alternative-judge checks strengthen credibility but cannot exclude correlated rubric preferences; Appendix B.1 explicitly acknowledges possible shared judge bias.
- **Analyst inference—uncertainty:** Fine-tuning is demonstrated on only two small models. The supplied results lack confidence intervals and repeated-run variability, limiting interpretation of small differences.

## Open research questions

- **How well does this work on naturally occurring mixed requests?** VizWiz evidence comes from a selected subset. Next experiment: independently collect and human-label naturally occurring compound requests without model-based selection.
- **Can helpfulness losses be reduced?** Answerable accuracy falls and benign refusal rates rise after tuning. Next experiment: sweep answerable-example proportions and factuality penalties, measuring both selective accuracy and over-refusal.
- **How dependent are gains on the reward judge?** Alternative judges validate agreement but are not shown training separate models. Next experiment: train matched variants with different reward judges and evaluate them using blinded human judgments.

## Confidence and missing information

**Confidence: medium.** Detailed tables, ablations, and transfer evaluations support the main finding, but broad generalization remains uncertain.

Material missing information includes the actual prompt contents behind Tables 12–29, cross-benchmark sample counts, statistical uncertainty, training/API costs, exact closed-model API versions, and trained-checkpoint release status.
