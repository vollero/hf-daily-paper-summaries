# When Quantization Breaks Memory: Recurrent-State Write-Back in Low-Precision Temporal Inference

> [← Daily summary](../2026-09-07.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2609.04490) · [arXiv](https://arxiv.org/abs/2609.04490)


## One-sentence takeaway
In simulated fluorescence-lifetime inference, controlled GRU and LSTM experiments show that coarse recurrent-state storage can suppress persistent updates and severely degrade accuracy, while auxiliary memory can recover much of that accuracy without retraining (§§3.1–3.5).

## Problem and motivation
A recurrent network repeatedly reads its stored state, so rounding that state can change subsequent computation. The authors identify a gap in evaluations based mainly on bit width: they do not explain when useful updates are repeatedly discarded or why quantization-aware training sometimes leaves an accuracy gap (§1).

The application is estimating short and long fluorescence lifetimes from noisy temporal signals, where compact inference models are motivated by rapid biomedical-imaging feedback. The evaluated data are simulated; clinical applications provide motivation rather than experimental validation (§§1, 2.1).

## Approach and contributions
- **Controlled storage interventions:** Freeze trained weights, recurrent computations, readout, and evaluation, then replace only recurrent-state write-back. Reconstructed native inference is checked before intervention (§2.2; §S8).
- **Mechanistic diagnostic:** Introduce the recurrent write margin, \(M=2|\delta|/\Delta_B\), to identify updates below the deterministic half-step boundary; combine it with write activity and persistence measurements (§2.2; §S8).
- **Direction memory:** Introduce an auxiliary signed counter that accumulates eligible sub-threshold proposals and triggers later grid transitions. Compare it with error feedback, residual memory, and stochastic rounding (§2.3; §S8).
- **Compatibility tests:** Use precision sweeps, matched training, and state-specific LSTM interventions to test whether failure depends on the learned interface and the stored variable. QMem is a newly developed diagnostic training scaffold; Seq2SeqLite and its dataset are reused (§§2.1–2.3).

## Evidence and main results

All paired lifetime errors below are **τ₁/τ₂ RMSE in nanoseconds**, evaluated on the common **160,000-sample held-out simulated test partition** (§2.1; §§S8–S9).

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Storage alone can cause severe failure | Frozen QMem P2F: continuous propagation **0.36/0.35**, native deterministic 4-bit **25.37/106.59**. Continuous propagation is the intervention for this checkpoint. | §3.1; Fig. 1c |
| Failure accompanies nearly absent decoder writes | At deterministic P2F, **99.59%** of decoder proposals are inside the write boundary; only **0.25%** of state elements change per step. | §3.2 |
| Auxiliary memory rescues the same checkpoint | P2F: error feedback **0.36/0.37**; 2-bit residual memory **0.34/0.40**; 3-bit direction memory **0.34/0.34**, all retaining 4-bit visible state. | §3.3 |
| Rescue extends to an independently trained GRU | Native 8-bit **0.20/0.22** → deterministic 4-bit **1.89/2.60**; error feedback **0.34/0.46**, 4-bit direction memory **0.49/0.58**. | §3.3; Fig. 2c |
| Higher precision can worsen a fixed solution | Native-4-bit GRU: **0.35/0.40** at 4-bit versus **0.43/0.57** at 8-bit; median occupied decoder levels increase **12 → 176.5**. | §3.4; Fig. S4 |
| Matched training yields parameter-dependent rankings | Across three matched runs, τ₁ mean ± SD: direction memory **0.30 ± 0.03**, 4-bit state **0.41 ± 0.03**, 6-bit state **0.48 ± 0.16**, residual memory **0.38 ± 0.10**. Six-bit state and residual memory outperform direction memory on τ₂ in every run. | §S6 |
| LSTM failure and rescue depend on state type | Native **0.239/0.254**; both states at 4-bit **3.857/1.327**; both with error feedback **0.263/0.332**. Cell-only 4-bit gives **8.158/1.292**, hidden-only **0.296/0.354**. | §3.5; Fig. S3 |

These controlled comparisons support a causal effect of write-back on the evaluated fixed networks. Diagnostics and rescue experiments support the authors’ suppressed-update explanation. They do not establish universal superiority of auxiliary memory: the accurate native-4-bit reference is not improved on both lifetimes by any tested memory or continuous-state alternative (§3.3).

## Limitations and validity risks
- **Author-stated:** Equal stored-bit counts do not imply equal arithmetic, routing, energy, or total hardware cost (§§S5, S10).
- **Author-stated:** LSTM cell and hidden states remain coupled; individual interventions are not an additive decomposition (§4).
- **Author-stated:** QMem represents one training trajectory, and matched training supports compatibility rather than a universal operator ranking (§S11; §S6).
- **Analyst inference:** One simulated task, compact architectures, and fixed sequence length limit conclusions about real measurements, larger networks, and other temporal settings (§§2.1, S7–S8).
- **Analyst inference:** Reported results do not isolate the sensitivity of direction memory to its fixed voting threshold through a dedicated threshold ablation (§S8).

## Open research questions
- **Does the mechanism persist on measured fluorescence data?** This study excludes biological-specimen datasets. Repeat frozen interventions on experimentally acquired decays with suitable reference lifetimes.
- **How robust is direction memory to its voting rule and temporal horizon?** The reported operator uses a fixed voting region and fixed-length sequences. Sweep vote thresholds, counter widths, and sequence lengths while measuring RMSE and suppressed-update persistence.
- **Which memory allocation is best under actual deployment constraints?** Stored-bit matching does not establish equal hardware cost. Implement the competing operators on one hardware target and compare accuracy, latency, energy, and storage.

## Confidence and missing information
**Confidence: high** in the reported within-study comparisons; broader generalization remains uncertain.
