# RoboSPA: Can VLA Models Go Beyond Simple Scenes and Short-Horizon Tasks?

> [← Daily summary](../2026-09-09.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2609.05324) · [arXiv](https://arxiv.org/abs/2609.05324)


## One-sentence takeaway
RoboSPA exposes substantial difficulty-related failures in four VLA models under single-task simulated manipulation, with the best overall success rate reaching only 22.3% at the hardest level (Table 2).

## Problem and motivation
The authors argue that existing manipulation benchmarks inadequately isolate fine-grained spatial grounding, extended procedural execution, and performance degradation as complexity increases. Binary task success also obscures whether failures arise from target selection, manipulation, ordering, or memory (§1).

RoboSPA addresses this diagnostic gap through controlled difficulty levels and complementary evaluation metrics, rather than introducing a new robot policy.

## Approach and contributions
- **Capability-organized benchmark:** Ten categories span spatial attributes, distances, indexing, relations, viewpoint transformations, repetition, unordered and ordered procedures, composite actions, and memory. The suite contains 56 base tasks with five difficulty levels each, producing 280 variants (§§3.2–3.3).
- **Simulation dataset:** Expert-coded demonstrations built on SAPIEN and RoboTwin 2.0 provide approximately 527K trajectories across five embodiments and clean or randomized scenes. Difficulty increases through candidate counts or procedural length (§§3.1–3.3).
- **Diagnostic evaluation:** Object-Normalized Target Accuracy (ONTA) chance-corrects success using object count; Progress Score (PS) measures the mean fraction of completed subtasks. Sampled failure analysis adds qualitative error attribution (§3.2.4; Appendix A).
- **Baseline study:** Four pretrained VLAs are fully fine-tuned separately per base task, using all difficulty levels. Additional experiments examine basic grounding and selected tasks across embodiments (§4.1; Appendices B, D, F.2).

## Evidence and main results
Main results use clean Aloha-AgileX scenes, separate models per base task, 250 training trajectories per task, and 100 evaluation trials per variant (§4.1; Appendix B).

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| All baselines have low hardest-level success | Overall SR, L1 → L5: RDT 16.8% → 6.9%; GO-1 25.1% → 8.8%; π0.5 55.2% → 22.3%; X-VLA 50.4% → 19.9%. | Table 2 |
| Reported uncertainty preserves the overall ranking | L5 overall SR bootstrap 95% CIs: π0.5 22.3% [21.3, 23.2]; X-VLA 19.9% [18.9, 20.8]. Intervals describe evaluation sampling uncertainty. | Table 10; Appendix F.1 |
| Spatial and procedural leaders differ | X-VLA spatial SR falls from 41.9% to 23.9%; π0.5 procedural SR falls from 71.2% to 23.1%, comparing L1 with L5. | Table 2 |
| Partial progress exceeds final completion | At L5, π0.5 averages 45.4 PS versus 23.1% procedural SR; X-VLA averages 35.7 PS versus 15.9% SR. PS is on a 0–100 scale. | Tables 2, 4 |
| Hardest memory tasks defeat every baseline | All four models have 0% L5 memory-category SR; π0.5 and X-VLA retain PS values of 11.4 and 7.3, respectively. | Tables 2, 4 |
| Chance-corrected spatial scores remain weak | Average L5 ONTA: RDT −11.0, GO-1 −5.3, π0.5 7.7, X-VLA 10.8; the defined random-selection reference is zero. | Table 3; §3.2.4 |
| Sampled failures suggest distinct bottlenecks | For π0.5 and X-VLA, target grounding accounts for over 70% of sampled spatial errors; manipulation accounts for approximately 50% of procedural errors. Analysis samples up to 20 failed videos per L5 task per model. | Appendix A; Figs. 7–8 |
| Difficulty effects extend across embodiments | X-VLA has lower L5 than L1 SR on every selected task–embodiment pair, using one task per category across five embodiments, with independent training for each pair. | Appendix F.2; Tables 11–12 |

The evidence establishes substantial failures in the reported fine-tuning setting, including partial execution without successful completion. It does not establish a universal ceiling for VLA models, real-world transfer, or cross-embodiment generalization without retraining. Individual task results are not uniformly decreasing across difficulty levels (Tables 13–16).

## Limitations and validity risks
- **Author-stated scope:** Simulation-only tabletop tasks limit real-world validity; deformable objects, human–robot interaction, and open-ended instructions remain underexplored (Limitations, p. 9).
- **Analyst inference—evaluation coverage:** The main study uses one embodiment and clean scenes. The multi-embodiment extension covers selected tasks and retrains separately; randomized-scene robustness results are not supplied (§4.1; Appendix F.2).
- **Analyst inference—metric interpretation:** ONTA transforms task success, which includes execution failures. It therefore cannot independently isolate target-selection accuracy, despite the authors’ grounding interpretation (§3.2.4; Appendix A).
- **Analyst inference—causal diagnosis:** Increasing object counts or action length also increases perceptual and execution burden. Failure annotations support possible explanations but do not experimentally isolate reasoning or memory deficits (§3.2.2; Appendix A).
- **Analyst inference—comparison limits:** Equal training steps and batch size do not equalize pretraining or compute. Bootstrap intervals do not establish variation across independently trained checkpoints (Appendices B, F.1).
- **Reporting ambiguity:** The basic-grounding comparison does not identify its evaluated model, limiting direct comparison with the main baselines (Appendix D; Table 7).

## Open research questions
1. **How much spatial failure comes from grounding versus control?** ONTA retains execution failures. Next experiment: score target identification separately, then compare normal execution with oracle-target execution (§3.2.4; Appendix A).
2. **Can explicit memory and progress tracking improve hard procedures?** The paper diagnoses memory and ordering failures without testing corresponding interventions. Next experiment: matched policy ablations with memory or subtask-state inputs, reporting both SR and PS (Appendix A).
3. **Do the findings persist under scene shifts and embodiment transfer?** Current embodiment experiments retrain per platform. Next experiment: evaluate held-out randomized scenes and embodiments without target-specific retraining (Appendices C, F.2).

## Confidence and missing information
**Confidence: medium.** The supplied text supports the main descriptive findings and provides extensive task-level results, but causal interpretations are less secure.

Material missing information includes independent training-seed variability, detailed bootstrap resampling procedures, explicit optimizer and learning-rate settings, failure-annotation agreement, randomized-scene performance, physical-robot validation, and the model identity for Table 7. Artifact availability is also unresolved: the abstract says code and data are available, while the licensing statement describes a future release.
