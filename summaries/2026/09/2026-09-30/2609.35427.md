# LLMs are General Asynchronous Agents

> [← Daily summary](../2026-09-30.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2609.35427) · [arXiv](https://arxiv.org/abs/2609.35427)


## One-sentence takeaway
AsyncLLM enables existing Qwen models to process concurrent inputs, reasoning, and actions without task-specific training, demonstrating improved responsiveness across several settings while leaving broad generality and reliable self-modification unproven.

## Problem and motivation
Sequential agent loops delay responses when observations arrive during reasoning or tool execution. The authors identify a common need across streaming assistants, interactive environments, and monitoring: ongoing computation must incorporate new information and react promptly. Existing approaches typically implement concurrency separately for each application; this paper proposes a shared programming and inference framework (§1–2).

## Approach and contributions
- **Programming interface:** AsyncLLM expresses agents as Python `asyncio` coroutines. Each writes model state into a `CacheBlock` and reads ordered combinations of blocks through cache views, exposing other coroutines’ intermediate progress without re-encoding their generated text (§3.1).
- **Hybrid and multimodal memory composition:** Building on prior concurrent-attention query rotation, the authors introduce blockwise affine composition for Gated Delta Network states and position-span handling for multimodal rotary embeddings (§3.2). These extend an existing attention technique rather than introducing shared attention from scratch.
- **Inference engine:** Balanced scheduling, chunked prefill, and modified attention kernels batch coroutines with different cache views while preserving responsiveness (§3.3; Appendix C).
- **Evaluation and assets:** The paper demonstrates training-free agents for input corrections, streaming video, videogames, and log monitoring; constructs ShardedVQA image-correction pairs; and explores agents rewriting their own inference routines (§4; Appendices F, J).

The evidence supports useful asynchronous behavior across the evaluated Qwen models and tasks. It does not establish universal model compatibility, consistently superior accuracy, or reliable autonomous architecture design. Monitoring demonstrates a measurable accuracy–responsiveness tradeoff. Streaming comparisons combine different base models and agent designs, so they do not isolate the causal benefit of AsyncLLM alone.

## Limitations and validity risks
- **Author-stated scope:** Videogame results establish basic capability rather than state-of-the-art performance. Self-defined coroutines are described as unreliable and perform worse on DeadlyCorridor (§2, §4.3).
- **Author-stated implementation boundaries:** Late-fusion visual models, optimized latent attention, and learned sparse attention remain future implementations. Exact recurrent-state composition requires affine updates; local convolution context is retained rather than recomputed after block rearrangement (Appendix D).
- **Analyst inference—comparison sensitivity:** Mage-VL tuning shows substantial metric tradeoffs. A tested configuration reaches TriggerAcc **90.63** but TimVal **4.31**, whereas the chosen configuration has **52.79** and **27.87**. Thus, the claim of superiority depends on the selected operating point and metric balance (Appendix H, Table 8).
- **Analyst inference—limited isolation and uncertainty:** The reported evaluations do not isolate shared memory, scheduling, and coroutine architecture through component ablations. Statistical uncertainty for task comparisons is not reported; synthetic timing values are medians of three measurements (Appendix E).
- **Deployment risk identified by authors:** Fast actions may occur before slower reasoning can intervene; self-modifying agents require sandboxing and restricted access. These risks are discussed without a corresponding safety evaluation (ethics statement, p. 10).

## Open research questions
- **Which component drives the gains?** Component ablations are absent. Compare identical models and prompts using sequential execution, asynchronous text exchange, and shared-state execution under matched compute budgets.
- **Does generality extend beyond Qwen and the implemented architecture?** Broader compatibility is argued rather than empirically demonstrated. Test another model family and a late-fusion model on the same correction and streaming tasks.
- **Can agents reliably improve their own coroutines?** Self-definition results vary by environment and lack detailed numerical reporting. Run repeated, budget-matched self-modification trials against a fixed human-defined agent, recording failures and performance trajectories.

## Confidence and missing information
**Confidence: medium.** The method and tabulated outcomes are explicit, but broad generality and causal attribution remain uncertain.

Material missing information includes exact values behind Figures 3–4, task-level confidence intervals, component ablations, detailed self-modification success rates and budgets, judge model identities for all judged evaluations, and verified public availability of the promised supplementary assets.
