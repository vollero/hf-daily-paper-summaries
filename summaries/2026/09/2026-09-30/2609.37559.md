# APM-Bench: Benchmarking Cross-session Persistent Memory for Egocentric Streaming Video Assistants

> [← Daily summary](../2026-09-30.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2609.37559) · [arXiv](https://arxiv.org/abs/2609.37559)


## One-sentence takeaway
APM-Bench evaluates memory across interrupted egocentric video sessions and finds that the tested systems struggle to combine historical recall, timely proactive assistance, and low storage and latency costs (Tables 3–4).

## Problem and motivation
Personal video assistants must reuse experiences after users stop recording and resume hours or days later. The authors identify a gap in evaluations centered on continuous videos: these do not jointly test cross-session recall, current-scene perception, proactive assistance, and deployment costs. Finite memory also creates a need to recognize when historical evidence is unavailable (§1).

## Approach and contributions
- **Multi-session benchmark:** APM-Bench organizes EgoLife and HD-EPIC recordings into activity-related trajectories, preserving session order and time gaps. It contains 104 trajectories, 549 sessions, and 2,719 human-refined candidates (§3.1; Figure 5).
- **Joint capability evaluation:** Twelve tasks cover cross-session understanding, real-time perception, and adaptive response. Models receive only prior-session memory and the current causal video prefix; adaptive responses are evaluated at independent annotated probes (§§3.2–3.3).
- **Evidence-availability diagnostic:** A separate set restricts accessible history to the two most recent completed sessions and tests both answering and selecting an insufficient-evidence option (§3.1).
- **Comparative analysis:** The authors compare raw-video replay, query-agnostic session summaries, and eight existing specialized memory systems using task scores, storage, and latency. The contribution is the benchmark and evaluation framework; no new memory architecture is proposed (§4.1).

## Evidence and main results
| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Raw video improves recall over summaries for the strongest evaluated general model | Gemini 3.6 Flash cross-session MCQA accuracy: **69.37%** with raw video versus **47.50%** with summaries; overall capability mean: **60.21** versus **53.54**. | Table 3 |
| Summaries substantially reduce storage and response costs | Qwen3.8-27B: raw-video memory uses **3.01 GiB/video-hour**, with **30.72 s** TTFT, versus **6.84 KiB/video-hour** and **8.13 s** for summaries; cross-session accuracy falls from **50.10%** to **41.05%**. | Table 3 |
| Current-scene perception can improve with compact history | Gemini perception MCQA accuracy rises from **64.20%** with raw video to **65.98%** with summaries, while its cross-session accuracy declines. | Table 3 |
| OASIS leads specialized systems in overall utility, with substantial overhead | Overall capability mean **41.46**, versus SimpleStream’s **37.58**; OASIS reports **32.44 s** TTFT and **2.66 GiB/video-hour** storage. | Table 3 |
| Autonomous assistance remains weak despite rich memory | Gemini with raw video scores **26.52** on memory-grounded proactive assistance and **25.58** on task-progress guidance, versus **73.62** on registered-condition response; these are gated judge scores on a 0–100 scale. | Table 4 |
| Recall and missing-evidence recognition diverge | On 130 available-evidence and 130 unavailable-evidence questions, Gemini achieves **85.38%** answer accuracy and **59.23%** unavailable-evidence detection; SimpleStream achieves **3.85%** and **95.38%**, respectively. | Table 13 |
| Necessary evidence alone does not solve adaptive response | On 12 EgoLife trajectories, 366 candidates, and three systems, Oracle evidence improves cross-session scores by **19.78–31.21 points**, but adaptive gated judge scores remain **28.98–51.86**. | Appendix B.6; Figure 6 |

These results support trade-offs among the evaluated representations and systems. They do not establish an unavoidable trade-off for every possible memory design. The authors interpret better perception with summaries as evidence of distracting history; **analyst inference:** this comparison also changes representation and input volume, so it does not isolate interference as the cause.

## Limitations and validity risks
- **Author-described scope:** Activity-selected trajectories omit intervening recordings. The Raw Lifelong control addresses this only on a subset of EgoLife trajectories and three systems (Appendix B.6).
- **Author-described persistence limitation:** Most specialized methods lack persistent-state export; storage is estimated from inference state. Their evaluation therefore does not demonstrate actual serialization and restoration across interruptions (§4.1).
- **Analyst inference—comparison confounds:** Specialized methods use different backbones, and general models have different frame caps. Rankings cannot isolate memory architecture effects (§4.1; Table 5).
- **Analyst inference—deployment validity:** Independent probes and offline replay do not establish continuous interaction behavior, repeated-intervention handling, or user benefit. Latency endpoints also differ: local TTFT versus proprietary full-response latency (§3.3; Appendix B.3).
- **Analyst inference—measurement validity:** Adaptive quality relies on one LLM judge; supplied text reports no human validation of judge scores. Output-format failures also contribute to poor results for some systems (Appendices A.3, B.5).
- **Analyst inference—diagnostic scope:** Missing evidence is simulated through a fixed history cutoff, rather than varied compression or retrieval failures (§3.1).

## Open research questions
1. **Can selective memory injection preserve recall while improving perception?** Representation comparisons leave relevance selection unresolved. Compare always-on history with relevance-gated retrieval using the same backbone and storage budget.
2. **Can explicit memory coverage improve calibrated answering?** Strong recall coexists with weaker missing-evidence detection. Add retained-session and evidence-coverage metadata, then test both answer accuracy and abstention across varying history budgets.
3. **What prevents useful autonomous assistance after successful retrieval?** Oracle evidence leaves adaptive performance low. Separate retrieval, intervention decisions, and response generation in a controlled ablation with human quality assessment.
4. **Do benchmark rankings survive continuous deployment?** Independent probes do not measure interaction feedback. Run uninterrupted replay with persistent-state restoration and previously delivered responses retained, measuring missed opportunities and repeated interventions.

## Confidence and missing information
**Confidence: high** for the benchmark design and reported results; **medium** for causal explanations and deployment generalization.

Material information unavailable in the supplied text includes explicit downloadable code/data locations and release status, participant demographics, human validation of the LLM judge, statistical uncertainty or repeated-run variability, and actual cross-interruption state-restoration tests for most specialized systems.
