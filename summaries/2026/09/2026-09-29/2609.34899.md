# ColNanoVDR: Document-Free Query Distillation for Multi-Vector Visual Document Retrieval via Optimal Transport

> [← Daily summary](../2026-09-29.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2609.34899) · [arXiv](https://arxiv.org/abs/2609.34899)


## One-sentence takeaway
ColNanoVDR distills multi-vector visual retrievers into 149M text-only query encoders using query embeddings alone, retaining 93.0–96.5% of teacher NDCG@5 on ViDoRe v2–v3 while preserving existing page indices (Table 1).

## Problem and motivation
Multi-vector visual document retrieval matches text queries directly to page images, but large vision-language query encoders run on every search. Conventional score distillation requires teacher embeddings for training pages, creating substantial caching overhead.

The authors identify a gap in document-free distillation: existing single-vector embedding regression does not directly handle unequal query-token sets or establish fidelity under MaxSim scoring. They aim to compress only the query encoder without rebuilding the teacher’s index (§§1–2).

## Approach and contributions
- **Document-free multi-vector distillation:** ColNanoVDR trains a text-only student against cached teacher query tokens; training consumes neither pages nor relevance labels. The authors claim this is the first framework of its kind (§§1, 3).
- **OTW objective:** Entropic optimal transport aligns differently tokenized query representations. A contextual linear head learns student-token weights, allowing one student token to represent several teacher tokens (§§3.2–3.3).
- **Score-fidelity guarantee:** For unit-normalized page tokens, the normalized weighted MaxSim discrepancy is bounded by \(\sqrt{2\,OT_c}\), and consequently by \(\sqrt{2\mathcal L}\). This is a sufficient condition, not a guarantee of unchanged rankings (§3.4; Appendix A).
- **Compatible inference:** Scaling student vectors by their learned weights realizes weighted scoring through standard MaxSim against the unchanged teacher index (§3.5; Appendix A.7).

## Evidence and main results
| Finding | Evidence / setting | Location in paper |
|---|---|---|
| High teacher retention across five teachers | Separate 149M students retain 99.0–99.5% of teacher NDCG@5 on v1 and 93.0–96.5% on v2–v3, each using its teacher’s index. | Table 1 |
| Faster CPU query encoding | ColQwen3.5 student: 87 ms versus teacher’s 2,290 ms, reported as 26× faster; one CPU thread, float32, batch size 1, median over 20 queries; MaxSim excluded. | Table 2; Appendix C.1 |
| Lower teacher-cache requirement | ColQwen3.5 query-only cache: 27.3 GiB versus 342.7 GiB for queries plus pages, a reported 12.6× difference. These are cache-volume figures, not an instrumented cumulative I/O measurement. | Table 5; Appendix C.2 |
| Competitive with score distillation | Same 149M student and training setup: OTW versus listwise KL yields v3 NDCG@5 of 55.1 versus 55.0 for ColQwen3.5, and 54.9 versus 49.9 for Tomoro; on ColQwen3.5 v2, OTW trails 60.0 versus 61.2. | Table 3 |
| Learned weights affect deployed retrieval | Holding ColQwen3.5 student embeddings fixed, replacing learned weights with uniform weights lowers 149M-student v3 NDCG@5 from 55.1 to 51.6. | Table 9 |
| Compatible with tested index pooling | ColVec1.1-4b on v3: pooling from 1,764 to 195 vectors/page changes teacher/student NDCG@5 from 61.6/59.1 to 61.1/58.2; retention changes from 95.8% to 95.3%. | Table 4 |
| Bound is empirically loose | On the 4,735-query analysis sample, OTW median maximum corpus score discrepancy is 0.069 versus chordal bound 0.568; the authors report 7.3–8.3× slack across document-free students. | Appendix E; Table 11 |

The evidence supports substantial query-encoding and cache savings with strong benchmark retention. It does not establish equal quality to every teacher, statistically significant small objective differences, or a 26× improvement in complete search latency. The mathematical bound applies to normalized scores; ranking preservation additionally requires sufficiently large teacher margins (Appendix A.3).

## Limitations and validity risks
**Author-stated:** All students use Ettin; every configuration has one fixed-seed run and no variance estimates. Objective comparisons cover only two teachers. Unpaired query-log training and language-specific performance are untested. Query compression leaves teacher index storage intact. The bound is loose and sufficient rather than necessary (Limitations, p. 9).

**Analyst inferences:** Deployment evidence is limited by encoding-only latency measurements and exhaustive scoring in the compression experiment (Appendices C.1, C.4). Also, training uses a truncated one-step Sinkhorn gradient rather than the exact gradient of the transport-cost objective; its practical adequacy is reported without a controlled exact-gradient comparison (Appendix B.3).

## Open research questions
- **Does OTW work with unpaired production queries?** All training queries originate from paired datasets. Compare matched-size training on query logs versus the existing query set, evaluating domain shifts and teacher retention.
- **How stable are objective rankings?** Single runs cannot resolve small margins, and alternatives are tested on only two teachers. Repeat multi-seed comparisons across all five teachers.
- **How much complete search latency is saved?** Encoding timings exclude MaxSim, and index size remains unchanged. Measure end-to-end retrieval across corpus sizes, batching settings, and approximate-search engines.
- **Does multilingual fidelity persist?** No language breakdown is reported despite translated training queries. Evaluate retention separately by language and compare English-centric with multilingual student backbones.

## Confidence and missing information
**Confidence: high** in the supplied method description and reported measurements; **medium** in broader generalization and deployment conclusions.

Material missing evidence includes run-to-run uncertainty, unpaired-query training results, language-specific evaluation, other student families, complete search latency, and controlled comparisons of exact versus truncated transport gradients. Code and models are linked in the paper but were not inspected.
