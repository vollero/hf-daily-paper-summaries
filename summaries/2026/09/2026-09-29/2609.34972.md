# Just MLPs: Efficient Visual State Reconstruction for Multimodal Language Models

> [← Daily summary](../2026-09-29.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2609.34972) · [arXiv](https://arxiv.org/abs/2609.34972)


## One-sentence takeaway
δ-Vision replaces repeated visual-token Transformer updates with learned low-rank adapters, preserving access to every visual token while improving accuracy over aggressive pruning at similar measured computation, without reducing default peak memory (Tables 1–2).

## Problem and motivation
Long image and video token sequences incur attention and feed-forward costs throughout an MLLM. Pruning reduces this cost but can remove evidence needed later. The authors investigate a different gap: whether layer-specific visual context can be constructed cheaply while retaining every token, rather than repeatedly evolving visual states through the full Transformer (§§1–2).

## Approach and contributions
- **Empirical motivation:** Spectral analyses, low-rank interventions, and MLP reconstruction suggest that useful visual computation occupies relatively small hidden subspaces and that layer-specific visual states are predictable (§4.3; Figures 1, 3; Tables 5–6).
- **Visual-memory adapters:** δ-Vision learns residual corrections using down-projection, SiLU, and up-projection. The embedding variant predicts each layer’s memory from initial visual embeddings; the recurrent variant accumulates corrections across layers. Memories remain full-dimensional (§3.1).
- **Retrieval and training:** In full-attention layers, frozen key/value projections expose all visual tokens to textual queries while visual queries, attention outputs, and feed-forward updates are omitted. Only adapters are trained, using teacher-forced forward-KL distillation from the original MLLM (§§3.2–3.3).
- **Extensions:** The paper evaluates multiple backbones, multi-image/video training, combination with pruning, and selective adapter skipping. Hybrid Gated DeltaNet layers require a distinct implementation that retains native visual recurrent-state updates (Appendices I–K).

## Evidence and main results
| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Strong single-image accuracy under aggressive-pruning comparison | Qwen3-VL-4B, nine-benchmark unweighted mean accuracy: embedding adapter 74.4%, recurrent adapter 75.4%, vanilla 80.1%; DivPrune at 5% retention 65.3%, EPIC 66.9%, DivPrune at 20% retention 74.2% | Table 1; §4.1 |
| Large FLOP reduction, modest realized speedup, no default memory saving | Video-MME, Qwen3-VL-4B: 17.90% of vanilla FLOPs, 1.30× total and 1.50× prefill speedup; peak memory 12.97 GB versus vanilla 12.94 GB and 5%-retention DivPrune 10.60 GB | Table 2 |
| Benefits extend to additional backbones | Nine-benchmark mean accuracy, δ-Vision versus 5%-retention DivPrune: LLaVA-1.5-7B 61.9% versus 59.8%; Qwen3-VL-30B-A3B 78.6% versus 71.3%; Qwen3.5-4B 71.6% versus 62.7% | Table 3 |
| Multi-image/video training improves transfer | Qwen3-VL-4B, mean accuracy across MuirBench, Video-MME, MVBench: single-image-trained adapter 49.5%, mixed-data-trained adapter 52.0%, vanilla 55.7%, 5%-retention DivPrune 50.2% | Table 4 |
| Sequential low-rank restoration recovers visual influence | Qwen3-VL-4B, interventions at all layers: RWQA accuracy is 71.2% vanilla, 46.1% with visual-to-text attention blocked, and 70.7% restoring 128 directions; MMStar is 64.9%, 25.6%, and 64.6%, respectively | Table 6 |
| Teacher-forced distillation performs well at lower reported training time | Embedding adapter, nine-benchmark mean accuracy: Supervised-KD 74.4% in 34m53s; OPD 74.0% in 4h38m08s; SFT 68.9% in 23m51s | Table 10; Appendix E |

These results support an alternative to sequence-length reduction in the evaluated settings. They do not establish universal superiority: δ-Vision trails several 20%-retention baselines across backbones, and trails 5%-retention DivPrune on LLaVA-v1.6-Mistral-7B (Tables 11–12). The reported 9.1-point advantage refers to the strongest **training-free** 5%-retention baseline; EPIC is the stronger training-based comparator in Table 1.

## Limitations and validity risks
The supplied text contains no dedicated author limitations section.

- **Observed trade-offs:** Default peak memory remains essentially unchanged, and FLOP reduction translates into substantially smaller wall-clock gains (Table 2).
- **Analyst inference—scope:** Disabling DeepStack for every Qwen3-VL method makes comparisons internally consistent, but leaves performance with that mechanism enabled untested (Appendix A).
- **Analyst inference—uncertainty:** Experiments use one fixed seed; confidence intervals and repeated-run variability are not reported (Appendix A).
- **Analyst inference—mechanistic evidence:** Native-trajectory interventions establish low-rank sufficiency under their construction, not that adapters can reproduce every relevant visual dependency (§4.3).
- **Implementation boundary:** The claim that visual attention computation is removed does not apply uniformly to hybrid layers, where predicted visual tokens still enter native Gated DeltaNet processing (Appendix K).

## Open research questions
- **How does efficiency scale with visual length?** Timing is reported on Video-MME without a controlled length sweep. Next experiment: vary image resolution, frame count, and output length while measuring latency and memory.
- **Would prompt-conditioned memories improve accuracy?** Both adapter variants construct memories without textual conditioning (§3.1). Next experiment: compare them with prompt-conditioned adapters at matched computation.
- **Can layer allocation generalize across backbones?** Sensitivity differs by model, while adapter-skipping results focus on Qwen3-VL-4B (Table 6; Appendix J). Next experiment: learn rank and skipping schedules across full-attention and hybrid models.
