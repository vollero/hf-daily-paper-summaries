# Jeveration: System One Models Now Generate

> [← Daily summary](../2026-11-19.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2611.24738) · [arXiv](https://arxiv.org/abs/2611.24738)


## One-sentence takeaway

Jeveration uses shared randomness to coordinate parallel image-code predictions from a frozen vision-language backbone, generating a 512 × 512 image in 77.8 ms end to end on one H200 at batch 1 while using the same checkpoint for image-to-image generation and dense prediction (§§3–4, Table 1).

## Problem and motivation

Autoregressive and diffusion generators generally require sequential model evaluations that add latency. Predicting all image codes in parallel removes that bottleneck, but independently sampled codes can reflect incompatible interpretations of the same prompt. The authors ask whether a pretrained vision-language model can coordinate those decisions in one pass and use the same architecture for image synthesis and dense visual prediction (§1, Fig. 2).

## Approach and contributions

- **Parallel typed decisions.** Jeveration adds shared LoRA adapters and task-specific heads to a frozen Qwen3.5-4B backbone. For generation, decision tokens share a sampled random state and predict discrete TA-TiTok codes in parallel. A decoder renders the codes and can also receive the source image (§§3.1–3.2, Fig. 3).
- **Training for coherent code predictions.** A first phase learns masked-code conditionals. A second phase matches the generator’s conditionals to that frozen reference using an auxiliary model trained on current generator samples. A confidence-guided loss also teaches the generator to reproduce corrections to low-confidence codes. These extra models and correction rounds are used during training (§3.3).
- **One checkpoint across visual tasks.** The shared adapters support text-to-image and image-to-image generation as well as semantic segmentation, depth estimation, and surface-normal estimation. Dense heads use spatial queries and produce deterministic outputs (§3.2, Fig. 3).

The reported experiments demonstrate single-pass prediction across the evaluated tasks and a latency advantage in the stated hardware setting. The largest speedup compares different resolutions, and quality rankings vary by metric and baseline. The fixed-state ablation supports the value of random conditioning on the reported quality metrics. Diversity across repeated draws for the same prompt remains unquantified.

## Limitations and validity risks

- **Authors’ observations.** Joint training gives a modest drop in depth and surface-normal accuracy relative to dense-only models. The authors suggest that shared capacity may affect fine local geometry, an explanation they leave untested (§§4.3–4.4).
- **Analyst inference.** Timing on one accelerator at batch 1 leaves throughput and latency scaling unresolved. Held-out structure metrics primarily measure fidelity to the input, and NYUv2 is the sole reported dense benchmark (§4.1, Tables 1–3).
- **Analyst inference.** The supplied ablation descriptions provide point estimates from separate runs. Without seed variation or uncertainty estimates, the stability of small effects such as the correction gain remains unclear (§4.4).

## Open research questions

- **How much diversity does the shared state provide for a fixed prompt?** The ablation reports alignment and preference scores. Compare random and fixed states over repeated generations per prompt, measuring both diversity and prompt adherence (§4.4).
- **Does the latency advantage persist at higher resolutions and batch sizes?** Jeveration’s main timing uses 512-px output at batch 1. Benchmark matched resolutions and batch sizes against single-step and few-step baselines, reporting latency and throughput (Table 1, Supplement §4).
- **What causes the surface-normal accuracy gap?** The paper suggests shared capacity as a cause. Compare shared and task-specific adapters under matched training exposure and parameter budgets, using NYUv2 normal metrics (§§4.3–4.4).
