# Unified Law for Visual Tasks (The Four Laws of Computer Vision)

> [← Daily summary](../2026-11-19.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2611.24917) · [arXiv](https://arxiv.org/abs/2611.24917)


## One-sentence takeaway

World Snapshot Models use one frozen image generator and independently trained task adapters to cast heterogeneous visual tasks as conditional generation, with end-to-end results reported for 1,148 dense input–output mappings (§§3.2, 5).

## Problem and motivation

Visual tasks take and produce different kinds of information, from RGB images and text to depth maps, poses, and semantic masks. The authors argue that this diversity makes a single prompt–answer interface insufficient and that existing adaptation methods leave open how to add thousands of visual capabilities efficiently. Their hypothesis is that a shared representation and generator can unify these tasks when the inputs preserve the information needed for prediction and the backbone can support the target representation (§1, surviving §7.5 excerpt).

## Approach and contributions

- **Task formulation.** The authors group visual tasks into generation, estimation, conditional control, and reconstruction. Four operational interfaces specify how to route RGB, text, and auxiliary observations to generate a target. The conceptual families and training interfaces have a many-to-many correspondence (§3.2, Fig. 2).
- **World Snapshot Graphics.** The `.wsg` format stores RGB and auxiliary attributes in an address space of up to 256 channel IDs. Each mapping reads and generates only its relevant channels, and generated outputs can become inputs to subsequent mappings (§§3.1–3.2).
- **TunnelingNet.** Each task key activates an independently trained, low-rank target-side adapter inside a frozen FLUX.2-klein-4B generator. Modality Tunneling Attention (MTA) gives clean evidence its own attention normalization for structured targets. Native Joint Attention (NJA) is retained for text-guided RGB synthesis. Categorical and native sparse outputs use dedicated output modules (§§3.4–3.7, Fig. 3).
- **Evaluation.** The authors benchmark the same training framework across a large dense task graph, test whether outputs match their own held-out targets better than shifted targets, and compare reversible target encodings to isolate the effect of alignment with the frozen backbone (§§5.1–5.3).

The evidence supports a shared implementation across many separately trained dense routes and shows sample-specific correspondence beyond a fixed output template. The matched attention and encoding experiments support design choices in the tested settings. The external comparisons establish competitiveness on selected tasks with the reported inputs and annotations. Universal or lossless world representation, performance on untrained mappings, and total training-cost superiority remain unestablished.

## Limitations and validity risks

- **Author-stated scope.** The dense benchmark excludes native sparse tasks, whose detailed evaluation is deferred. The authors found no released input-matched image-level baseline for inverse rendering. Their formal scope also depends on information preservation, target readability, backbone coverage, and paired supervision (§3.2, §5.4, surviving §7.5 excerpt).
- **Author-reported measurement limits.** Global velocity MSE can reward background-heavy predictions, and some legacy edge previews in the attention ablation use different examples. The reported edge update ratios therefore compare visually unequal endpoints. The selected RGB reference route also achieved marginally better validation MSE while showing failures when reference pose conflicted with the current condition (§§4.1–4.2, Figs. 5–7).
- **Analyst inference.** External comparisons use short task-specific adaptation runs against systems trained for different scopes, so the sample ratios characterize the reported adaptation budgets. Public annotators test transfer between labeling conventions, while accuracy against measured scene geometry remains open. The controlled encoding result uses one normal-estimation task and one frozen backbone (§§5.3–5.6).

## Open research questions

- **Does representation alignment predict learning efficiency across backbones and target types?** The supplied controlled test covers one backbone and surface normals. Repeat the reversible-encoding comparison across multiple generators and targets, using the same native metric within each task (§5.3).
- **How quickly do errors accumulate in composed routes?** The supplied text describes routing one generated state into the next, while depth-dependent reliability remains unclear. Evaluate chains of increasing length with both ground-truth and generated intermediate states to measure error propagation (§§3.2, 3.4).
- **When does first-frame RGB improve inverse rendering?** The paper reports gains on some paired mappings, but the external comparisons lack a matched inverse-rendering baseline. Compare identical routes given correct, absent, and deliberately mismatched first frames using task-native metrics (§§5.1, 5.4).

## Confidence and missing information

**Medium.** The supplied text supports the architecture, dense benchmark protocol, and reported comparisons. The collector truncated a substantial middle portion, including much of the qualitative evaluation and discussion. The full formal statement, complete numerical task matrices and comparison tables, detailed sparse-task evaluation, and a full accounting of failures in composed routes are unavailable in the supplied text.
