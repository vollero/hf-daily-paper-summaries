# Lyris: Layout-Guided Long Video Generation with Persistent 3D Memory

> [← Daily summary](../2026-11-24.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2611.31239) · [arXiv](https://arxiv.org/abs/2611.31239)


## One-sentence takeaway

Lyris pairs editable 3D object layouts for unseen regions with persistent point-cloud memory for revisits, yielding a reported 3.8× reduction in camera rotation error and a 22% improvement in revisit similarity over the best baselines across six directed and autonomous evaluation blocks (§4.3, Tables 1–2).

## Problem and motivation

A walkthrough generated from a single photo must follow a supplied camera path, invent plausible content outside the initial view, and preserve that content when the camera returns. The authors identify a gap between memory-based methods, whose geometric guidance ends where prior views end, and layout-conditioned methods, which offer spatial control but typically require a prebuilt layout. Automatically planning the unseen regions could make long walkthroughs practical to author from sparse imagery (§1).

## Approach and contributions

- **Automatic, editable layouts.** Before each chunk, a vision-language planner uses the start frame, prior boxes, reconstructed memory, and upcoming cameras to place one labeled 3D box per object. Geometric checks and repairs address support, collisions, visibility, and other constraints. The system renders the boxes along the camera path and links their colors to object names in the prompt (§3.1, Fig. 3, App. B.1).
- **A generation loop with persistent 3D memory.** A fine-tuned MiniMax-H3 video diffusion model receives the rendered layout, rendered point cloud, retrieved appearance references, and camera-ray embeddings. The system reconstructs generated chunks and adds their geometry and posed frames to memory only when alignment passes a quality check (§§3.2–3.3, Fig. 2, App. B.4).
- **Evidence for the layout interface.** The authors compare rendered boxes with text-only plans and show that moving or swapping boxes changes object placement in same-seed regenerations (§4.4, Tables 3–4, Fig. 6).

The ablations support rendered layouts as a camera-control signal within Lyris. The filtered and shifted-return tests provide additional evidence for revisit consistency, though both still rely on estimated geometry or poses. The main fidelity metrics cover surfaces visible in the start frame, and box adherence measures surface placement within coarse bounds. These metrics leave the geometric accuracy of invented regions and the identity of objects inside those bounds unverified (§4.1, App. C.2).

## Limitations and validity risks

- **Authors’ limitations.** Depth and alignment errors can accumulate in memory over long paths. Training uses static captures, and the model does not currently model dynamic scenes. Boxes leave detailed object shape unspecified, and sequential planning and sampling make generation noninteractive (§5, App. D).
- **Analyst inference.** Main comparisons use one fixed-seed run per scene and method, leaving seed sensitivity unresolved. AnyRecon receives an empty prompt under its official implementation, so its directed result uses different text conditioning from the other systems (App. C.3).
- **Analyst inference.** SpatialVID is filtered for ground-level static walkthroughs and agreement between DA3 and ViPE on captured footage. This limits what its results establish about scenes where pose recovery is difficult. The low-rotation Revisit check also leaves translation error and differences in which pairs pass the filter unresolved (Apps. A.6, C.1–C.2).

## Open research questions

1. **How much does the memory acceptance rule help over longer paths?** The paper reports update pass rates for directed CA-1M, leaving the trade-off between rejecting bad geometry and retaining coverage open. Sweep the acceptance thresholds on longer routes with repeated loops and measure drift, memory coverage, and Revisit (App. B.4).
2. **Can richer layout primitives improve shape control without making planning less reliable?** The reported edits and adherence metrics operate on boxes. Compare boxes with coarse meshes on the same scenes, measuring shape agreement, planning failures, and latency (§4.4, App. D).
3. **Can the memory preserve object identity through motion and occlusion?** The paper reports qualitative box-motion edits from a model trained on static captures. Evaluate a model trained on dynamic clips using trajectories that revisit moving objects after occlusion, and score identity and motion consistency (Apps. A.8, D).

## Confidence and missing information

**Medium.** The supplied text describes the method, evaluation protocol, and headline comparisons clearly. It includes table captions and selected results but omits the numerical table bodies, so per-dataset scores, exact ablation values, and geometric-check tolerances cannot be audited in full. Seed-to-seed variation, retained-pair counts for the low-rotation Revisit analysis, and Lyris code or checkpoint release status are unspecified.
