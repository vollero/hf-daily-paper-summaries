# VideoNexus: Video Perception Beyond the Reasoning Context

> [← Daily summary](../2026-11-18.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2611.21392) · [arXiv](https://arxiv.org/abs/2611.21392)


## One-sentence takeaway
VideoNexus delegates dense audiovisual inspection to independent model calls and returns compact, timestamped evidence to a planner, reaching 88.6% accuracy on full LVBench with Gemini 3.8 Flash at 44% of the built-in agentic mode’s measured API cost (§4.2, Table 1).

## Problem and motivation
Long-video question answering requires finding brief events, resolving fine details, and combining observations across time. Static ingestion puts those operations in one dense context. Adaptive agents can choose where to look, but returning raw clips or one caption per frame still makes planner input grow with sampling density. The authors identify a gap in the observation interface: agents need to inspect more detail without carrying every observation forward (§§1–2).

## Approach and contributions
- **Planner-directed perception.** The training-free planner chooses the interval, sampling rate, and local question. Independent sub-agents read native audio and video. Cached transcripts and a sparse, question-conditioned Overview help locate candidate intervals, which the planner can revisit with Inspect (§§3.1–3.2).
- **Compact evidence exchange.** Overview caps its candidate list. Inspect returns a structured Finding with claims, source timestamps, modalities, and an explicit status. The harness checks structure and timestamp ranges. Visual Findings can include a small contact sheet for verification. The contribution is the combination of adaptive inspection and compact, task-specific reports within an established delegated-perception design (§§2, 3.2–3.4).
- **Empirical analysis of the interface.** The authors measure how report size grows with inspected media and test the effects of raw clips, text Findings, selected frames, and sampling budgets on planner input and answer accuracy (§§4.4–4.6).

## Evidence and main results

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Higher LVBench accuracy than static ingestion at lower measured cost | Full LVBench, Gemini 3.8 Flash, 1,549 questions. VideoNexus scored 88.6% at $0.140/question versus Static at 85.0% and $0.172/question (+3.6 percentage points, exact McNemar \(p=5\times10^{-7}\)). Costs use cold-start API pricing and exclude ASR. | §§4.1–4.2, Table 1 |
| Lower measured cost than Gemini Agentic, with close observed accuracy | Same full-set setting. Gemini Agentic scored 87.5% at $0.319/question. VideoNexus used 44% of that cost, with an observed +1.1-point accuracy difference (\(p=0.10\)). | §4.2, Table 1, Fig. 3 |
| Higher accuracy than the VideoSeek re-run | Same full-set setting. VideoSeek scored 81.4% at $0.188/question, giving VideoNexus a +7.2-point margin (\(p=5\times10^{-16}\)). VideoSeek used still images and lacked audio. Repricing its images at the cheapest tier yields $0.140/question with accuracy held fixed in the calculation. | §4.2, Table 1, Appendix C |
| Delegation reduced planner input in a paired ablation | Gemini 3.8 Flash on LVBench dev-200, with evidence cards disabled and transcription enabled. Switching from raw clips to text Findings reduced total planner input from 18.07M to 12.33M tokens (32%). Accuracy moved from 86.5% to 89.0% (\(p=0.23\)), and cost rose from $0.105 to $0.110/question. | §4.4, Table 3a |
| Reports grew slowly, and local cards showed observed gains | On full LVBench, Inspect’s highest versus lowest perceived-media deciles showed 16.8× as many frames and 1.67× as much returned text. On dev-200, local cards increased accuracy from 74.5% to 79.5% with Gemini 3.0 Flash and from 89.0% to 90.0% with Gemini 3.8 Flash. Only aggregate counts were available for the latter card comparison. | §§4.4–4.5, Table 3b, Fig. 4, Appendix F |
| Video-GAIA gains concentrated on harder questions | Across 271 questions with Kimi K3 in both arms and one shared semantic judge, VideoNexus scored 60.2% versus 51.7% for official ReAct (+8.5 points). The L2 margin was +11.5 points. The questions also informed tool development. | §4.3, Table 2, Appendix G |

The strongest evidence is for lower planner input in the tested delegation ablation and a full-LVBench accuracy gain over same-backbone static ingestion. The Gemini Agentic result establishes a measured cost advantage under the reported pricing. Its accuracy comparison leaves superiority and equivalence unresolved. The VideoSeek and Video-GAIA comparisons measure whole systems, so the individual contributions of report format, sampling, and media access remain open.

## Limitations and validity risks
- **Author-reported.** The LVBench ablations reused development questions, and the full benchmark includes that subset. The Video-GAIA questions also informed tool development, the arms differed in observation access and runtime settings, and scoring deviated from the official protocol. Missing perception usage records prevented a Video-GAIA cost comparison (§4.1, Appendices G and N).
- **Author-reported.** API costs depend on provider pricing and media transport. Matched wall-clock latency is unavailable. Findings can contain overconfident absence judgments or conflicting counts, and the earlier harness sometimes underperformed static ingestion on short clips or questions about global event order (§3.3, Appendices C, K and N).
- **Analyst inference.** The full-set accuracy gains cannot be assigned to compact reports alone. The closest ablation produced a clear planner-input reduction but an inconclusive accuracy difference, while the VideoSeek comparison changed several factors at once. Full-run variability is also unknown (§§4.2, 4.4, Appendix N).

## Open research questions
1. **How much does the report interface contribute when media access is matched?** VideoSeek differs in audio, sampling, and transport. Run a held-out factorial comparison that varies report format and audio access while fixing the model, inspected media, and budgets (§4.2, Appendices C and E).
2. **When should the planner request denser sampling or additional visual evidence?** The reduced-budget accuracy result was inconclusive, and the observed card gains differed across harness configurations. Compare uncertainty-driven and fixed-budget inspection on held-out questions at matched API cost, measuring answer accuracy and evidence correctness (§§4.4, 4.6, Appendix F).
3. **Does the Video-GAIA advantage survive held-out evaluation?** The reported questions informed tool development, and scoring used one judge draw. Freeze both harnesses, align observation and turn budgets, and repeat evaluation on fresh questions using the official judging protocol (Appendix G).

## Confidence and missing information
**Medium.** The main benchmark metrics and planner-input comparison are well specified. Material gaps include repeated full-set runs, held-out Video-GAIA results, matched wall-clock measurements, complete Video-GAIA usage records, per-question outcomes for the Gemini 3.8 card ablation, and confirmation that VideoNexus code or full evaluation traces were released.
