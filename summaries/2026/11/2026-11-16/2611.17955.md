# WebArena-Pro: A Heterogeneous, Multimodal, Reproducible Benchmark for Web Agents

> [← Daily summary](../2026-11-16.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2611.17955) · [arXiv](https://arxiv.org/abs/2611.17955)


## One-sentence takeaway
WebArena-Pro evaluates agents on isolated, multimodal workflows across 20 self-hosted applications, with the strongest tested configurations achieving 62.3% task success under a 50-step budget (Table 5).

## Problem and motivation
The authors identify a tradeoff in web-agent evaluation: self-hosted benchmarks provide repeatability but limited application and modality coverage, while live websites broaden coverage but change between runs. Existing settings also inadequately test embedded audio and video. WebArena-Pro aims to combine heterogeneous applications, temporal media, and reproducible stateful workflows (§§1–2).

## Approach and contributions
- **Broader benchmark coverage:** 300 human-validated test tasks across 20 applications and six domains, each with its own task template; a separate development set contains 100 easier tasks (§3.2; Appendix B.3).
- **Integrated media access:** Accessibility-tree nodes expose embedded media. Agents can request transcripts and sampled frames; compatible omni models can receive audio and video directly (§3.2).
- **Isolated execution:** Seeded Docker environments reset before every task, preventing changes from carrying into subsequent evaluations (§3.1).
- **Construction and verification pipeline:** Author-annotators draft tasks and rubric criteria, automated triage filters candidates, and another annotator validates them. A dependency-aware rubric verifier combines backend checks, action heuristics, and an LLM judge (§§3.3–3.4).

The contribution is primarily benchmark infrastructure and evaluation assets, rather than a new agent architecture.

| Media access improves performance on audited tasks | On a post hoc subset of 43 media-content-dependent tasks at 50 steps, Opus 5.5 rises from 14.0% SR without media tools to 48.8% with transcripts/frames; Qwen 3.6 27B rises from 0.0% to 16.3%. | §4.4; Table 7 |
| Native media access has a modest observed advantage | On that same 43-task subset, Gemini 3.1 Pro achieves 2.3% SR without media tools, 30.2% with transcripts/frames, and 34.9% with native audio/video. | Table 7 |
| Judge agreement is imperfect | On 300 trajectories spanning 50 tasks and six agent models, the selected Qwen judge has 89.5% pooled rubric-level agreement with humans, versus 90.5% and 90.6% for alternative judges. | Appendix D; Table 15 |

These results establish substantial remaining difficulty for the tested configurations and support the usefulness of media access. They do not isolate model capability from harness design or demonstrate generalization to production websites. The media ablation’s audited subset offers stronger evidence of content dependence than the full media-task pool.

There is a reporting inconsistency: §4.2 gives Kimi’s overall SR as **60.3%**, while Table 5 and the abstract give **60.7%**; the table value is used above.

## Limitations and validity risks
- **Author-stated:** Temporal interaction excludes live voice dialogue and streaming video. Model, harness, and tool configurations are confounded; equal step budgets do not equalize tokens, observations, latency, or native tool use. Costs depend on pricing and caching (Limitations).
- **Analyst inference—external validity:** Controlled applications reproduce workflow patterns without claiming production feature parity. Appendix E reports both adapted open-source applications and AI-assisted custom sites, so production-site transfer remains unestablished (§3.1; Appendix E).
- **Analyst inference—selection effects:** Discarding tasks solved on an LLM agent’s first attempt can make difficulty depend on the unspecified triage agent (§3.4).
- **Analyst inference—measurement reliability:** Rubric-level judge agreement leaves meaningful disagreement with humans; task-level grading error is not quantified. Repeated-run uncertainty is not reported, and authors explicitly call for repeated evaluations (Appendix D; Limitations).
- **Analyst inference—media validity:** The content-dependent subset was selected post hoc, and some media-labelled tasks remain solvable without media access (§4.4).

## Open research questions
1. **How much performance comes from the harness?** Existing comparisons mix models and tools. Next experiment: evaluate the same backbone across harnesses with matched observations, tools, and token budgets.
2. **Does native media input reliably outperform transcripts and frames?** Only Gemini receives the native-access ablation. Next experiment: repeat matched media-access comparisons across compatible models and runs on a prospectively defined content-dependent subset.
3. **Which mechanisms cause cross-site failures?** Aggregate gaps and examples identify coordination problems without isolating causes. Next experiment: compare matched single-site and cross-site workflows while varying navigation and intermediate-state support.
4. **How stable are rankings under grading and interface changes?** Judge disagreement is measured, but ranking sensitivity and UI robustness are not. Next experiment: human-audit borderline outcomes and rerun agents under controlled interface perturbations.

## Confidence and missing information
**Confidence: high** in the benchmark description and reported table values; **medium** in comparative interpretations.

Material gaps include repeated-run variance, confidence intervals, the triage agent’s identity/configuration, task-level verifier error, detailed inter-annotator agreement, hosting resource requirements, and direct evidence of production-site transfer. The supplied text describes released assets but does not independently establish their availability or successful reproduction.
