# CEPO: A General Framework for Improving Prompt Optimization in Multi-Agent Systems

> [← Daily summary](../2026-11-02.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.34722) · [arXiv](https://arxiv.org/abs/2610.34722)


## One-sentence takeaway
CEPO separates shared coordination instructions from agent-specific execution prompts and supplies role-specific optimization guidance, improving four existing prompt optimizers across the paper’s evaluated multi-agent tasks.

## Problem and motivation
Multi-agent systems need effective collaboration and specialized execution, but existing optimizers typically update prompts that mix these responsibilities. The authors argue that this makes shared coordination changes difficult to apply consistently across agents with different roles (§§1–2).

## Approach and contributions
- **Prompt decomposition:** Each agent receives a shared coordinator prompt prepended to its own executor prompt, allowing global collaboration rules and local procedures to change separately (§3.2, Eq. 2).
- **Role-aligned guidance:** Different optimizer meta-instructions target team coordination and individual execution. Both prompt layers remain selected using the same system-level validation metric; they do not have separate numerical objectives (§3.2).
- **Optimizer integration and evaluation:** CEPO supplies structure and guidance while PE2, OPRO, ProTeGi, or MASPO performs the search. The default schedule optimizes the coordinator first, then selected executors; this schedule is an implementation choice rather than the framework’s defining contribution (§3.3).

## Evidence and main results
| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Gains over corresponding document optimizers | On MDocAgent’s five document benchmarks, CEPO improves every PE2, ProTeGi, and OPRO result; reported gains span 0.6–6.5 score points. | Table 8 |
| Document systems improve over unoptimized baselines | PE2 + CEPO raises average document QA scores from 65.2 to 69.5 for MDocAgent and 70.0 to 72.7 for DocAgent, using custom document-level test splits and GPT-5-mini judging. | Table 2; §4.1 |
| CEPO complements MASPO | Across three mathematics and two code benchmarks, average reported score rises from 72.85 with MASPO to 73.89 with MASPO + CEPO; every benchmark improves. Exact per-task metric definitions are not supplied. | Table 3; §4.1 |
| Video improvement | LongVideoAgent’s LongTVQA+ score rises from 60.3 baseline to 63.4 with PE2 and 64.9 with PE2 + CEPO. | Table 7 |
| Components and guidance matter | On MDocAgent/MMLongBench-Doc, accuracy is 57.9 with vanilla PE2, 58.6 with coordinator-only optimization, and 61.0 with full CEPO. Aligned guidance scores 61.0 versus 57.7 with reversed guidance. | Tables 4 and 6; §4.2 |
| Better API-call efficiency in one setting | On MDocAgent/MMLongBench-Doc, CEPO with one iteration per phase reaches 60.1 accuracy using 2 optimizer and 3,120 internal calls; PE2 with three executor iterations reaches 57.9 using 10 and 5,714 calls. | Table 5 |
| Agent-count results favor CEPO | For evaluated two-to-five-agent MDocAgent configurations, headline CEPO accuracy increases from 56.9 to 61.0. Intermediate counts average different valid role subsets. | Figure 3; Table S3 |
| More executor updates can hurt | Optimizing GENERAL alone gives 61.0 accuracy; optimizing all five executors gives 56.9 in the document analysis. | Table S7 |
| Coordinator transfer is partial | Transferring the MMLongBench-Doc coordinator gives a reported four-benchmark average of 69.3 versus 71.6 with in-domain optimization. | Table S9; Appendix B.2 |

These results support CEPO as a useful addition to the tested optimizers. They do not establish universal gains across architectures, larger teams, or deployment conditions. Component, cost, and scaling evidence is concentrated in one document system. The component analysis reports averaging three seeds, but uncertainty estimates are not provided.

## Limitations and validity risks
- **Author-identified scope:** Joint optimization of multiple executors remains future work; expanding the optimized executor set does not improve the default document result (Appendix B.2).
- **Author-identified deployment risk:** Optimized prompts may still produce unintended behavior in high-stakes or out-of-distribution settings (Ethics statement).
- **Analyst inference—limited scaling evidence:** Agent-count comparisons change role composition and sometimes average configurations. They support the tested configurations rather than isolating agent count as the sole cause (Appendix A.4).
- **Analyst inference—evaluation uncertainty:** Document correctness relies on GPT-5-mini judging; human agreement, judge sensitivity, confidence intervals, and comprehensive run variability are unavailable (§4.1; Appendix C.1).
- **Analyst inference—cost claims need qualification:** CEPO’s reported inference time is close to baseline but higher than vanilla PE2. API-call counts also do not establish dollar or token cost equivalence (Tables 5 and S5).
- **Reporting and reproducibility:** Several prose references point to incorrect table numbers. Table S9’s caption describes transfer loss as negligible despite the reported average gap. Full code is only promised upon acceptance; exact math/code evaluation protocols are delegated to MASPO (§4.1; Reproducibility statement).

## Open research questions
- **How should multiple executors be optimized together?** Expanded target sets underperform GENERAL-only optimization (Table S7). Compare joint candidate selection with sequential updates under matched total budgets.
- **Does coordination optimization scale beyond these small teams?** Scaling evidence covers MDocAgent role subsets (Table S3). Test larger teams with repeated role composition and fixed resource budgets.
- **How transferable are coordinator prompts across systems?** Transfer is demonstrated only across document benchmarks and trails in-domain optimization (Table S9). Transfer coordinators across architectures and domains while controlling executor prompts.
- **How robust are gains to evaluation choices and randomness?** Broad uncertainty and judge-validation results are missing. Repeat optimization across seeds and document splits, then audit a blinded sample with human evaluators.

## Confidence and missing information
**Confidence: medium.** The supplied text gives detailed methods, numerical tables, prompts, and several useful controls. Material gaps include uncertainty estimates, comprehensive seed reporting, judge agreement, exact mathematics/code metric and split details, complete non-document optimization prompts, monetary optimization costs, and an available code release.
