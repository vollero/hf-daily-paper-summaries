# FLAMIA: FLAsh MIcroscaling Attention for Fast and Causally Safe Training on Blackwell

> [← Daily summary](../2026-11-03.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2611.03344) · [arXiv](https://arxiv.org/abs/2611.03344)


## One-sentence takeaway
FLAMIA reports faster low-precision attention training calls on Blackwell across nine causal packed-document workloads, while showing that strict causal safety requires optional settings currently limited to supported batched calls (§§4.1, 5).

## Problem and motivation
Low-bit tensor-core throughput does not automatically translate into faster, reliable attention training. Quantization can duplicate operands across matrix orientations, shared scales can transmit future-token information despite causal masking, and inconsistent forward/backward computations can destabilize training. Packed documents add alignment and scheduling costs (§§1, 3).

The authors identify a gap between demonstrating single-step numerical similarity and delivering efficient kernels with validated training behavior and controlled causal dependencies (§§1, 3.2–3.3).

## Approach and contributions
- **Reusable quantized representations:** Token-block scaling lets an E4M3 payload serve different matrix orientations, reducing duplicate quantization. FLAMIA provides MXFP8 and mixed NVFP4/FP8 paths; the mixed path uses NVFP4 for score computation and recomputation (§§3.1, 3.4).
- **Causal-dependency controls:** Upward-rounded scales, diagonal per-key scaling, and related safeguards address identified leakage mechanisms. Optional per-token/per-row scales and a causal gradient-accumulator scale remove the remaining identified dependencies in supported batched causal configurations (§3.2; Appendices A.3–A.4).
- **Consistent training numerics:** Forward and backward align quantized operands, tiling, diagonal handling, exponential evaluation, and gradient conventions. Blockwise softmax-gradient scaling preserves small entries (§3.3).
- **Kernel and packing optimizations:** Fused quantization, coordinated softmax/matrix scheduling, low-bit two-CTA backward execution, and GPU work scheduling process packed documents directly. Separate bit-level exponential approximations target inference (§§3.5–3.7).

## Evidence and main results

All results below are author-reported.

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| MXFP8 wins every evaluated causal packed training-call workload | Across nine workloads with 16 query heads and head dimension 128, forward + backward + quantization is **1.10–1.40× faster on B200** and **1.06–1.42× on B300** than the fastest supported baseline per workload. | §4.1; Table 1 |
| Mixed NVFP4/FP8 has strong backward kernel performance | Causal packed backward, excluding quantization: **1.22–2.01× speedup on B200**, **1.17–2.00× on B300**, against the fastest evaluated baseline per workload. | §4.1; Tables 3, 13 |
| Packing reduces memory and improves model throughput | At 131,072 tokens, peak attention-call memory is **2.7 GB packed versus 16.8 GB padded**. For the 1B model on one B200 at a 64k row length, throughput is **96.8k versus 84.3k tokens/s**. | §4.1 |
| Exact causal controls carry overhead and narrower support | Only exact options plus causal accumulator scaling leave earlier outputs unchanged in the reported probes. Causal accumulator scaling adds **8–11% backward overhead at 32,768 tokens** and currently covers batched causal calls. | §4.5; Table 5; Appendix A.4 |
| Leaking kernels can make validation loss misleading | Six-layer byte-level GPTs trained on enwik8 for 6,000 steps obtain **0.811–0.827** loss through leaking kernels, but **0.888–0.940** with exact attention; a model trained without the leak obtains **0.862** under exact attention. | §4.5 |
| Single-step gradient similarity does not establish stability | Mismatched diagonal handling produces a single-step gradient cosine of **0.945**, yet gradient norm grows from **0.5 to 200,000** in the evaluated configuration. | §4.5 |
| Larger training validation is qualitatively favorable | A 1B Llama-style model trained on 100B FineWeb-Edu tokens with 2k contexts reportedly shows marginal loss increases and downstream scores close to BF16 FlashAttention-4; actual scores are absent from the supplied table text. | §4.6; Table 6 |
| An inference approximation provides modest gains | On B200 packed inference calls including quantization, with aligned document starts, Schraudolph’s approximation gives **1.03–1.17× speedups** over default MXFP8 while changing output cosine by less than **10⁻⁴**. | §4.4 |

These results support practical attention-call acceleration in the tested settings and demonstrate failures that cosine similarity alone misses. They do not establish the same speedups for complete training runs against competing attention implementations, nor strict causal independence for default packed execution. The larger-model quality claim cannot be assessed quantitatively from the supplied text.

## Limitations and validity risks
- **Author-stated causal limitation:** Defaults retain dependencies within token blocks and through sequence-wide backward accumulator scaling. Packed documents, windows, and all-4-bit backward currently retain the default accumulator scale (Appendices A.3–A.4).
- **Comparison scope:** Several low-bit baselines lack a supported packed backward path in this evaluation. The combined-call ranking therefore concerns supported implementations, not every listed baseline (§4).
- **Timing qualifications:** Kernel-only measurements use aligned document starts, unlike training-call measurements, so subtraction cannot isolate quantization overhead. cuDNN output scales are calibrated beforehand on the same data (§4.1).
- **Author-stated confounds:** Bit-width comparisons change operands and scaling schemes; document skew is not isolated from other shape differences; the gradient-underflow association does not establish sole causation (§§4.1–4.2, 4.5).
- **Analyst inference—generalization remains uncertain:** Principal packed benchmarks use one head dimension, while larger-model quality validation uses one model scale and short contexts relative to the longest performance workloads (§§4.1, 4.6).
- **Reproducibility qualification:** Code is reported available, but table bodies and some training details are missing here. The authors also report substantial timing sensitivity to toolchain version (Appendices D–G).

## Open research questions
- **Can strict causal safety remain fast on packed documents?** Exact accumulator scaling currently excludes this setting. Extend document-local causal scaling and compare perturbation invariance, latency, and training loss with defaults (Appendix A.4).
- **Does quality preservation extend to larger models and longer training contexts?** The reported larger validation uses a 1B model with 2k contexts. Run matched BF16/MXFP8/mixed-precision training across larger scales and longer contexts, with repeated seeds (§4.6).
- **What causes the degradation associated with gradient underflow?** The scaling ablation shows association without isolating causation. Vary underflow while controlling other rounding errors and measure training outcomes (§4.5).
- **How much does scheduling benefit from document skew alone?** Existing workloads confound skew with other shape differences. Hold total tokens, head configuration, and document count fixed while varying the length distribution (§4.1).

## Confidence and missing information
**Confidence: medium.** The supplied narrative supports the method, reported speedup ranges, and causal qualifications, but omits table bodies.

Material missing information includes per-workload timings, exact downstream task names and scores, complete training hyperparameters, larger-training variability, and explicit identification of the causal-safety options used in those larger runs.
