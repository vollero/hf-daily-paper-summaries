# Diagnosing the Reference Gap: What Visual Scaffolds Can and Cannot Fix in Multimodal Reasoning

> [← Daily summary](../2026-11-03.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.39419) · [arXiv](https://arxiv.org/abs/2610.39419)


## One-sentence takeaway
Paired visual interventions show that task-matched numbering, shading, and grids improve multimodal reasoning, supporting—but not conclusively isolating—the authors’ proposed failure to maintain stable visual references.

## Problem and motivation
Models can recognize visual elements yet lose track of them during counting, comparison, or spatial transformations. The authors call this a **reference gap**: unstable bindings between language-based reasoning and visual entities, regions, or locations.

Prior approaches confound reference changes with training changes or additional prompt instructions. This paper asks whether references alone help fixed models, and whether their usefulness depends on the visual operation required (§§1–2).

## Approach and contributions
- **Controlled benchmark:** ReGap-Bench contains 1,000 generated scenes across shape counting, angle ranking, size ranking, clock ranking, and transformation prediction, yielding 3,800 images. Paired conditions preserve scene geometry, questions, answers, and prompt text while varying references (§3; Appendices B–C).
- **Task-dependent scaffold diagnosis:** Numbering supports indexing, shading exposes bounded regions, and grids supply spatial coordinates. Matched, mismatched, incomplete-reference, and model-scale experiments test when these interventions help (§§2, 4).
- **Training-free agent skill:** Written selection rules, visual examples, and an overlay script let an agent construct references during map reasoning. The authors evaluate this on a sampled CartoMapQA subset (§5).

The contribution is the controlled diagnosis and reusable scaffold-selection skill; the paper attributes the reference-gap concept to prior work (§1).

## Evidence and main results

Accuracy differences below are expressed as **percentage points**, consistent with the paper’s definition of scaffold effect as accuracy subtraction (§2.3).

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Numbering improves counting and clock ordering | Across five evaluated MLLMs, exact-match gains over plain images are 6.0–17.5 points for shape counting and 8.5–25.0 points for clock ranking; 200 scenes per task. | §4.1; Fig. 3 |
| Matched references outperform additional marks generally | Shape-counting accuracy changes averaged across models: numbering +11.3 points, shading +1.7, grids −4.1 versus plain. | §4.2; Fig. 6 |
| Shading improves angle ordering unevenly | Valid-ranking pairwise accuracy rises from 76.4% to 85.2% for Gemini and 59.7% to 68.0% for Qwen3-VL; four of five models improve. | §4.1; Appendix D, Table 5 |
| Grids provide smaller, consistent gains | Exact-match gains across evaluated models: 2.0–8.0 points for size ranking and 2.0–5.5 points for transformation prediction. | §4.1; Fig. 5 |
| More complete clock references help more | Mean clock-ranking exact-match accuracy is 23.9%, 25.3%, 31.8%, and 38.0% with zero, two, four, and twelve dial numerals; each model’s trend is non-decreasing. | §4.3; Fig. 7 |
| Scale does not eliminate numbering benefits | Six Qwen3-VL Thinking models spanning 2B–235B parameters retain shape-counting exact-match gains of 9.0–23.5 points. | §4.4; Fig. 8 |
| Preliminary probes suggest counting exceeds isolated recognition difficulty | Claude achieves 96.5% accuracy counting all shapes, 95.9% on cropped single-shape classification, and 72.0% counting the target class on plain scenes. | Appendix A |
| Agent transfer is reported, but its magnitude is unavailable | Codex GPT-5.5 is evaluated with/without the skill on 100 stratified CartoMapQA tasks across eight subtasks; it draws overlays on 57 tasks. Authors report improvement, but Table 2’s numerical cells are absent. | §5; Table 2 caption |

These results establish that changing visual references can change performance on otherwise paired problems, and that benefits depend on scaffold choice. They support the authors’ reference-gap explanation. They do not uniquely establish an internal binding mechanism: improved perceptual legibility remains a possible contributor, particularly for shading and clock numerals.

## Limitations and validity risks
- **Missing result detail:** The supplied text includes figure and table captions without their full plotted values or table cells. Complete per-model comparisons and CartoMapQA effect sizes cannot be recovered.
- **Analyst inference—mechanistic uncertainty:** The perception probes cover one model and shape counting. Cropped classification also changes the perceptual setting, so these probes do not exclude perception-related explanations across all tasks (Appendix A).
- **Analyst inference—limited generalization:** Main experiments use generated geometric scenes. Transfer covers one agent and a sampled map benchmark subset (§§3, 5).
- **Analyst inference—incomplete intervention coverage:** Mismatched-reference analysis focuses on counting and clocks; numbering is not applied to the other three tasks (§4.2; Fig. 2).
- **Measurement constraints:** Pairwise accuracy excludes invalid rankings. Wrong-side errors are inferred from final rankings, while grid use is judged from written responses without images; these are indirect behavioral measures (Appendix C).
- **Uncertainty and reproducibility:** The supplied text does not report confidence intervals, repeated-run variability, decoding settings, or agent execution costs. Its size-ranking shading statement, “from 4.0% to 11.0%,” is ambiguous about whether these are accuracy endpoints or a gain range (§4.1).

## Open research questions
1. **Do scaffolds improve binding independently of perception?** Existing probes are narrow. A next experiment could verify full-scene recognition per item before comparing paired multistep reasoning.
2. **How reliably can agents choose the right scaffold?** Map transfer lacks numerical detail and a selection-quality ablation. Compare autonomous selection with oracle selection, fixed overlays, and random selection on identical tasks.
3. **When does reference density become harmful?** Complete clock numbering helps, while mismatched grids hurt counting. Sweep label density, grid spacing, and scene complexity under matched and mismatched conditions.

## Confidence and missing information
**Confidence: medium.** The experimental design and several quantitative findings are explicit, but mechanistic conclusions and transfer strength remain less certain.

Material missing information includes full figure/table values, CartoMapQA accuracy gains, statistical uncertainty, decoding and execution settings, invalid-ranking frequencies, annotation agreement, and independently verified release contents.
