# Auto-Research Agent on MSA Organization to Improve Protein-Protein Complex Structure Prediction

> [← Daily summary](../2026-11-04.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2611.03183) · [arXiv](https://arxiv.org/abs/2611.03183)


## One-sentence takeaway
The authors report that an LLM agent improves frozen AlphaFold 3 interface predictions by adapting MSA sequence selection and pairing per complex, using confidence-only feedback and substantially shallower alignments (§§4–6).

## Problem and motivation
Uniform MSA construction can retain irrelevant homologs or impose unreliable cross-chain pairings, reducing protein-complex prediction accuracy. The authors argue that aggregate conclusions about depth versus pairing obscure target-specific optima, while fixed candidate portfolios cannot use prediction feedback to decide what to generate next (§§1–2).

The central difficulty is that a new target’s true structure is unavailable: AF3 confidence provides an imperfect proxy for accuracy rather than a directly measurable optimization objective (§1).

## Approach and contributions

- **Adaptive MSA search:** A GLM-5.3 agent writes Python programs to filter, combine, reorder, and pair existing homolog sequences. Frozen AF3 evaluates proposals; the agent reflects on feedback and eventually nominates a previously tested input (§§4–5).
- **Flexible confidence-guided experimentation:** The agent examines confidence scores, predicted structures, and consistency across samples without a prescribed scalar objective. Ground-truth structures and DockQ remain hidden during the main experiments (Appendix A; §B.5).
- **Target-specific construction findings:** Evaluation and row-shuffling experiments distinguish sequence-content improvements from benefits of pairing policy, including deliberate non-pairing (§§6.1–6.2).

Each episode begins with an unchanged AF3 control. Persistent files and structured round summaries support iterative analysis; query sequences and templates remain fixed (§§4.2–4.3, 5.2).

## Evidence and main results

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Overall interface accuracy improves | AF3-Default → Agent mean DockQ: **0.584 → 0.604** on FB-v1-pp; **0.556 → 0.583** on FB-v2-pp-hard; **0.583 → 0.624** on HD439. Each interface averages 25 structures, followed by equal interface weighting. | §§3, 6.1; Table 1 discussed, numerical body absent |
| Shallower alignments accompany gains | Nominated MSAs average **40% of Default depth**; half retain fewer than **20%** of Default rows. | §6.2; Table 2 discussed |
| Pairing policy adds benefit for intra-species interfaces | On **339 HD439 intra-species interfaces**, preserving the agent’s policy accounts for approximately **0.014 of the 0.029** mean DockQ improvement over Default, using chain-wise row shuffling. | §6.1 |
| Fixed nominations transfer to fresh seeds on FB-v1 | Overall Agent–Default mean DockQ difference is **+0.020** with original seeds and **+0.024** with one disjoint seed set, over **278 interfaces**; each condition uses 25 structures per target. | Appendix D |
| Confidence-based nomination loses discovered gains | On matched FB-v1 interfaces, best-tested proposals improve mean DockQ by approximately **0.035**, but nomination relinquishes **41.0%**, leaving approximately **0.020** improvement. | §6.3; Figure 2 |
| Ground-truth guidance improves exploration and selection | On the same FB-v1 evaluation set, final mean DockQ is **0.6425** with ground-truth guidance versus **0.6041** for Blind; mean submissions also increase from **6.55 to 10.98** per target. | Appendix F |

These results support adaptive MSA editing over the matched Default input under the reported protocol. Equal final ensemble sizes prevent a simple “more final samples” explanation, but the agent uses additional predictor calls for search—**6.01 per target on average** (§6.1). The evidence does not isolate an advantage over an equally expensive nonadaptive search. Fresh-seed validation covers fixed FB-v1 nominations only, rather than repeated agent searches across all benchmarks.

## Limitations and validity risks

- **Author-identified proxy limitation:** Confidence can misrank candidates; final selections sometimes regress despite Default remaining eligible (§6.3; Appendix C).
- **Comparison confounding:** FoldBench fixed baselines use different MSA sources from Agent and Default, so their differences cannot be attributed solely to agent behavior (§5.3; §B.3).
- **Statistical dependence:** Tests treat interfaces from the same complex as independent, use unadjusted p-values, and assess one shuffling realization per target (Appendix C). **Analyst inference:** these choices limit the strength of significance claims.
- **Oracle confounding:** Ground-truth-guided episodes run longer on average. **Analyst inference:** their gains do not separately identify feedback quality and exploration duration (Appendix F).
- **Scope and reproducibility:** Experiments use one LLM and one predictor configuration. Benchmarks overlap, FoldBench-v2 similarity is explicitly a proxy, and API filtering causes one target exclusion (§§B.2, B.4–B.5).
- **Coverage limitation:** The supplied source is truncated, and several referenced tables contain captions without numerical bodies; complete coverage and independent inspection of all comparisons are impossible.

## Open research questions

1. **Does adaptive reasoning beat a matched-budget candidate portfolio?** The reported comparisons do not isolate this advantage. Test adaptive search against randomized and fixed portfolios using identical MSA pools, predictor calls, and nomination rules.
2. **Can better label-free nomination recover missed gains?** Nomination regret remains substantial (§6.3). Compare nomination strategies on held-out targets and fresh prediction seeds.
3. **How portable is the workflow?** Only GLM-5.3 with AF3 is evaluated (§5.2). Repeat the protocol with alternative agents and predictors under matched budgets.
4. **Which MSA interventions cause improvements?** Some cases alter composition, depth, multiplicity, and row order together (§G.3). Run factorial ablations that vary these factors separately across targets.

## Confidence and missing information
**Confidence: medium.** The supplied methods and prose support the main findings, but the source is truncated. Missing material includes complete main-result tables, subgroup uncertainties and p-values, aggregate resource-table values, parts of case-study trajectories, and confirmed availability of executable code and generated artifacts. Matched-budget nonadaptive comparisons and broader agent/predictor robustness are not established.
