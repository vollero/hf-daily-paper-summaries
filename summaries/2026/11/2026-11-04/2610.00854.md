# Are Frontier VLM Agents Ready to Be Robot Generalists? An Empirical Study with the Embodied Agent Arena

> [← Daily summary](../2026-11-04.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.00854) · [arXiv](https://arxiv.org/abs/2610.00854)


## One-sentence takeaway
Across the authors’ embodied evaluation, strong visual judgments and executable actions frequently fail to produce complete task success, with rankings depending on task composition and execution settings (§§4.2–4.4).

## Problem and motivation
Robot generalists must satisfy complete physical goals, rather than merely recognize objects, attempt actions, or achieve intermediate subgoals. The authors argue that aggregate accuracy and final success alone obscure where execution breaks: perception, target selection, state maintenance, or verification of completion (§1).

Their evaluation addresses this gap by measuring prediction quality, functional grounding, intermediate achievement, and final outcomes together.

## Approach and contributions
- **Unified evaluation:** Embodied Agent Arena combines 1,000 cases from 32 established sources and GeoProbe across Geometry, Spatial Reasoning, Affordance, Task Planning, and Manipulation (§3.1).
- **New geometric diagnostics:** GeoProbe contributes 168 queries with controlled camera motion, object motion, and scale references, primarily using Blender scenes with some real photographs (Appendix A).
- **Model-directed harness:** Agents choose actions through source-native interfaces and helpers, with persistent state and independent outcome scoring; the baseline adds no specialist perception or control pipeline (§3.2; Appendix B.1).
- **Failure analysis:** Ten-model comparisons and matched traces distinguish interface errors, incorrect target bindings, lost physical progress, and premature completion claims (§§4.2–4.4).

The contribution is principally a benchmark and empirical diagnosis, rather than a newly trained robot policy.

## Evidence and main results
| Finding | Evidence / setting | Location in paper |
| --- | --- | --- |
| Similar spatial performance can accompany very different planning success. | Qwen-Max versus Astra: Spatial Pass@1 **68.9 ± 1.1% vs 69.4 ± 1.0%** over 220 cases and five runs; Planning **36.9% vs 80.3%** over 157 tasks, one episode per assignment. | Table 2; §4.1 |
| Open-weight agents have larger execution gaps. | The three evaluated open-weight VLMs achieve **48.0–51.6%** Spatial Pass@1, **19.1–31.2%** Planning success, and **9.9–20.9%** Manipulation success; interactive denominators are 157 and 182 assignments. | §4.2; Table 2 |
| Manipulation leadership depends on aggregation. | Opus 5.5 leads Gemini 4 Argon with task weighting, **47.8% vs 44.0%** over 182 binary assignments; equal weighting across thirteen sources reverses this to **44.5% vs 47.4%**. Recorded outcomes remain unchanged. | §4.2; Appendix J.1 |
| Model diversity offers retrospective complementary coverage. | Across the same 157 Planning tasks, Astra solves **126**, Astra plus Gemini 4 covers **137**, and all ten cover **142**; **15** defeat every model. | Figure 7; Appendix J.1 |
| Similar raw depth errors conceal different distortions. | On twelve GeoProbe depth cases over five runs, Gemini 4 and Qwen-397B have raw AbsRel **0.299 vs 0.312**; oracle per-case scale alignment leaves **0.065 vs 0.203**. | §4.3; Appendix J.6 |
| Code recovery rarely guarantees sequence completion. | Among **100 CALVIN episodes**, **65** contain execution errors; **62** subsequently execute error-free code, but only **three** subsequently complete all five ordered goals. | Figure 8; Appendix J.4 |
| Self-review can introduce semantic regressions. | On eighteen Spatial cases, Qwen-27B self-review corrects **one** answer but breaks **two**; crop review corrects **two** but breaks **four**. | §4.4 |

These observations support the authors’ distinction between perception, interface compliance, and achieved environment state. They do not establish that release category causes performance differences, that oracle scale correction is deployable, or that retrospective model unions constitute a working routing system.

## Limitations and validity risks
- **Truncated coverage:** The supplied source omits a substantial middle portion, including detailed protocols and results; this analysis cannot assess the complete paper.
- **Recorded comparison constraints:** Manipulation retains source- and batch-specific observation schedules and ceilings. **Analyst inference:** scores compare complete configured systems, with model capability and execution support not fully isolated (§4.1).
- **Limited repetition:** Planning, Manipulation, tracing, and polygons use one run per assignment. **Analyst inference:** their rankings lack directly measured run-to-run stability (Appendix B.4).
- **Metric scope:** Continuous errors average valid predictions, while binary scores retain missing outputs and error terminations. Numerical Spatial success also differs from VSI-Bench’s official metric (Appendix B.3).
- **Opaque verification:** The authors explicitly cannot identify which pose or contact condition causes HumanCLAW sitting failures because its verifier is private (§4.3).
- **Review confounding:** Tool-assisted review adds both measurements and response allowance, so its gains do not isolate either factor (§4.4).
- **Reproducibility:** DeepSeek’s endpoint alias is mutable, and the supplied extraction lacks several referenced configuration tables (Appendix B.2).

## Open research questions
- **Does explicit state verification improve completion?** Traces show attempted actions without confirmed grasp or seating. Next experiment: compare the baseline with prerequisite checks under matched budgets (§4.3).
- **Which feedback component produces gains?** Tool review combines measurements and extra allowance. Next experiment: independently vary measurement access and response budget (§4.4).
- **Can complementary models be routed effectively?** Reported unions use outcomes retrospectively. Next experiment: evaluate a router using only information available before task execution against fixed-model baselines (Appendix J.1).
- **How stable are interactive rankings?** Single-run outcomes and weighting reversals leave this unresolved. Next experiment: repeat matched assignments with standardized observation schedules and budgets (§4.1; Appendix J.1).

## Confidence and missing information
**Confidence: medium.** The supplied text supports the main findings and their settings, but the source is truncated. Material missing information includes complete manipulation configurations, several table bodies, full coverage and dispersion analyses, and detailed review protocols. Reported public assets were not independently inspected; physical deployment generality is not established by the supplied evidence.
