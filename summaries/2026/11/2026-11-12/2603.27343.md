# WMIP: A Working-Memory-Inspired Programmable Probe of Cumulative State Tracking in Large Language Models

> [← Daily summary](../2026-11-12.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2603.27343) · [arXiv](https://arxiv.org/abs/2603.27343)


## One-sentence takeaway
The supplied paper’s WMF-AM probe measures cumulative state tracking through adjustable-depth, final-answer-only tasks, with scores associated with agent performance across models but weaker evidence for distinguishing strong models or isolating a memory-specific mechanism (§§3–5).

## Problem and motivation
The authors identify a gap between evaluating multi-turn task orchestration and measuring a model’s ability to update intermediate state within one query. Fixed-difficulty benchmarks can saturate, while existing memory probes may emphasize retention or lack controls separating cumulative tracking from simpler skills. They propose an adjustable diagnostic inspired by working memory, without establishing equivalence to human working memory (§§1–3).

**Source discrepancy:** The requested metadata names WMIP; the retrieved paper instead names its method **WMF-AM** and gives a different title. This analysis follows the supplied body.

## Approach and contributions
- **Adjustable cumulative-tracking probe:** Prompts provide an initial state and \(K\) arithmetic updates; models return only the final number, scored by exact match. The primary evaluation averages accuracy across \(K=3,5,7\) (§3; §4, Metrics).
- **Construct-isolation controls:** Single-step arithmetic, direct-assignment tracking, and self-cancelling arithmetic controls test alternative explanations; prompt variations assess robustness (§4.3; Appendix B).
- **Cross-domain extension and validation:** Permissions, schedules, and inventories test non-arithmetic cumulative tracking. Agent-battery correlations and extended depth sweeps characterize downstream association and degradation (§§4.2, 4.4, 4.7).
- **Reusable toolkit:** The authors report releasing configurable code, data, and templates. Their claimed novelty is the combination of adjustable depth, isolation controls, and downstream validation, rather than arithmetic tracking alone (§§2, 6).

## Evidence and main results
All values below are author-reported; correlations use Kendall’s \(\tau\)-b.

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Probe scores associate with agent performance across models | Mean accuracy at \(K=3,5,7\) versus deterministic 10-task battery: \(\tau=0.595\), 95% bootstrap CI [0.374, 0.785], \(p<0.001\), \(N=28\). Among models with agent score ≥0.7: \(\tau=0.293\), \(p=0.19\), \(N=14\). | §4.2; Fig. 2 |
| Controls support a cumulative-load contribution | At \(K=1\), 22/28 models reach accuracy ≥0.90; direct-assignment controls average 0.92. WMF-AM’s agent correlation exceeds the yoked control by \(\Delta\tau=0.214\), CI [0.017, 0.453], one-sided \(p=0.016\), \(N=28\). | §4.3 |
| Non-arithmetic tracking shows similar rankings | Across permissions, schedules, and inventories, mean accuracy declines 0.62 → 0.51 → 0.43 at \(K=3,5,7\); arithmetic–logical rank correlation is \(\tau=0.728\), \(p<0.001\), \(N=28\). | §4.4 |
| Published benchmark comparison does not establish superiority | On the same \(N=20\) models, MMLU–agent correlation is 0.603 versus WMF-AM’s 0.569. MMLU uses published 5-shot scores. | §4.5 |
| Scratchpad permission materially changes the measurement | CoT wrappers yield accuracy ≥0.90 for 20/28 models, reducing discrimination. | §4.6 |
| Collapse thresholds have limited interpretability | Reliable sigmoid fits (\(R^2>0.90\)) occur for 14/28 models, with \(K_{\text{crit}}\) spanning 1.3–55.3. The reported all-model threshold–agent correlation is nonsignificant: \(\tau=0.171\), \(p=0.23\), \(N=28\). | §4.7; Fig. 3 |

The evidence supports a depth-sensitive behavioral diagnostic with cross-domain consistency and cross-model agent association. It does **not** establish a causal contribution to agent success, a human-like memory mechanism, or superiority to established benchmarks. Final-answer-only prompting also cannot ensure equivalent computation budgets when some models use hidden reasoning (§§3, 5).

## Limitations and validity risks
- **Authors’ limitations:** Agent validation uses one seed, one ReAct scaffold, and a small task battery; criterion reliability and cross-scaffold generalization remain untested. The association is weaker among strong models (§5, L1).
- **Authors’ limitations:** Serial error propagation, instruction following, prompt format, and tokenization remain alternative explanations. The logical extension lacks matched non-cumulative controls and template-stability testing (§§4.4–5).
- **Authors’ limitations:** Related model families, uncontrolled API settings and hidden CoT, and untested non-English or fine-tuned variants restrict generalization (§5, L1–L4).
- **Authors’ limitation:** History removal confounds lost state support with disrupted chat formatting, weakening interpretation of the exploratory load-shift intervention (§4.8; §5, L5).
- **Analyst assessment—reporting consistency:** Query counts and seed coverage conflict across Table 1, §4.1, §4.6, and Appendix D. Open-weight counts also differ. Section 4.7 describes a full-model sweep through \(K=100\), whereas Appendix A says only two models have data at the highest depths.
- **Analyst assessment—threshold validity:** The reported all-model threshold correlation includes unreliable fits, despite language about excluding an artifact; the exact analysis population needs clarification (§4.7).

## Open research questions
- **Does the agent association generalize?** Criterion reliability is unestablished (§5). Repeat evaluation across multiple batteries, seeds, and scaffolds, with a separate analysis of strong models.
- **What mechanism causes depth-related failure?** Existing controls do not exclude serial error propagation (§§3, 5). Compare matched serial and independent computations while controlling prompt length and elementary-operation difficulty.
- **Does cross-domain consistency survive stronger controls?** Logical tracking lacks matched non-cumulative and template controls (§4.4). Add those controls within each logical domain.
- **Do collapse thresholds matter for deeper agent tasks?** Current threshold results are nonsignificant and fit-sensitive (§§4.7, 5). Evaluate agents at calibrated state-update depths and restrict threshold analysis to reliable fits.
