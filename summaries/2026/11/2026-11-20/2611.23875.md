# In Situ Training of Optical Neural Networks by Coding Agents

> [← Daily summary](../2026-11-20.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2611.23875) · [arXiv](https://arxiv.org/abs/2611.23875)


## One-sentence takeaway

A coding agent used camera measurements to characterize and train a diffractive optical network on one physical device, outperforming the tested gradient-free baselines on digit classification and image encoding and approaching the calibrated-backpropagation reference on both tasks.

## Problem and motivation

Fabrication errors, misalignment, and aberrations can make phase masks trained in simulation perform poorly on hardware. Calibrated backpropagation requires fitting a differentiable model to each device, while generic gradient-free search can require many measurements across a large parameter space. The authors ask whether a coding agent can use informative measurements to identify a compact physical design and tune it on the device. (Fig. 1, pp. 1–3)

## Approach and contributions

- **Measurement-driven training.** The authors introduce *optics as code*, a harness through which an agent writes phase masks, requests probes and task evaluations, and records findings for later sessions. Each request requires a hypothesis and expected outcome. Agent programs run on a CPU under an image budget, without numerical light-propagation models. (Fig. 1d, Methods)
- **Interpretable optical designs.** Agents used their probes to choose compact parameterizations. Classifier runs produced Fourier and spot routers, while an encoder run used a focusing lens and tuned low-order aberration modes. (Figs. 3–4)
- **Evaluation of the harness.** The authors benchmarked classification and encoding on hardware and used a calibrated simulator to test which harness components contributed to classifier performance. (Figs. 2–4)

## Evidence and main results

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Simulation-to-hardware accuracy drop | Ideal-model starting masks scored 98% in simulation and 35% on hardware for MNIST digits 0–2. | Fig. 1a, pp. 4–5 |
| Best-run hardware classification | On 3,147 sealed test digits, the agent reached 91.1% from task text and 96.8% with prior-session notes and code. PPO reached 52.5%, policy gradient 52.3%, and calibrated backpropagation 96.3%. The agent and gradient-free baselines had a 51,200-measurement budget. | Fig. 2b, Methods, pp. 10–11 |
| Measurement cost and run variation | The best classifier masks were selected after 50,328 measurements, while the backpropagation reference used about 67,000 camera images for calibration alone. Three agent runs given prior notes or general lessons scored 89.2%, 91.3%, and 96.8% on the hardware test set. | Fig. 2a, p. 5, Methods, p. 11 |
| Hardware image encoding | On 300 held-out Fashion-MNIST images reconstructed from 16 detector signals, Fable 5.2 with prior notes and code reached 16.09 dB mean test PSNR from a 13.87 dB session start. PPO reached about 15.0 dB and calibrated backpropagation 16.9 dB. The agent and PPO had 25,600 measurements each, with gains measured against their own session starts. | Fig. 3, p. 7, Methods, p. 11 |
| Physical characterization | The authors report that estimates of magnification, astigmatism, and tilt sensitivity from 48 probe measurements agreed with the calibrated model. The text gives no parameter-by-parameter error estimates. | p. 3, Fig. 4a–c,f |
| Harness ablation in simulation | On the calibrated model, classifier test accuracy was 80.6% with the full harness, 76.8% without evaluation camera images, 80.0% without probes, 76.9% without required hypotheses, 71.3% with scalar rewards only, and 58.7% for PPO. The full harness with prior notes reached 94.5%. | Fig. 4e, Methods, p. 10 |

The hardware results show that the agent can train this device under a fixed measurement budget. The best classifier score is close to the calibrated reference, and the paper reports no paired significance test for the difference. The measurement counts compare agent training with calibration alone, so they provide a partial cost comparison. The simulator ablations suggest that richer feedback and prior-session material help, with their effects on hardware still unquantified.

## Limitations and validity risks

- **Author-stated scope.** The authors demonstrate one optical setup and discuss combining units into larger networks and transferring knowledge across devices as future possibilities. (Discussion, p. 9)
- **Analyst inference on comparison scope.** PPO and policy gradient are the tested gradient-free classifier baselines. The study leaves open how classical optimizers would perform with the same compact optical parameterizations and probe feedback. (Fig. 4d–e, Methods, p. 11)
- **Analyst inference on attribution and repeatability.** The best prior-session condition bundles notes and code, and the assisted classifier runs vary in what they receive. The encoder model comparison reports one run per condition, which leaves run-to-run variability and the effect of model choice uncertain. (Figs. 2–3, Methods, pp. 10–11)

## Open research questions

- **How well does prior-session knowledge transfer across devices?** The reported transfer is between sessions on one device. Test notes and code from one unit on independently assembled units, with matched runs from task text alone.
- **How much of the gain comes from discovering a compact parameterization?** The hardware baselines search full-resolution masks. Give PPO and the agent identical router parameters and starting points, then compare held-out accuracy at matched measurement budgets.
- **Which harness features improve hardware performance?** The component ablations ran on the calibrated model. Repeat the image, probe, hypothesis, and prior-session ablations across multiple hardware runs, holding the model and measurement budget fixed.

## Confidence and missing information

**High** confidence in the reported task settings and headline results. The supplied text does not establish public availability of the harness or run artifacts, paired uncertainty for the classifier comparison with calibrated backpropagation, repeated results for each encoder model condition, or a full end-to-end cost comparison that includes language-model inference and calibration.
