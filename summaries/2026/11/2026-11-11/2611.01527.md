# From Tool State to Scientific Action: Auditing Decision Provenance in Biomedical Research Agents

> [← Daily summary](../2026-11-11.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2611.01527) · [arXiv](https://arxiv.org/abs/2611.01527)


## One-sentence takeaway
BioAgent-DF shows that corrupted scientific-tool values can change agents’ evidence choices or assay allocations without changing aggregate outcomes, and that recovery after consumption can require restoring execution state alongside corrected values (§§3.4, 5.4).

## Problem and motivation
Final-answer accuracy can conceal changes in which documents an agent reads, sentences it cites, or compounds it sends for testing. The authors investigate finite numerical errors from faulty GPUs that ordinary NaN/Inf checks can miss, identifying a gap between recording execution provenance and verifying the computation behind consequential decisions (§1).

Their central distinction is between **reference fidelity**—recovering a specified execution’s evidence and decisions—and biological or benchmark correctness: a recovered reference can itself be wrong (§§3.3, 5.3).

## Approach and contributions
- **Paired tool-state audit:** BioAgent-DF saves healthy-reference and candidate values at the same computation site, restores or transplants selected original coordinates, and continues on healthy hardware. Repeated references control for agent variability (§§2.1–2.5).
- **Separate fidelity endpoints:** It measures retrieval, reads, citations, actions, and verdicts independently, while distinguishing globally sparse replacement from replacement of every changed value actually encountered (§§2.3–2.4).
- **Recovery experiments:** Literature, molecular, cellular, and optimizer studies distinguish recovery of numerical state, ranked selections, and persistent agent history (§§3–5).
- **Certified commitment:** Decisions authorize action only when all scores consistent with valid bounds imply the same decision; otherwise trusted recomputation or abstention is required. The implemented hERG commitment experiment uses full trusted recomputation (§§5.3–5.4; Appendix K).

These results support a separation between aggregate correctness and object-level provenance under the tested interventions. They do not establish how frequently such failures occur in routine deployments, that reference recovery improves biological truth, or that the commitment mechanism prevents errors in physical laboratory execution.

## Limitations and validity risks
- **Author-stated scope:** Strictly repeated SciFact effects span only two claims and two small agent models, using Case 2 captures selected for upstream retrieval changes. Repeated batches are technical repetitions, not independent claims or captures (§7).
- **Completion and prompt sensitivity:** Budget exhaustion restricts comparisons to jointly completed groups; some conditions affect completion. Verdict changes under the baseline prompt did not recur with explicit examples (§§3.1–3.3; Appendix H.8).
- **Reference fidelity is not evidence validity:** Gemma’s stable SUPPORT verdicts were benchmark-correct despite neither branch citing annotated evidence; Qwen’s repeated NEI verdicts were incorrect (Appendix H.13).
- **Selective recovery is empirical:** R1+M uses a retrospective residual maximum, not a valid universal error bound. Checksums can detect/localize errors without bounding individual scores; formal certification requires valid bounds or trusted full recomputation (Appendix K.2).
- **Operational scope:** hERG experiments reuse one compound cohort and saved fault sources; accepted commitments are local records. Exactly-once external execution additionally requires an idempotent action service (Appendices I.7, K.3).
- **Analyst inference:** The reported verification speedup does not establish an end-to-end deployment advantage: timing excludes several setup/transfer costs, and direct trusted recomputation is faster than processing saved states with checks plus recomputation in Table I11.
- **Coverage limitation:** The supplied source is truncated, including part of Appendix H; some tables are represented only by captions. This analysis cannot claim complete methodological coverage.

## Open research questions
1. **How common are provenance changes without upstream selection?** The sustained-batching cohort shows no excess over healthy-repeat variation. Next experiment: prospectively sample captures and claims without retrieval-change filtering, reporting completion and capture-balanced uncertainty.
2. **Can selective recomputation provide inexpensive certificates?** R1+M recovers tested decisions empirically, while the commitment experiment fully recomputes scores. Next experiment: compare valid per-score interval refinement against full recomputation on new fault sources and cohorts.
3. **Which execution state must recovery restore?** File replacement fails, but the hERG restoration jointly replaces multiple dependent components. Next experiment: ablate visible history, variables, derived files, pending actions, and server caches separately.
4. **Does reference recovery improve real experimental outcomes?** Commitment is evaluated through local allocation records, and prospective laboratory studies remain proposed (§7). Next experiment: execute certified and control allocations with independent measurements and replication across sites.
