# VisSearch-Bench: Evaluating Long Horizon Visual Search in Multimodal Agents

> [← Daily summary](../2026-11-06.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2611.04894) · [arXiv](https://arxiv.org/abs/2611.04894)


## One-sentence takeaway
VisSearch-Bench tests whether multimodal agents can connect visual evidence across extended web searches, with the best evaluated system completing only 26.47% of its 204 tasks (Table 3).

## Problem and motivation
The authors argue that identifying an entity from an initial image and then searching text does not adequately test visual context management: connecting images, object identities, external facts, and later search targets. Their benchmark targets searches requiring repeated visual comparison, candidate filtering, complete set coverage, and integration across dependent steps (§1).

## Approach and contributions
- **Task framework:** Five search families distinguish set coverage, sequential dependencies, combined breadth and depth, fine-grained disambiguation, and image-structure-guided search (§3.1).
- **Benchmark:** 204 human-written tasks across seven domains and 25 subdomains, paired with reference answers, evidence sources, reference solutions, and scoring prompts (Table 2; Appendix E).
- **Construction and evaluation:** Human source curation and evidence structuring, shortcut review, and program checks support task integrity. Full-answer Accuracy is complemented by task-specific Process Score for partially correct answer content (§§3.2–3.3; Appendix B).
- **Empirical study:** Direct answering and search-agent settings are compared, including ablations of access to retrieved visual evidence (§4).

The contribution is a benchmark and evaluation framework; the paper does not introduce a trained agent.

## Evidence and main results
| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Tasks vary substantially in reference-solution length | 204 tasks; mean 17.6 reference steps per task. Competitive Disambiguation averages 3.9 steps, versus 23.9 for Set-wise Search. | Table 2 |
| Search improves complete-task performance | Across all 204 tasks, Direct Answer peaks at 6.37% Accuracy; ReAct + Kimi-K3 reaches 26.47%. | Table 3 |
| Accuracy and partial-answer rankings differ | ReAct + GPT-5.5 achieves 25.49% Accuracy and the highest overall Process Score, 49.52%; ReAct + Kimi-K3 scores 38.57% Process Score. | Table 3 |
| Exhaustive set completion remains difficult | On 68 Set-wise tasks, best Accuracy is 11.76% with ReAct + Kimi-K3. ReAct + GPT-5.5 scores 44.10% Process Score but 8.82% Accuracy. | Table 4 |
| Framework choice depends on backbone | Qwen3.6-35B-A3B scores 10.78% Accuracy with DeerFlow versus 7.35% with ReAct; GPT-5.5 scores 20.10% versus 25.49%, respectively, over 204 tasks. | Table 3 |
| Direct inspection improves aggregate results in tested ablations | For DeepSeek-V4.1-Flash with ReAct over 204 tasks, Full scores 22.55% Accuracy / 39.47% Process Score; Caption scores 19.12% / 36.33%; Text scores 12.25% / 23.14%. All retain initial images. | Table 5; §4.3 |
| Full visual access does not win on every task | For DeepSeek-V4.1-Flash, switching Full → Caption loses 20 correct answers but gains 13 on previously failed tasks. | Table 6 |

These results establish difficulty under the tested tools and budgets, and show aggregate benefits from search and direct visual access. They do not isolate visual context management as the sole cause of failure: retrieval, tool availability, visual recognition, and answer completeness also affect outcomes. Process Score evaluates submitted content rather than directly measuring internal state management or search quality (Appendix B).

## Limitations and validity risks
- **Analyst inference—scoring ambiguity:** §3.3 defines Process Score as an unweighted fraction of recovered critical states. Appendix B instead describes task-specific weighted scoring and row-matching F1, evaluated only from `final_answer`; Appendix D refers to intermediate entities and “Trajectory Accuracy.” These descriptions are not fully reconciled.
- **Analyst inference—protocol inconsistency:** §4.1 says settings share a state-and-answer schema, while Appendix B says Direct Answer has no fixed JSON schema.
- **Analyst inference—uncertainty:** Each system receives one fresh-context run per task. No repeated-run uncertainty or confidence intervals are reported (§4.1).
- **Analyst inference—resource confounding:** ReAct has fixed image and tool budgets; a qualitative failure explicitly exhausts its image budget. Caption also adds separate model calls, so the ablation is not compute-matched (§4.1; §4.3; Figure S2).
- **Analyst inference—limited reproducibility detail:** The supplied text does not identify the semantic judge model, validate judge agreement with humans, or fully specify DeerFlow’s configuration.
- **Reporting discrepancy:** §4.3 says GPT-5.5 leads both Hybrid Wide–Deep metrics, but Table 4 gives Gemini 3.5 Flash a Process Score of 28.08%, above GPT-5.5’s 28.36%? No—the table supports GPT-5.5’s higher score; its lead is specifically among the reported systems.
- The authors provide no dedicated limitations section. Their caption-detail-loss explanation is presented as a possible mechanism, rather than demonstrated causally (§4.3).

## Open research questions
- **Can explicit evidence tracking improve exhaustive coverage?** Set-wise Accuracy remains low despite substantial partial credit (Table 4). Compare the same backbone and budget with versus without persistent candidate–evidence records.
- **When should agents use captions versus direct inspection?** Caption solves some tasks that Full misses (Table 6). Test an adaptive routing policy against compute-matched Caption and Full settings.
- **How much failure comes from budgets versus reasoning?** Fixed limits and documented image-budget exhaustion leave this unresolved (§4.1; Figure S2). Sweep image and tool budgets while tracking coverage and accuracy.
- **How reliable is Process Score?** Its operational descriptions differ across sections. Compare the implemented scorer with independent human ratings and explicit critical-state annotations.

## Confidence and missing information
**Confidence: medium.** Aggregate results and benchmark composition are clearly reported, but scoring and protocol inconsistencies weaken interpretation.

Material missing information includes judge identity and human agreement, repeated-run variability, detailed DeerFlow settings, annotation agreement, and reconciliation of the Process Score definitions. The text describes a prepared release package, but its availability was not independently verified.
