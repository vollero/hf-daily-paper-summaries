# Who Remembers What? Multi-Granularity Memory Extraction for Multi-User, Multi-Agent Interaction

> [← Daily summary](../2026-11-13.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2611.10439) · [arXiv](https://arxiv.org/abs/2611.10439)


## One-sentence takeaway
MixUA routes lessons into four user–agent memory scopes, improving task success and preference retention in synthetic mixed-population experiments while showing low—but not universally zero—measured privacy leakage.

## Problem and motivation
Sharing agent experience can spread useful lessons, but indiscriminate pooling can expose personal information or deliver advice to agents for which it is unsuitable. The authors identify a gap between private assistant memory and broadly shared stores: lessons can generalize independently across users and agents, requiring both selective audiences and disclosure boundaries (§1).

## Approach and contributions
- **Four-scope memory:** MixUA assigns each lesson to Pair, User, Agent, or Global memory. Each pair retrieves only its authorized scopes, using task-to-situation embedding similarity and per-scope context budgets (§§3.1–3.4).
- **Separated writing and review:** A splitter produces reusable and protected evidence for isolated writers. Protected entries can enter only their owner’s User or Pair memory; optional review re-scopes and merges entries (§3.3). This restriction depends on the splitter correctly identifying protected content.
- **CrossLearnBench:** The benchmark adds synthetic private facts and document preferences around unchanged tasks from seven existing datasets, jointly measuring task utility, personalization, leakage, and resources (§4; Appendix E). It contributes an evaluation layer, rather than new underlying tasks.
- **Empirical scope analysis:** Single-scope comparisons, scope removal, frozen-store masking, and targeted probes examine which audiences support transfer and personalization (§5.3).

## Evidence and main results

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Scoped sharing improves scheduled-task utility | In rounds 2–3, MixUA with LLM writer and review gains **16.3 percentage points** over no memory, versus **11.5 pp** for Global-only; scheduled conditions use three runs. | §5.2; Table 3; Appendix A.1 |
| Transfer crosses both identities | On scheduled tasks previously attempted only by pairs sharing neither user nor agent, reviewed LLM MixUA gains **13.9 pp** over no memory. | Appendix A.1, “Reading the held-out arms” |
| Gains extend to first-seen tasks | Under random assignment, on **526** first-attempt tasks pooled across two seeds, reviewed MixUA gains **10.1 pp** over no memory, versus **5.5 pp** for Global-only; reported MixUA comparison has **p < 10⁻⁷**. | §5.2; Table 11 |
| Personalization persists with learning disabled | On 20 held-out tasks, reviewed LLM MixUA retains **91%, 91%, and 88%** of document checks across three runs; Global-only retains **11%, 10%, and 10%**. | Table 7 |
| Planted-fact leakage is rare, but preferences still leak | Three of four scheduled MixUA variants have no forbidden-scope planted-fact matches in approximately **18,000 probes each**; review removes the agentic writer’s **four violations**. Scheduled preference leakage remains **0.9–4.8%** across variants. | §5.2 |
| Global and User scopes carry much of the main-benchmark benefit | Removing Global reduces utility gain from **15.3 to 9.0 pp**; removing User reduces preference retention from **90% to 81%**. Full MixUA uses three runs; removal conditions use two. | Table 14 |
| Smaller delivered context can still outperform Global-only | At a **10k-character budget per scope**, reviewed MixUA delivers **22.8k characters/task** and gains **13.1 pp**, versus Global-only’s **39.7k** and **11.5 pp**. | Table 3; §5.3 |

The evidence supports useful experience transfer and a separation between task knowledge and user conventions within these experiments. It does not establish a general privacy guarantee or deployment readiness. Planted-fact leakage and preference leakage are different measures; Global-only’s random-assignment preference leakage is explicitly noncomparable because it receives no protected stream (Table 11).

## Limitations and validity risks
- **Author-stated audience limits:** The four scopes cannot represent teams, organizational hierarchies, or arbitrary subsets of agents and users (Limitations).
- **Author-stated scale limits:** Synthetic populations and bounded task sequences do not establish performance for open populations or indefinitely growing stores. Whole-store review and writing cost may become bottlenecks (Limitations).
- **Author-stated deployment gaps:** Consent, inspection/deletion mechanisms, and malicious memory contributions are not evaluated (Ethical Considerations).
- **Analyst inference—privacy coverage:** Exact substring checks plus an LLM judge on a seeded sample may miss some semantic disclosures. Low planted-fact leakage therefore supports only the tested probes, not comprehensive confidentiality (Appendix D).
- **Analyst inference—comparison scope:** Baselines are scope-pinned versions sharing MixUA components, used as proxies for prior designs; they are not direct implementations of all named prior systems (§5.1; Appendix C).
- **Analyst inference—uncertainty and cost:** Scheduled runs share one initial round and measure later model nondeterminism; scaling uses one seed per population size. Result-table costs include only the writer on the memory side, excluding other substantial memory-processing costs (Appendix D).

## Open research questions
- **Can group audiences improve sharing without widening disclosure?** Intermediate audiences are unsupported. Compare declared team/model-family scopes against four-scope routing using group-specific secrets and lessons (Limitations).
- **How does memory behave over long horizons?** Evaluation stops after short round sequences, while review reads the whole store. Test incremental review and retrieval under a growing store with matched total resource budgets (Limitations; Appendix D).
- **How robust is the splitter to adversarial or indirect disclosures?** Synthetic ambient facts do not test malicious contributors. Introduce misleading lessons and paraphrased sensitive content, then audit downstream memory and responses (Ethical Considerations; Appendix D).
- **When do Agent and Pair scopes materially help ordinary workloads?** Their removal changes relatively little on the main benchmark, while targeted probes show stronger benefits. Vary naturally occurring agent conflicts and pair-specific preferences under matched context budgets (§5.3; Appendix A.3).

## Confidence and missing information
**Confidence: medium.** The supplied text supports the method and principal findings, but many tables and figures appear only as captions, leaving full results, scaling outcomes, exact model identifiers, and some reconstruction details unavailable. Executable code and asset-release status are not established; privacy guarantees beyond the tested probes remain unsupported.
