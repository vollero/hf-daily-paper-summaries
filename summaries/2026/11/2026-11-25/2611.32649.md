# ICLWorld: Benchmarking In-Context Learning of Agents from Digital to Physical Worlds

> [← Daily summary](../2026-11-25.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2611.32649) · [arXiv](https://arxiv.org/abs/2611.32649)


## One-sentence takeaway

ICLWorld finds that agents can recognize rules from context yet struggle to execute them, with GPT-6 Astra answering 98.0% of robot rule questions correctly but completing only 19.6% of the corresponding simulated tasks in the video-rule ablation (Fig. 5).

## Problem and motivation

Agents need to apply user-specific rules at inference time, including rules shown through demonstrations. The authors argue that offline benchmarks using text or static images miss interactive execution, that public materials and familiar goals can let agents succeed from prior knowledge, and that single-rule tasks obscure whether behavior changes with the rule. They also identify a gap in evaluating computer and robot use with the same agents and harness (§1).

## Approach and contributions

- **ICLWorld benchmark.** The authors built 160 tasks, 30 paired environments, and 630 demonstration videos. Each task has three rules that require different behavior from the same starting situation, with matching text and video contexts and a programmatic final-state verifier (§§3.1–3.2, Appendix D).
- **UIverse harness.** A shared browser interface exposes screens, actions, and demonstration frames for web, desktop, and simulated robot tasks. Each model retains its agent CLI (§3.3, Appendix B).
- **Diagnostic evaluation.** The protocol tests replay, new instances, and counterpart environments, with a goal-only control and a separate pre-action rule quiz. The authors apply it to six agents in the main experiment (§§3.4, 4.1).

The goal-only and rule-version comparisons support context-dependent behavior on the tested tasks. The quiz-to-execution gap supports the authors’ interpretation that execution is a major bottleneck, especially in simulation. The quiz measures recognition of a rule, so it cannot establish that the agent formed a usable plan or isolate the cause of each failed action. Small aggregate modality gaps leave open meaningful text–video differences on individual tasks.

## Limitations and validity risks

- **Author-stated.** Hand-building limits coverage to 160 tasks. Ablations use three models, robot execution takes place in simulation, and no task combines computer and robot use (§6).
- **Analyst inference.** UIverse standardizes tool access, while the two domains still differ in task mix, difficulty criteria, observations, and action precision. The observed gap therefore gives a benchmark-level comparison, with the effect of physical execution itself still unresolved (§§3.1–3.4).
- **Analyst inference.** Replay-to-Resample evidence in computer use comes from easy tasks whose demonstrations cover the whole task. Relocate tests transfer to purpose-built counterparts with matching functionality, so broader workflow and environment transfer remain unmeasured by these comparisons (§3.4, Appendix C).

## Open research questions

1. **Which stages cause robot failures after correct rule recognition?** The quiz and case study show a gap but do not quantify the contributions of grounding, planning, and motor execution. On matched simulated tasks, separately supply correct object locations, an action plan, or higher-level manipulation controls and compare success.
2. **Do robot results carry over to hardware?** Demonstrations include real-world footage, while all execution is simulated. Run matched tasks with the same rules and comparable controls in simulation and on a physical robot, then compare verifier outcomes and failure modes.
3. **Can additional demonstrations improve learning of hidden criteria?** Procedure, labeling, and selection showed a text advantage, but the reported comparison does not test whether more diverse examples close it. Vary the number and diversity of videos and measure success on held-out instances against the same text rules.

## Confidence and missing information

**High** for the benchmark design and headline comparisons explicitly reported in the text. The supplied text omits the body cells of Tables 3–5 and 9, which prevents reconstruction of the full model-by-modality scores and ablation breakdowns. Exact episode budgets, repeated-run variability, and hardware execution results are also unavailable.
