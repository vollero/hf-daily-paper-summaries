# Factorized Context Attention: From Emulated to Native Grid Probing

> [← Daily summary](../2026-11-25.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2611.32423) · [arXiv](https://arxiv.org/abs/2611.32423)


## One-sentence takeaway

Factorized Context Attention reuses a single context encoding to run grid probes inside frozen models, cutting repeated-query latency relative to prompt-based probing while retaining similar select-read accuracy in the reported long-text and video comparisons.

## Problem and motivation

A monolithic read becomes expensive as context grows, can lose accuracy before reaching the model’s context window, and truncates inputs beyond it. Grid probing gives the model shorter local and strided views, but it re-encodes overlapping spans for every question. The authors ask whether a frozen model can use those same views while caching the context once for later questions. (§§1–3)

## Approach and contributions

- **Emulated versus native attention.** The authors frame prompt-based grid probing as an external way to control which context a question sees, then characterize the latency, memory, and model-access trade-offs of moving that pattern inside the model. (§§3.1, 3.4, Table 2)
- **Factorized Context Attention (FCA).** FCA lays out context blocks on a grid and encodes each row causally into a reusable KV cache. For each question, it batches masked reads over rows and columns. The direct read pools probe scores to choose an answer, while the select read re-encodes the blocks ranked highest by the evidence map and answers from them. Column probes are approximate because cached blocks were contextualized along rows. (§§3.1–3.2, Fig. 2)
- **Stair positions and encoding cost.** The position schedule gives row and column neighbors the same positional stride, keeping probe positions compact. The authors characterize local probes as equivalent up to a positional shift, with residual score differences measured in the appendix. In their cost model, the attention component of context encoding scales as \(s^{1.5}\) for fixed block size and is paid once per context. (§§3.3–3.4, Appendices B and H.1, Tables 11 and 22)

The authors interpret the close select-read scores as evidence that FCA preserves grid probing’s accuracy. The paired intervals include zero for the reported text and video comparisons with emulated probing, so the evidence supports similar observed accuracy in those settings. Formal equivalence remains untested. The needle tests establish access to isolated evidence beyond the window under the specified truncation or sampling baselines. Performance on questions that require combining distant evidence remains open. (Appendix C.2, Table 13, Appendix E)

## Limitations and validity risks

- **Author-stated.** FCA requires access to attention layers and stores KV states for the whole context, using host memory when the store exceeds the configured GPU budget. Strided probes reuse row-encoded states and therefore approximate independent column encodings. (§6, Appendix A)
- **Analyst inference.** The video needle test conditions on examples each model answers from the inserted image alone, and the text needles use explicit word–number associations. These choices narrow what the results establish about natural long-context QA. (Appendix E)
- **Analyst inference.** The Qwen3-VL comparisons combine a change in attention with different frame resolutions for FCA’s store and GridProbe’s probes. The resolution ablation shows that this choice affects accuracy and cold latency. (§4.1, Appendix D.6, Table 19)

## Open research questions

- **Can FCA combine evidence across blocks that share neither a row nor a column?** Appendix I relies on the select reread to bring such evidence together, while the needle tests place the answer in one block. Test paired-evidence questions with controlled grid placement and measure both evidence recall and answer accuracy as the select budget changes.
- **Where does whole-context caching become a serving bottleneck?** Timed runs use one A100, while distributing the cache across devices is proposed. Vary context length and query concurrency across GPU-resident, host-backed, and distributed caches, measuring memory and cold and warm latency. (§3.4, Appendix C)
- **When is a separate strided encoding worth its cost?** The text ablation shows a direct-read benefit on Qwen3-4B at twice the encoding cost, with smaller effects on select reads. Compare row-only, full strided, and selectively re-encoded columns across text and video under matched compute budgets. (Table 10, Appendix H.3)

## Confidence and missing information

**High** confidence in the reported method and benchmark-specific comparisons. The supplied text lacks multi-device and concurrent-serving measurements, a controlled test of questions requiring evidence across separate spans, and uncertainty intervals for most reported comparisons. The paper lists a code repository on p. 1. Its contents and reproducibility were outside the supplied evidence.
