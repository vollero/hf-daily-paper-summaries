# PINE: Point, Instance and Normal Estimation in One-Step Diffusion Model

> [← Daily summary](../2026-11-25.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2611.29389) · [arXiv](https://arxiv.org/abs/2611.29389)


## One-sentence takeaway

PINE predicts an affine-invariant 3D point map, surface normals, and a class-agnostic instance map from one RGB image in a single forward pass, leading the reported average point-map comparisons with and without camera intrinsics while trailing SAM on small objects (§§3, 4.2).

## Problem and motivation

A single-image scene parse needs both geometry, which locates and orients surfaces, and instance segmentation, which groups pixels into objects. The authors argue that chaining specialists adds latency and memory costs, while the generalists they discuss still require separate passes or multiple sampling steps. They identify three design problems for a shared diffusion transformer: instance colors are arbitrary, pixel coordinates do not preserve ray positions across crops, and attention can spread across unrelated surfaces or objects (§1).

## Approach and contributions

- **One-pass, three-stream prediction.** A shared pixel-space Diffusion Transformer uses flow matching at separate timesteps for points and normals and a permutation-invariant clustering loss for deterministic instance-map regression. A stream mask lets the geometry streams interact and isolates the instance stream from geometry noise (§3.1, Fig. 2, Algorithm 1).
- **Camera-aware ray encoding.** The model projects patch rays onto a reference camera plane and uses those coordinates in its absolute and rotary positional encodings. When intrinsics are missing, it uses a default camera and a learned missing-intrinsics embedding, then fits focal length from the predicted point map (§3.2, Fig. 3).
- **Grounding attention.** Learned low-rank projections of frozen DINOv3 features add patch-affinity biases to attention within the normal and instance streams (§3.3, Fig. 4).

The results support strong aggregate geometry and lower latency under the reported protocols. Geometry scores use ground-truth alignment, so metric accuracy remains untested. The instance scores measure mask selection from a point derived from each ground-truth object, leaving automatic instance discovery unevaluated. The authors’ training-image comparisons describe the reported task supervision. The effect of training-set size remains unisolated because the compared models use different pretraining and architectures (§§4.1–4.2, Appendix B).

## Limitations and validity risks

- **Author-stated.** Point maps lack metric scale, semantic classes are future work, and PINE trails SAM on medium and small objects. The authors attribute the small-object shortfall to objects spanning few patches (§§4.2, 5).
- **Analyst inference.** The component ablations use PINE-L trained on two synthetic datasets. Their effect sizes may differ for PINE-H or under the full training mixture (§4.3, Table 5).
- **Analyst inference.** Baselines receive different camera information according to their interfaces, including horizontal field of view for some and full intrinsics for others. The reported rankings therefore reflect those evaluation configurations. The single A100 timing setup also leaves deployment latency on other hardware open (Appendix B.2, Fig. 7).

## Open research questions

1. **Can finer instance features close the small-object gap?** The authors propose patch coverage as an explanation, but the supplied experiments do not isolate it. Compare a finer patch grid or multiscale instance head under the same one-point protocol and report mIoU by object size alongside latency.
2. **How robust is calibration when the principal point is off-center?** Focal fitting assumes centered principal points and square pixels (§3.2). Evaluate controlled principal-point shifts and unequal focal lengths, measuring recovered field-of-view error and aligned point-map error.
3. **Can PINE recover metric scale while retaining one-pass inference?** The current point maps lack metric scale and the geometry evaluation aligns away scale (§5, Appendix B.1). Add metric supervision and compare absolute depth and point errors before alignment alongside inference latency.

## Confidence and missing information

**High** for the architecture and the explicitly reported benchmark results.
