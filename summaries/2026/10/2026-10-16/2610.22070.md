# Memory as Weights: Internalizing Long-Term History for Streaming Videos

> [← Daily summary](../2026-10-16.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.22070) · [arXiv](https://arxiv.org/abs/2610.22070)


## One-sentence takeaway
MaLoW encodes streaming video history into recurrently generated LoRA weights, improving memory-focused benchmark performance while keeping current observations in the input context and the base VLM frozen (§§3–4).

## Problem and motivation
Streaming VLMs must recall past events while interpreting current observations under bounded memory and latency. The authors argue that existing approaches compress or retrieve history back into the context window, making historical information compete with current visual evidence; they instead investigate storing history in model parameters (§1).

## Approach and contributions
- **Memory framework:** MaLoW carries history through fixed-size, evolving LoRA weights, while the frozen VLM receives current observations and queries (§3.1).
- **Recurrent adapter generator:** Learned queries compress video and timestamp embeddings. A DeltaNet state models temporal dynamics, a gated accumulation branch preserves global semantics, and linear heads decode their outputs into LoRA factors (§3.2). Training uses next-token prediction and adapter-magnitude regularization (§3.3).
- **Training asset:** MaLoW-Instruct contains 381K instruction samples over 56K videos, assembled through question generation, causal answer generation, and verification (§3.4).
- **Mathematical interpretation:** The appendix establishes conditional realizations or approximations of history-induced feature changes through low-rank updates; it explicitly does not establish equivalence to full-context attention (Appendix A).

These results support useful history retention across several backbones and benchmarks, rather than universal superiority. Real-time results sometimes trail competing models (§4.1). Most QA evaluations use parallel processing of historical prefixes, whereas the VLA evaluation explicitly uses persistent streaming state (Appendices C.1–C.2). Consequently, QA accuracy and streaming latency provide complementary evidence, not a complete deployment evaluation.

## Limitations and validity risks
- **Author-stated:** Memory can retain only coarse details; failures also involve fine-grained perception, inaccurate annotations, and tasks requiring frame revisiting through tools. Agentic tool use remains future work (Appendix D.2).
- **Author-stated theoretical boundary:** The derivation relies on specified assumptions and approximations; it does not prove that learned MaLoW adapters reproduce full-context attention (Appendix A).
- **Analyst inference—comparison controls:** Baselines differ in backbones, sampling, context windows, and training. Most baseline scores come from their original papers, limiting attribution of gains solely to memory design (Appendix C.1).
- **Analyst inference—robotics attribution:** Additional action-decoder training accompanies MaLoW training, so the reported policy gain does not isolate the memory mechanism (§4.2; Appendix C.2).
- **Reporting ambiguities:** The abstract reports a 9.3% robotics gain, while §4.2 reports 9.4 percentage points. Gating documentation mixes cosine distance and cosine similarity thresholds (Appendix C.1). Question-type percentages in Appendix B.3 are not mutually consistent unless categories overlap, which is unexplained.
- **Coverage:** The supplied source is truncated, and many tables contain captions without numerical bodies. Ablations are described, but their complete results cannot be inspected; they also use a training subset rather than the final dataset (Appendix D.1).

## Open research questions
- **How quickly does detailed recall degrade as history grows?** Coarse recall failures remain despite long-horizon gains (Appendix D.2). Test controlled streams with increasing delays and distractors, scoring exact attributes separately from semantic recall.
- **Which components drive gains under matched training?** Existing comparisons and subset ablations do not fully isolate method, data, and backbone effects. Train competing memory mechanisms on identical data with matched windows and compute budgets.
- **Does memory alone improve robot control?** The action decoder is also updated during the added training stage. Compare equal-duration decoder-only training, visual-history memory, and visual-plus-action-history memory.
- **Does parallel-prefix evaluation match persistent streaming behavior?** QA evaluation uses parallel history processing despite the claimed causal equivalence (Appendix C.1). Compare answers, state outputs, and measured throughput between both execution modes on identical long streams.

## Confidence and missing information
**Confidence: medium.** The supplied text clearly supports the method and principal benchmark findings, but coverage is incomplete.

Material missing information includes complete numerical ablation and long-horizon tables, latency hardware details, uncertainty estimates, full dataset-source documentation, and verified release contents. The gating rule and inconsistent reported statistics require clarification.
