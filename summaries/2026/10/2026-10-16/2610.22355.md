# OmniVerifier-C1: Decomposed Graded Verifier for Rule-Governed Generative World Modeling

> [← Daily summary](../2026-10-16.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.22355) · [arXiv](https://arxiv.org/abs/2610.22355)


## One-sentence takeaway

OmniVerifier-C1 turns decomposed binary visual judgments into graded RL rewards, improving reported image-generation results, while reference-image verification further improves performance on structured tasks with available ground-truth states.

## Problem and motivation

Binary visual verifiers assign the same failure label to partially correct images of different quality, weakening reward discrimination for generative RL. The authors also argue that supervising only final binary verdicts permits shallow reasoning shortcuts. They target richer, more reliable feedback for compositional text-to-image generation and rule-governed visual state prediction (§§1, 3).

## Approach and contributions

- **Decomposed graded verification:** Split prompts or rules into sub-questions, judge each as satisfied or unsatisfied, and average the judgments into a satisfaction score. An idealized analysis establishes better preservation of quality rankings than all-or-nothing rewards (§3.1; Appendix A).
- **Decoupled RL:** Train a verifier on both global scoring and individual binary judgments. Global rewards penalize absolute score error; local rewards indicate answer correctness. Decomposition is first learned through distilled SFT (§3.2).
- **Reference-based world-modeling rewards:** Give the verifier the generated image and ground-truth target image, alongside the initial state and instructions. Here, “pairwise” means comparison with a reference state, rather than preference ranking between generated candidates (§4.2).
- **Empirical evaluation:** Test verifier generalization, downstream generative RL, and six constructed game-task families with held-out harder variants (§5; Appendix B).

These results support the evaluated training recipes and downstream reward choices. They do not independently establish reduced reward hacking or a general emergence of reasoning intelligence. The ranking theorem concerns exact satisfaction counts under lossless decomposition; it does not guarantee that a learned verifier recovers those counts correctly (§3.1; Appendix A).

## Limitations and validity risks

- **Author-stated scope:** World-modeling evaluation uses controlled games with explicit rules and uniquely determined target images. Open-ended environments with multiple valid outcomes remain future work (Appendix C).
- **Author-observed decomposition failures:** Excessive decomposition introduces redundant or unsupported requirements and output-format violations, distorting scores (Appendix B.5).
- **Analyst inference—mechanism isolation:** Reported comparisons do not separately remove local judgment training while retaining global scoring, so the distinct contribution of decoupling versus decomposition remains uncertain (§3.2; Table 1).
- **Analyst inference—reference assumptions:** The pairwise error argument assumes removing target inference leaves judgment error alone; it does not establish that reference comparison preserves the same judgment-error distribution (§4.2).
- **Analyst inference—evaluation strength:** Training curves use a reference-based model evaluator for world tasks. Independent symbolic correctness checks and repeated-run uncertainty are not reported (§5.3; Appendix B.1).
- **Analyst inference—reasoning interpretation:** Updating only the DiT supports learning outside the frozen text encoder, but does not by itself distinguish transferable reasoning from learned transformation patterns (§5.3).

## Open research questions

1. **Can reference-based rewards handle multiple valid solutions?** The demonstrated setting assumes a determined target state. Compare single-reference, multiple-reference, and rule-based rewards on tasks with several valid outputs (Appendix C).
2. **Which training component drives the gains?** Decoupled RL is evaluated as a combined recipe. Run matched-data ablations of local-only, global-only, and joint training with the same decomposition format (§3.2).
3. **How can decomposition remain faithful as complexity grows?** Granularity has a non-monotonic effect and can introduce unsupported criteria. Test adaptive decomposition with redundancy and coverage checks against fixed question-count ranges (Appendix B.5).
4. **Do gains survive independent correctness evaluation?** Reported model-judge results leave evaluator dependence unresolved. Re-evaluate generated puzzle states using symbolic validators and blinded human review (§5.3; Appendix B.1).
