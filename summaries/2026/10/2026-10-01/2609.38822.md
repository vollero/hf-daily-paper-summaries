# SkillSeek: Revisiting Agent Skill Retrieval at Marketplace Scale

> [← Daily summary](../2026-10-01.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2609.38822) · [arXiv](https://arxiv.org/abs/2609.38822)


## One-sentence takeaway
On SkillsBench under OpenHands, off-the-shelf deterministic skill retrieval matches the observed scores of a restricted LLM-mediated baseline at lower reported token spend, but equivalence remains unproven.

## Problem and motivation
Agents must select useful procedural skills from large catalogs without overwhelming their context or paying for repeated LLM retrieval. The authors identify a missing comparison: whether standard retrieval and reranking can match agent-mediated query rewriting and skill refinement at lower cost (§1–2).

## Approach and contributions
- **Retrieval system:** BGE-base retrieves 20 candidates; a cross-encoder reranks them and returns five through MCP. Skills are indexed by name, description, and four structured tags; bodies load on demand (§3).
- **Empirical comparison:** Evaluate deterministic retrieval against BM25 and reimplemented LLM-mediated baselines across two pools and two agent backbones. The contribution is the comparison and cost analysis, rather than a new retrieval architecture (§4).
- **Diagnostics and assets:** Indexing and candidate-depth ablations, reranker scaling, a gold-hit versus gold-miss “helpfulness gap,” and a reported release of code and reproduction scripts (§4; Appendix K).

Retrieval uses no online LLM calls, but an LLM generates the structured index tags offline (Appendices G, L).

## Evidence and main results
“Pass rate” means mean fractional verifier reward across 89 tasks, with missing runs scored zero—not the fraction of fully solved tasks (§4.1).

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| BM25 exceeds the implemented refined baseline in three settings | BM25 versus `liu_refined`: 192/Qwen 0.430 vs. 0.397; 192/MiniMax 0.387 vs. 0.344; 34K/MiniMax 0.346 vs. 0.329. Single rollout per task. | Table 1 |
| A small reranker matches the remaining headline cell | On 34K/Qwen, Qwen3-Reranker-0.6B and `liu_refined` both score 0.442; default BGE reranker scores 0.409; no skills scores 0.352. | Table 1 |
| Default retrieval has lower reported token spend | On 34K/Qwen, default SkillSeek: $27.54 at 0.409; refined baseline: $51.30 at 0.442; no skills: $27.41 at 0.352. | Table 6 |
| Structured tags outperform alternative indexed text | Higher-concurrency 34K/Qwen ablation: tags 0.360; name+description 0.338; name+description plus first 800 body characters 0.328. | Table 2; footnote 11 |
| Larger rerankers yield small, nonmonotonic differences | On 34K/Qwen, Qwen rerankers score 0.442/0.430/0.450 at 0.6B/4B/8B; Voyage rerank-2.5 scores 0.435. | Figure 2; §4.4 |
| Gold retrieval and task success can diverge | Voyage rerank-2.5 has reported top-five recall 72.2% but a gold-hit minus gold-miss reward gap of −0.025 on 34K/Qwen. | §4.4; Figure 2 |

The evidence supports competitive observed scores and lower online token expenditure in this setup. It does not establish statistical equivalence, causal benefit from retrieving gold skills, or generalization across harnesses. The headline cost and accuracy claims combine different SkillSeek variants: Table 6 prices the default BGE reranker, while the 0.442 tie uses Qwen3-Reranker-0.6B.

## Limitations and validity risks
- **Authors:** Main comparisons use one rollout per task. A repeated MiniMax condition had approximately one percentage point standard deviation; headline Qwen equivalence remains untested (Limitations).
- **Authors:** Baseline reimplementation restricts exploration and refined-skill output and omits capabilities, favoring SkillSeek’s accuracy comparison. A faithful baseline could outperform it (Appendix D).
- **Authors:** MiniMax experiences frequent failures; curated-pool selection and one-harness evaluation limit interpretation. First-stage alternatives lack downstream agent comparisons (Limitations; Appendix E).
- **Analyst inference:** Gold-hit and gold-miss groups contain different tasks, so the helpfulness gap is associative; a negative gap does not prove that retrieving gold actively harms the agent (§4.4).
- **Analyst inference:** The proposed recall ceiling is a hypothesis, not a demonstrated upper bound. Table 5 reports R@5 rather than candidate-set recall at the reranker’s top-20 input.
- **Reporting ambiguities:** The stated 4×11 grid is not shown as a complete grid; Table 1 contains six methods, with additional rerankers evaluated only on 34K/Qwen. Section 4.4 also says the strongest reranker only matches 0.442 despite reporting 0.450.
- **Scope and cost:** Lookup/load instructions strongly steer agent behavior. Reported dollar costs exclude local compute and offline indexing; SkillSeek does not audit retrieved skills (Appendices C, J, L).

## Open research questions
- **Does equivalence survive replication?** Single rollouts and baseline restrictions leave this open. Repeat headline Qwen settings with a faithful baseline and a predefined equivalence margin.
- **Is first-stage coverage the bottleneck?** R@5 alone cannot establish this. Compare stronger first stages using top-20 gold coverage and downstream reward with a fixed reranker.
- **Does retrieval causally help?** The helpfulness gap mixes task difficulty with retrieval outcomes. Randomize gold, near-twin, and no-skill exposure within the same tasks.
- **Does the recipe transfer?** Only OpenHands and SkillsBench were evaluated. Repeat comparisons on independent tasks and additional harnesses.

## Confidence and missing information
**Confidence: medium.** The supplied text supports the core observed comparisons, but not strong equivalence or causal explanations.

Material gaps include repeated headline rollouts, a faithful unrestricted baseline, variant-specific cost for the parity-achieving reranker, full local-compute costing, exact package versions, and the full Tool-REX prompt—which the text says is reproduced but does not actually supply.
