# State World Models: Execute the Rules, Generate the Pixels

> [← Daily summary](../2026-10-20.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.26811) · [arXiv](https://arxiv.org/abs/2610.26811)


## One-sentence takeaway

Stateful Harness executes explicit rules before rendering, raising reported counterfactual-pair ending accuracy on WorldState-Bench from 64% with explicit ending prompts to 92% using the same frozen MiniMax-H3 model (Appendix D, Table 4).

## Problem and motivation

Interactive video models can depict actions without reliably enforcing consequences that depend on invisible state, such as whether a player possesses a key. The authors identify a gap between navigable, responsive video and persistent rule-governed interaction: storing state does not ensure that its prescribed consequences appear in generated pixels (§1).

The paper addresses both authoritative state transitions and faithful rendering, with an evaluation designed to isolate changes in hidden state.

## Approach and contributions

- **Stateful runtime:** A coding agent creates a typed world definition with fixed rules. A semantic ledger and editable spatial scene evolve as actions are resolved before generation. A visual observer subsequently proposes state updates, which the runtime accepts only when compatible with those rules (§§3.1–3.2).
- **Compiled rendering interface:** A deterministic VisualScript compiler converts settled events into structured instructions. An image anchor preserves visual continuity, while a coarse 3D “clay” preview can guide layout and camera movement through a frozen backend’s existing reference interfaces (§3.2; Appendix F).
- **WorldState-Bench:** The authors introduce counterfactual twins sharing an image, action, and rule program while differing in hidden state. PairFollow requires both prescribed endings; PairStrict additionally excludes forbidden outcomes throughout both clips (§4; Appendix B).

The claimed contribution is the combination of executable state, compiled rendering inputs, and counterfactual evaluation; the paper does not introduce newly trained video-model weights.

## Evidence and main results

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Explicit endings help, but the harness improves further | On 50 counterfactual pairs, frozen MiniMax-H3 achieves **32% → 64% → 92% PairFollow** under Rule-only, Rule+end, and harness conditions. PairStrict is **0% → 4% → 90%**, respectively. | Appendix D, Table 4 |
| Reported PairFollow increments are statistically supported | For the same three-condition chain, gains are **+32 percentage points**, paired bootstrap 95% CI **[16, 48]**, exact McNemar **p = 0.0004**; then **+28 points**, CI **[12, 44]**, **p = 0.0026**. Sampling unit: counterfactual pair. | Appendix D |
| Unwrapped models struggle with joint compliance | Across eleven backends, best Rule-only PairFollow is **32%**, shared by Wan2.2 and MiniMax-H3; highest Rule+end PairStrict is **26%**, from Wan2.2. | Table 4 |
| Human comparisons favor the harness | Across 25 further case pairs compared against four Rule-only baselines, aggregate harness wins are **98%**, with **2%** split auditor votes. Each comparison receives two blinded ratings. | Appendix C, Table 3 |
| Automated judging has substantial, imperfect human agreement | On **102 clips**, with three blinded ratings each, VLM agreement with human majority is **91.2%** for ending identification and **86.3%** for forbidden-content detection. | Appendix C |
| External gains involve tradeoffs | With frozen MiniMax-H3 on WBench, raw text versus full harness yields full-split overall **74.2 → 77.9**, setting **71.1 → 87.2**, and consistency **83.8 → 77.8**. Navigation trajectory improves **68.9 → 77.7** on the navigation split. | Tables 8–9 |
| Multi-turn operation is demonstrated qualitatively | Three episodes span **15**, **29**, and **11** turns for town exploration, dating, and combat, respectively; no aggregate long-horizon success rate is reported. | §5.3; Figures 15–17 |

These results support improved rendering of externally resolved rule outcomes on the tested cases. They do not establish that the video model itself learns hidden-state reasoning, or that observer feedback improves long-horizon reliability. The second component-chain increment bundles several changes and cannot isolate each component’s causal contribution.

## Limitations and validity risks

- **Author-stated:** Coarse boxes omit articulated pose and fine appearance; instance-recovery errors propagate into previews; clay appearance can leak into outputs; spatial processing is offline (Appendix I).
- **Author-stated scope:** Richer temporal rules, more entities and relations, additional backends, longer episodes, multi-agent interaction, and evolving rules remain future work (Appendix I).
- **Analyst inference—limited component isolation:** The harness bundles settlement, compilation, anchoring, and reference inputs. Its specific visual-feedback contribution is not independently tested (Appendix D.1.1, “Scope”).
- **Analyst inference—evaluation boundary:** Expected outcomes and harness execution share the same case programs. This tests rendered compliance with supplied rules, rather than independent correctness of world-definition generation (§4).
- **Reporting ambiguity:** Table 1 mixes probe-specific values relative to Table 4: MiniMax-H3’s displayed Rule-only PairFollow accompanies Strict metrics matching Rule+end. Table 4 provides the clearer complete comparison.
- **Reference ambiguity:** Table 1 and Table 6 describe the deployed counterfactual configuration using first-frame reference, while general method descriptions include preview video. The contribution of preview video to the headline result is therefore unclear.
- **Reproducibility:** Artifact release is promised upon publication; linked repositories alone do not establish that all required materials are available. Frozen weights do not guarantee deterministic episode replay (Appendix H).

## Open research questions

1. **Does visual feedback improve persistent state accuracy?** Its benefit is not isolated. Compare full feedback against retaining provisional state across matched multi-turn episodes, measuring state accuracy and rendered compliance.
2. **Which components drive the remaining gain beyond ending prompts?** Several change together. Run a factorial ablation of settlement, compilation, anchoring, and preview conditioning on identical cases and seeds.
3. **How well does the method transfer across backends and richer worlds?** Quantitative harness results use MiniMax-H3, while broader rules and environments remain future work. Evaluate multiple compatible backends on held-out temporal-rule and multi-entity scenarios.

## Confidence and missing information

**Confidence: medium.** The supplied text supports the central result and evaluation design, but inconsistent tables and reference-channel descriptions weaken precise interpretation.

Material missing information includes repeated-generation variability, isolated observer-feedback results, systematic long-horizon success rates, per-turn latency and cost, verified artifact availability, and clarification of the headline configuration and conflicting metrics.
