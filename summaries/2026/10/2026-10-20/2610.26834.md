# Kronecker Delta Rule for Long Context Linear Attention

> [← Daily summary](../2026-10-20.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.26834) · [arXiv](https://arxiv.org/abs/2610.26834)


## One-sentence takeaway
KronLSTM updates scalar key–value associations to reduce memory interference, with conditional stability guarantees and reported language-modeling and long-context retrieval gains over recurrent baselines (§§2–3).

## Problem and motivation
Linear attention compresses context into fixed-size matrix memory, reducing the context-dependent costs of softmax attention. The authors identify a tension: forgetting controls memory growth but weakens long-term retention, while conventional delta updates can disturb associations whose keys overlap with a new write. KronLSTM aims to preserve more associations while maintaining stable memory dynamics (§1).

## Approach and contributions

- **Kronecker Delta Rule:** Corrects the scalar association \(v^\top S k\) toward a target through an update along \(vk^\top\). Interference depends on both key overlap and value overlap, so orthogonality in either protects an existing scalar association (§2.1, Eqs. 3–5).
- **KronLSTM architecture:** Combines this rule with separate vector forgetting, scalar erase, and scalar write gates; normalized queries, keys, and values; and a gated, normalized readout. It removes mLSTM’s normalizer and stabilizer states (§2.2).
- **Theory:** Establishes least-squares mean convergence, stationary behavior, and expected memory-norm bounds under stated stochastic assumptions. The scalar-association capacity result requires linearly independent Kronecker features (§2.1; Appendix A3.3).
- **Efficient training:** Derives chunkwise computation using key and value Gram matrices and a triangular solve, without explicitly forming Kronecker features (Appendix A8).

The authors frame the novelty as the bilinear, scalar-target memory update and its architecture; vectorization recovers the established Widrow–Hoff delta rule on Kronecker-product inputs (Appendix A2).

## Evidence and main results

All empirical findings below are author-reported; numerical table bodies and plotted values are absent from the supplied text.

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Conditional memory stability | For i.i.d. triples, fixed step size, positive-definite feature second moment, and the specified step-size range, the mean converges to the least-squares memory; expected squared memory norms have context-independent bounds in the non-expansive regime. | §2.1, Theorems 1–2 |
| Best reported language-task average | Pure linear KronLSTM improves Avg-6 accuracy over KDA by **1.6 percentage points** for **1.5B-parameter models trained on 100B tokens**; authors also report the lowest LAMBADA perplexity in both pure and hybrid groups. | §3.1; Table 1 description |
| Strong recall and extrapolation rankings | Best average accuracy on the real-world recall suite at **2k context** in both model groups; hybrid KronLSTM reportedly leads every RULER task at **16k**, after **8k-context pretraining**. | §3.2; Tables 2–3 descriptions |
| Context extension retains an advantage | Linear KronLSTM and GDN-2 branch after **75B tokens**, then train for **25B tokens at 32k context**. Authors report stronger natural-text retrieval for KronLSTM, while both models drop substantially from 16k to 32k evaluation. | §3.3; §4; Figure 4 and Table A4 descriptions |
| Retrieval-sensitive design choices | At **1.5B/100B**, base KronLSTM exceeds the coupled-write variant by **12.6 accuracy points** and the unnormalized-value variant by **19.9 points** on mean RULER accuracy at **4k**; the unnormalized variant leads by **2.2 points at 8k**. | Appendix A6.2; Table A3 description |
| Competitive training throughput | Pure linear **1.5B models**, single **H100 80GB**, **16,384 tokens/step**, shapes from **2K×8 to 16K×1**: KronLSTM reaches **36.8–44.5K tokens/s**, **11–18% above GDN-2**; GDN remains fastest. | §3.5; Figure 6 description |
| State tracking is task-dependent | With the erase-gate range extended, KronLSTM is reported similar to GDN on parity and permutation tracking; Mamba-3 wins on modulo arithmetic. Training lengths reach **128**, evaluation lengths **1024**. | §3.4; Figure 5 description |

These results support competitive performance within the tested recurrent-model comparisons. They do not establish superiority over full-softmax Transformers or at larger scales. The interference formula supplies a mechanism consistent with retrieval gains, but benchmark rankings alone do not isolate its causal contribution.

## Limitations and validity risks

- **Truncated evidence:** The source omits a substantial middle portion, table bodies, and plotted values. Complete coverage and independent checking of rankings, uncertainty, and proofs are therefore impossible.
- **Author-stated trade-off:** Longer retention comes with slower adaptation toward the least-squares memory at fixed step size (Appendix A5.5).
- **Author-observed failures:** KronLSTM underperforms on artificial repeated-noise S1 settings, attributed by the authors to residual accumulation for recurring keys; both extended models lose substantial retrieval accuracy at the longest evaluated context (§§3.2–3.3).
- **Analyst inference—guarantee scope:** The stated stochastic bounds assume i.i.d. inputs and fixed step size. Input-dependent gates, decoupled targets, and dependent language sequences require additional justification; non-expansive homogeneous transitions alone do not establish bounded driven states or stable whole-network training (§§2.1–2.2; Appendix A1).
- **Analyst inference—capacity interpretation:** The capacity result concerns scalar pair scores, not independently recoverable value vectors; multiple values sharing a key can be returned as a sum (§2.1; Appendix A3.3).
- **Evaluation scope:** Large-scale models and full-softmax hybrids remain future work (§4). Shared language-model seeds are specified, but repeated-run language-model uncertainty is unavailable; state-tracking experiments explicitly use multiple seeds (Appendix A7).

## Open research questions

- **Do the bounds extend to learned, dependent updates?** The presented assumptions differ from gated language-model execution. Next experiment: measure memory norms and effective targets across controlled dependent streams and trained layers.
- **What controls the retention–adaptation trade-off?** Appendix A5 identifies slower adaptation, and S1 exposes repeated-key weakness. Next experiment: vary repetition, target changes, and key/value overlap while measuring retention and overwrite speed.
- **Which components drive retrieval gains?** Available ablations show context-dependent effects but do not fully separate update geometry from forgetting. Next experiment: match gates, normalization, and state size while swapping only the memory rule.
- **Do gains persist with scale and full attention?** The authors leave both directions open (§4). Next experiment: compare larger token-matched models and hybrids containing full-softmax layers.
