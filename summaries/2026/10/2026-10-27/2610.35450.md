# OBB-PBD: Extending Parallel Box Decoding to Oriented Bounding Boxes for Referring Expression Grounding in Aerial Imagery

> [← Daily summary](../2026-10-27.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.35450) · [arXiv](https://arxiv.org/abs/2610.35450)


## One-sentence takeaway
OBB-PBD extends parallel coordinate decoding to oriented boxes, with matched AVVG controls showing that learning oriented geometry improves rotated IoU beyond block expansion alone, while diagnostics expose and correct a silent loss of image/prompt conditioning (§§3.3, 4.2).

## Problem and motivation
Referring expression grounding must identify a described object among small, similar objects in aerial images and localize its rotated extent. Horizontal boxes poorly represent tilted vehicles, but LocateAnything’s existing Parallel Box Decoding (PBD) interface supports only horizontal geometry. The authors investigate whether that interface can accommodate orientation while preserving correct conditioning and useful accuracy–latency trade-offs (§§1, 2.5).

The gap is specifically an oriented extension of PBD—not the first oriented grounding model or joint box predictor (§§2.2–2.5).

## Approach and contributions
- **Oriented coordinate block:** Replace four corner-coordinate slots with six jointly predicted slots: center, width, height, and double-angle sine/cosine orientation. Boxes are canonicalized to width ≥ height and represented using the existing quantized coordinate vocabulary (§§3.1–3.2).
- **Validated implementation:** Correct a causal-prefix defect that prevented training coordinate slots from attending to image and prompt tokens despite decreasing loss. Visibility, leakage, and image/prompt-shuffle checks validate the decoding path (§§3.3, 3.6; Appendix A).
- **Controlled empirical characterization:** Fine-tune LocateAnything-3B using language/vision LoRA adapters and a trained multimodal projector, with cross-entropy plus spatial, circular-consistency, and directional losses. Compare oriented targets with horizontal-envelope controls to distinguish orientation learning from block expansion (§§3.4, 4.2).

| Predictions depend on both supplied modalities | Complete-test rotIoU: matched **0.303 ± 0.012**, image-shuffled **0.006 ± 0.001**, prompt-shuffled **0.044 ± 0.002**, across three trained seeds. | Table 4; §4.3 |
| Conditioning defect was observable despite falling loss | On one training batch, the first coordinate slot could attend to **7/894** keys before correction, with no image/prompt visibility, versus **894/894** afterward. | §3.3; Table 5 |
| Parallel decoding reduces measured latency | On one RTX 6000 Ada, batch size one, 60 test samples: six-slot parallel decoding **329.82 ms**, versus cached autoregressive decoding **568.65 ms**, a reported **1.72×** speedup. Four-slot parallel decoding takes **306.87 ms**. | §4.4 |

These results support a useful oriented PBD extension within AVVG and demonstrate input dependence under the reported controls. They do not establish that orientation explains the entire zero-shot improvement: most gain occurs in a step combining domain adaptation with a decoding-path change. The matched orientation comparison also includes the tighter box extent enabled by orientation (§4.2).

## Limitations and validity risks
- **Author-stated scope:** Evaluation covers only AVVG/UAV imagery; cross-dataset, sensor, scale, and annotation-format generalization remains untested (§5.2).
- **Comparison limits:** No matched comparison with dedicated OBB regression architectures such as SATGround. The zero-shot comparison changes both training status and inference path (§§4.1, 5.2).
- **Control asymmetry:** Four-slot HBB-PBD trains on fewer records because of corner-frame exclusions, weakening clean attribution of the format-switch result (§4.2).
- **Remaining errors:** Dense scenes produce neighboring-object selection failures; some expressions use subjective attributes (§4.4; Figure 2).
- **Loss validity:** The directional-loss gate uses image-normalized side ratios rather than physical aspect ratio. A single corrected-gate run cannot resolve its effect across training randomness; loss-weight ablations remain future work (§§3.4, 6).
- **Analyst inference:** Shuffle degradation establishes modality dependence, but does not establish reliable relational-language understanding. The qualitative examples were deliberately selected rather than randomly sampled (§3.6).

## Open research questions
1. **How much gain comes from adaptation versus decoder changes?** These remain combined (§4.2). Evaluate zero-shot and fine-tuned horizontal models through both compatible decoding paths on identical records.
2. **Which auxiliary losses and gate definitions help consistently?** Equal-budget loss ablations are absent, and the physical-ratio gate has only one run (§§3.4, 6). Repeat component-removal, weight, and gate comparisons across matched seeds.
3. **How does coordinate-token PBD compare with joint regression?** No matched architectural comparison is reported (§5.2). Train a regression-head alternative using the same backbone, data, budget, and accuracy/latency protocol.
4. **Does the extension transfer beyond AVVG vehicles?** Generalization is untested (§5.2). Evaluate additional sensors, object categories, and scales while retaining visibility and modality-shuffle diagnostics.
