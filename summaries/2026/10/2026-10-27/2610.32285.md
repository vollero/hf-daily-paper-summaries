# Trial by Trace: Benchmarking AI Agent Harnesses for Reliability and Failure Attribution

> [← Daily summary](../2026-10-27.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.32285) · [arXiv](https://arxiv.org/abs/2610.32285)


## One-sentence takeaway
TraceTrial-Bench separates task completion from operational harness reliability, finding that 31.1% of evaluated runs complete the task despite failing at least one harness criterion, while treating automated failure links as candidates rather than causal proof (§1).

## Problem and motivation
Task success measures the combined behavior of a model and its harness. It can conceal failures in context delivery, tool results, permissions, or lifecycle management; conversely, a model can fail despite faithful harness execution. The authors identify a gap in benchmarks that directly test harness obligations using evidence beyond final outputs (§§1–2).

## Approach and contributions
- **Mechanism-oriented benchmark:** TraceTrial-Bench contains 95 tasks covering seven harness components and 40 mechanism-level properties. Tasks pair harness obligations with agent deliverables and executable or state-based truth anchors (§3.2; Figure 4).
- **Separate evaluation layers:** Trajectory Tracing normalizes native records into a provenance-preserving Trace IR; Multi-source Evidence Acquisition assembles criterion-specific evidence from traces, artifacts, and environment state. Agent and Harness criteria receive separate verdicts (§§3.3–3.4).
- **Conservative failure attribution:** Predeclared mechanism chains identify candidate links between failed criteria. Validated propagation additionally requires manual evidence reconciliation, intermediate distortion, event ordering, and consideration of alternatives (§3.5).
- **Comparison assets:** The authors report tasks, configurations, traces, and verdicts for four harnesses and nine model groups across 3,420 selected executions (§§1, 4).

The seven-component taxonomy builds on prior work; the paper’s contribution is its benchmark and evaluation implementation (§§1, 3.2.1).

## Evidence and main results
| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Task success and complete criterion satisfaction differ sharply | Across 3,420 selected runs: 1,351 (39.5%) pass every Agent criterion; 286 (8.4%) pass every criterion in both layers. | §5.1 |
| Task success can coexist with harness shortfalls | 31.1% of runs complete the task while failing at least one Harness criterion; these are operational zeros, not necessarily confirmed defects. | §1; definitions in §§3.6, 4.3 |
| Harness rankings depend on the metric | On 855 matched model–task cells per harness, Claude Code leads Agent success at 44.0%; OpenClaw leads Harness macro at 72.0% and jointly clean rate at 11.7%. | Table 6 |
| Operational Harness satisfaction varies across systems | Harness macro: Claude Code 71.2%, Codex 59.8%, DeepSeek Harness 68.8%, OpenClaw 72.0%; each uses the same task/model population. | Table 6 |
| Continuous scores overstate all-criteria success if read as success rates | Across all runs, Agent macro is 72.9%, Harness macro 67.9%, and their equal-weight combined mean 70.4, versus 8.4% jointly clean. | §5.1; Table 6 |

These results establish descriptive differences in archived criterion satisfaction and task outcomes. They do not establish confirmed defect rates, causal harness effects, or validated failure propagation. Moreover, the two layers are not statistically independent: a semantic Harness criterion marked “not exercised” passes only when all Agent criteria pass (Table 4).

## Limitations and validity risks
- **Author-stated:** Each cell contains one selected execution, including replacements from recovery; within-cell repeatability is not estimated (§4.1).
- **Author-stated:** Scheduling, task revisions, and recovery conditions vary, limiting causal interpretation and controlled throughput comparisons (§4.2).
- **Author-stated:** Judge identity is fixed, but scoring budgets vary. Corpus-level Judge agreement, selector recall, and candidate-link precision are not estimated (§§3.6, 4.2).
- **Scoring qualification:** Empty required evidence receives zero; unexercised mechanisms use outcome-conditioned scoring. Consequently, Harness scores combine criterion satisfaction, evidence availability, and applicability rules rather than measuring confirmed defects alone (§3.4).
- **Analyst inference:** Coverage supports uneven conclusions across components: Verification has only one task, compared with 27 for Execution (Figure 4).
- **Evidence boundary:** Automated candidate activation does not validate propagation; the supplied results provide no corpus-level validated-link count (§§3.5–3.6).

## Open research questions
- **Are rankings repeatable?** One selected execution per cell leaves variability unresolved. Repeat matched cells under frozen configurations and report rank stability (§4.1).
- **How much do scoring conventions affect rankings?** Outcome-conditioned applicability and empty-evidence zeros influence Harness scores. Recompute results with separately reported applicability and evidence-sufficiency categories (Table 4).
- **How reliable are automated judgments and links?** Agreement and candidate-link precision are unmeasured. Independently audit a stratified sample of verdicts and activated links against full archives (§3.6).
- **Which native mechanisms explain outcome differences?** Aggregate comparisons do not isolate causal effects. Compare controlled mechanism changes within a harness while holding model, task revision, and budget fixed (§4.2).
