# ParetoRSI-Gym: Can AI Agents Improve Language Models Across Multiple Domains?

> [← Daily summary](../2026-10-27.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.34386) · [arXiv](https://arxiv.org/abs/2610.34386)


## One-sentence takeaway
ParetoRSI-Gym finds that agents can curate data that improves average held-out language-model accuracy, but preserving gains across domains and successive training rounds remains unreliable.

## Problem and motivation
The authors argue that existing agent-driven post-training evaluations emphasize single benchmarks, whereas practical training must balance several capabilities without sacrificing earlier gains. They introduce an evaluation setting for repeated data curation across mathematics, code, medicine, finance, and science, separating feedback benchmarks from held-out evaluation (§§1–2).

## Approach and contributions
- **Multi-domain curation benchmark:** Agents search the Hugging Face Hub, acquire data, maintain a persistent pool, select parent checkpoints, and revise their strategy using per-domain proxy scores and answer traces (§§2.1–2.3).
- **Generalization-aware protocol:** Separate held-out benchmarks and stated evaluation-overlap screening assess whether proxy improvements transfer. Agents receive capability vectors and non-dominated checkpoints; the reported “proxy-best” checkpoint nevertheless maximizes mean proxy accuracy (§§2.2–2.4; Appendix A).
- **Empirical characterization:** The study compares agent systems, target models, harnesses with a fixed backbone, dataset-selection behavior, and human-supervised commits (§§3–4; Appendix F).

The training framework is fixed to LoRA supervised fine-tuning with AdamW, but agents choose selected hyperparameters within unspecified ranges. Each round uses one epoch, capped at 15 million training tokens and 40,000 entries; runs last five rounds (§3.3).

These results support average held-out improvements and substantial cross-domain trade-offs. They do not establish sustained, universal Pareto improvement. Appendix D.3 describes one checkpoint that matches or exceeds its starting model in every domain, but later rounds lose that property. The per-domain oracle is not a single deployable model.

## Limitations and validity risks
- **Author-stated scope:** Only three agent systems, three target models, five domains, and English text are evaluated; harness and backbone versions are moving targets (Limitations).
- **Unequal replication:** Claude Code and Codex use three training seeds; CheetahClaw and the fixed-backbone harness comparison use one run per setting. Seed standard deviations are supplied only for Qwen3-4B-Base (Appendix G).
- **Analyst inference—causal attribution:** Main comparisons change both harness and backbone. The fixed-backbone experiment helps isolate harness effects but covers one target model with no replication (§4.2).
- **Analyst inference—generalization boundaries:** Four held-out suites are partitions of the same named benchmark; only code uses a separate benchmark. Split construction and overlap-screening details are unavailable, limiting assessment of distribution shift and contamination protection (§2.4; Table 2).
- **Protocol ambiguity:** §2.2 and Appendix A restrict cross-round state, while §3.2 says full interaction history persists. The abstract’s “everything but the data” framing also requires qualification because agents select hyperparameters and parent checkpoints.
- **Analyst inference—mechanisms remain uncertain:** Dataset overlap suggests persistent preferences but does not itself prove failure to adapt. Likewise, the answer-length case study does not isolate length from other dataset changes (§4.3; Appendix D.1).

## Open research questions
1. **Can agents retain Pareto improvements?** Later regressions remain common. Compare current checkpoint selection with explicit no-regression acceptance rules under matched budgets.
2. **How much improvement is knowledge versus answer formatting?** The largest medical gain is partly format-driven. Compare ordinary SFT against format-only training using format-tolerant scoring.
3. **Do harness effects replicate?** The controlled comparison uses single runs. Repeat it across target models and seeds with matched backbone and resource limits.
4. **Does inspecting individual entries improve curation?** Appendix C reports no entry reading in 49 of 50 logged rounds. Compare enforced entry inspection with current dataset-level selection under matched budgets.

## Confidence and missing information
**Confidence: medium.** The supplied text supports the benchmark design and descriptive results, but interpretation is limited by unavailable split sizes and construction, contamination-rejection rules, hyperparameter ranges, decoding details, complete prompts, resource costs, human-review procedures, and uncertainty estimates across most settings. Several referenced figures and prompt/transcript boxes lack their underlying content in the supplied text.
