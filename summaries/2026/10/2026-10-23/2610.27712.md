# RLSplat: Resource-Linear Budget Control for Feed-forward 3D Gaussian Splatting

> [← Daily summary](../2026-10-23.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.27712) · [arXiv](https://arxiv.org/abs/2610.27712)


## One-sentence takeaway
RLSplat learns where to allocate an exact Gaussian budget and decodes only those Gaussians, reporting better novel-view synthesis quality and lower generation costs than budget-controllable baselines, while retaining a fixed image-encoding overhead (§§3–4; Appendix A).

## Problem and motivation
Budget-controllable feed-forward 3D Gaussian Splatting methods adjust representation size but still generate dense candidate sets before pruning or selection. Consequently, smaller outputs do not substantially reduce generation latency or peak memory. The authors target this gap by making Gaussian generation itself depend on the requested budget, supporting reconstruction under resource constraints (§1).

## Approach and contributions
- **Learned budget allocation:** A geometry backbone converts uncalibrated images into spatial anchor tokens and predicts cameras. A budget-conditioned policy distributes exactly \(B\) Gaussians across anchors. GSPO trains discrete allocations using negative novel-view reconstruction loss as reward; deterministic rounding produces exact counts at inference (§§3.1–3.2; Appendix B).
- **Budget-dependent decoding:** Anchors spawn only their allocated tokens. Local attention refines each token using Gaussian neighbors found through an anchor-first hierarchical search. Attention costs \(\mathcal{O}(BK_{\mathrm{gs}})\), avoiding global quadratic attention. Locality and projection losses support spatially coherent decoding (§§3.3–3.4).
- **Integrated quality–resource control:** The contribution combines allocation and decoding so that reducing the output budget also reduces variable generation costs. Experiments compare quality, latency, and memory against dense-candidate methods (§4). GSPO itself is adopted from prior work (§2).

## Evidence and main results

All findings below are author-reported. Unless otherwise specified, quantitative evaluation uses RE10K-trained models on 249 ACID scenes at 256×256. Resource measurements use one RTX A6000, batch size one, excluding loading, pose alignment, and rendering (§4).

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Better quality at matched budgets | Authors report best PSNR, SSIM, and LPIPS across tested budgets and view counts. With eight context views, PSNR gains over F⁴Splat are 0.74, 0.99, and 1.22 dB at respectively 4K, 2K, and 1K Gaussians **per view**. | §4.1; Table 1 discussion |
| Low-budget resource advantage | At **2K total Gaussians**, authors report 0.9 dB higher PSNR, 4.1× faster generation, and 9.6× lower peak memory than F⁴Splat. The accompanying text does not identify the view count. | §1; Fig. 1 |
| Compact output versus a fixed-budget baseline | With 24 context views on ACID, RLSplat achieves 25.58 dB PSNR using 24K Gaussians; SPFSplat achieves 25.00 dB using 1536K—64× as many. | §4.1; Table 2 discussion |
| Hierarchical search reduces search cost | At 65,536 Gaussians and 16 anchor/Gaussian neighbors, search takes 8.1 versus 219.6 ms; reported generation latency falls from 595.0 to 388.0 ms relative to exact search. | §4.2; Table 5 discussion |
| Spatial regularization supports neighbor accuracy | Hierarchical search returns the exact neighbor set for 99.0% of Gaussians with Voronoi regularization versus 60.2% without it; the latter uses shortened training. | §4.2; Appendices D, F |
| Refinement and constraints matter | On ACID with eight views and 8,192 total Gaussians, shortened-training ablations lose 0.53 dB without offset loss, 2.51 dB without both locality losses, and 0.96 dB without refinement; removing projection loss causes reconstruction failure. | §4.2; Table 3 discussion; Appendix F |
| Learned allocation beats tested heuristics | Policy allocation outperforms uniform and Sobel-based allocation on all three quality metrics after fine-tuning from the same checkpoint; numerical margins are absent from the retrieved table content. | §4.2; Table 4 discussion; Appendix F |

These results support improved quality–resource trade-offs within the tested protocol. They do not establish universally linear total inference cost: the authors explicitly acknowledge budget-independent encoding overhead. Full table bodies and plotted numerical series are absent from the supplied text, limiting independent assessment of aggregate claims.

## Limitations and validity risks
- **Author-stated:** Fixed image encoding bounds speed-ups at small budgets; evaluation uses one cross-dataset transfer and 256×256 targets. Downstream applications remain unevaluated (Appendix A).
- **Analyst inference:** Generation-only timing cannot establish complete application latency because rendering and other pipeline stages are excluded (§4).
- **Analyst inference:** Architectural ablations use shortened schedules, so their effect sizes may differ under full training (Appendix F).
- **Analyst inference:** Neighborhoods are computed once from initial positions and depend on locality constraints. The reported neighbor-match degradation shows sensitivity to spatial drift (§§3.3, 4.2).
- **Evidence availability:** The supplied text provides no run-to-run uncertainty estimates. Several table and figure cross-references are inconsistent, and numerical table bodies are missing.

## Open research questions
1. **Where does resource scaling saturate?** Fixed encoding remains unavoidable overhead (Appendix A). Sweep budgets while reporting separate encoding, allocation, search, decoding, and rendering costs.
2. **Does the advantage transfer to higher resolutions and other scene distributions?** Evaluation covers one transfer setting at one target resolution. Repeat matched-budget comparisons across additional datasets and resolutions.
3. **Does learned allocation preserve task-relevant information?** Rendering quality supplies the reward, while robot learning and 3D vision-language applications remain future work. Compare equal-budget representations on downstream tasks, including task-aware allocation rewards.
4. **How much do allocation and spatial constraints help under full training?** Current component studies use shortened schedules. Repeat the principal ablations with full schedules and multiple runs.

## Confidence and missing information
**Confidence: medium.** The method and reported trends are clear, but complete numerical tables, plot values, uncertainty estimates, absolute low-budget resource measurements, and the view count for the total-2K comparison are unavailable. Code availability is claimed in the text; its contents and reproducibility were not checked.
