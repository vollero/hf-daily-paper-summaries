# EditHero: A Benchmark for Long-Horizon Part-Level 3D Editing and Vibe Modeling

> [← Daily summary](../2026-10-05.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.02298) · [arXiv](https://arxiv.org/abs/2610.02298)


## One-sentence takeaway
EditHero supplies exact intermediate references for sequential part-level 3D editing and finds that code-writing agents preserve assets better than four tested generative editors, while geometry fidelity and latency remain obstacles (§§3–5.4).

## Problem and motivation
Iterative 3D editing must execute each new instruction while preserving earlier work and untouched parts. The authors identify a gap in single-edit benchmarks: isolated source–target pairs cannot measure degradation when methods repeatedly edit their own outputs (§§1–2).

Whole-object similarity also obscures editing failures because unchanged content dominates the score; an editor that makes no changes can outperform one that attempts an edit but damages the asset (§§4–5.2).

## Approach and contributions
- **Data synthesis engine:** Assemble segmented hosts and library parts using add, remove, replace, and retexture operations. Logged parts, poses, and textures deterministically reconstruct every intermediate target; reviewers repair assemblies and instructions (§3; Appendix §8).
- **Benchmark:** EditHero contains 457 human-reviewed chains, 2,755 edits, and 252 hosts. Chains span 3–30 turns, with median length 6 (§3, Figure 3). The authors claim novelty in combining sequential natural-language part edits, exact intermediate references, and evaluation on methods’ own outputs (§2).
- **Evaluation framework:** Self-rollout feeds each output into the next turn. Part-defined regions separate geometric instruction following (IF) from preservation of the previous output and initial host (CC). Four non-agentic editors are evaluated across the benchmark; six code-writing agents are compared on a shared subset (§§4–5.4).

## Evidence and main results

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Non-agentic editors poorly execute geometric changes | Across 457 chains under self-rollout, mean IF is 0.12–0.32 over completed, defined turns; first-turn IF is already 0.24–0.36. | §5.2, Table 2 |
| Whole-object metrics can reward inaction | No-op beats every tested non-agentic editor on whole-object F-score, LPIPS, and PSNR. Edit-region LPIPS instead favors editors: 0.474–0.521 versus no-op’s 0.569, averaged over fixed views and completed, defined turns. | §§4–5.2, Table 2 |
| Untouched initial content degrades across turns | On the same 135 chains with at least seven turns completed by all four editors, CC⁰ falls from 0.60–0.78 at turn 1 to 0.33–0.67 at turn 7. | §5.2, Figure 4a–b |
| Resetting the input reduces accumulated error | On 147 diagnostic chains with at least five turns, turn-5 target IoU is 0.68 versus 0.52 for Nano3D and 0.46 versus 0.36 for 3DEditFormer, comparing ground-truth input with self-rollout. | §5.2, Figure 4c; Appendix §14 |
| Agents preserve more and usually edit better | On 55 shared chains comprising 416 turns, all six agents achieve CCᵖʳᵉᵛ of 0.95–0.98 versus at most 0.90 for non-agentic editors. All except GLM outperform them on IF; Opus reaches 0.62 versus a non-agentic maximum of 0.36. Means exclude incomplete or undefined scores. | §5.4, Table 3 |
| Agent geometry construction remains difficult | On the comparison subset, agent IF ranges are 0.88–0.99 for removal, 0.10–0.49 for addition, and 0.17–0.52 for replacement. | §5.4 |
| Agents incur substantial latency | Approximate median costs are 1.5–6 minutes and 6–16 model calls per edit, versus 20–50 seconds for non-agentic editors on a local H100. Agent costs are amortized per chain and include model/tool latency. | §5.4; Appendix §16, Table 12 |

These results support a preservation advantage for the tested agent systems and show inherited-state degradation in two generative editors. They do not establish universal agent superiority, text-only conversational performance, or a hardware-controlled speed comparison. IF measures geometry and is undefined for retexturing (§4).

## Limitations and validity risks
- **Authors’ stated obstacles:** Code-built additions and replacements often miss target shape or size; agent latency remains unsuitable for interactive work (§§5.4, 6).
- **Analyst inference—generalization:** Agent comparisons use a selected subset with clearly visible edits, while all four non-agentic methods share TRELLIS-based representations. Conclusions may not extend to arbitrary assets or other editing architectures (§5.4; Appendix §7).
- **Analyst inference—comparison controls:** Agent runtimes, tools, and budgets differ. VoxHammer receives an extra ground-truth mask, Nano3D uses adapted material routing, and regeneration receives ground-truth alignment. These are system comparisons with unequal assistance, rather than isolated architectural tests (Appendices §§12, 16).
- **Analyst inference—metric coverage:** Completed-turn averaging and method-dependent IF eligibility complicate direct comparisons. The paper reports coverage and matched-cohort checks, but IF cannot assess material instructions (§4; Appendices §§10, 12–15).

## Open research questions
- **Can hybrid editing improve fidelity without sacrificing preservation?** The authors propose combining agentic and conventional methods but do not test it (§6). Next experiment: let an agent isolate the edit region and use a generator only for the new part, measuring IF, CC, and latency.
- **Does the agent advantage persist across the full benchmark?** Agents are evaluated only on the selected comparison subset (§5.4). Next experiment: run them across all chains and report results by operation and chain length.
- **How well does editing work without target images?** Every evaluated turn supplies a target render (§4). Next experiment: compare text-only and image-conditioned runs on identical chains.
- **Can material-edit success be measured independently of geometric preservation?** IF excludes retextures; the paper uses image diagnostics instead (§4; Appendix §15). Next experiment: validate a material-specific change metric against human judgments.

## Confidence and missing information
**Confidence: medium.** The supplied prose supports the central findings and protocol, but numerical table bodies and actual figure panels are absent. Material missing information includes complete per-method scores, execution and IF coverage counts, interval values, full agent prompts and resource rules, and detailed cost breakdowns. The text announces release of the engine and chains; their availability is not established by the supplied content.
