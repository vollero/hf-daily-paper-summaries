# Benchmarking and Enhancing Skill-Level Memory for Partially Observable Robotic Manipulation

> [← Daily summary](../2026-10-02.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2609.38886) · [arXiv](https://arxiv.org/abs/2609.38886)


## One-sentence takeaway
SEEK combines recent visual history, retrieved historical references, and predicted execution progress to achieve 62.9% average success on the authors’ HIDE benchmark versus 51.2% for the strongest evaluated baseline, SAM2Act+ (Table 1).

## Problem and motivation
Robotic manipulation can require information unavailable in the current observation: completed repetitions, earlier object locations, or already inspected search locations. Visually similar states can therefore require different actions.

The authors identify a gap between retaining interaction history and recovering the particular hidden state needed for a decision. HIDE targets this distinction explicitly, rather than treating long trajectories or occlusion alone as evidence of memory dependence (§§1, 3.1).

## Approach and contributions
- **HIDE benchmark:** Fifteen RLBench-based tasks covering repetition counting, historical-state recall, and execution-progress tracking. Scripted demonstrations include randomized configurations, appearance variations, and automatically generated stage annotations (§3; Appendix A.1).
- **SEEK framework:** Windowed Context Memory retains recent interactions; Persistent Anchor Memory retrieves one older entry using visual-descriptor similarity; Stage-Counter Memory advances a learned progress representation at predicted stage boundaries. Memory conditions coarse target selection in a language-conditioned, coarse-to-fine manipulation policy (§4).
- **Controlled memory analysis:** Behavior-cloning experiments compare memory content, history length, and component combinations, alongside standard manipulation, perturbation, and physical-robot evaluations (§5).

The paper’s distinctive contribution is organizing benchmark design and memory analysis around explicit hidden-state requirements; it does not claim to originate robotic memory generally (§2).

## Evidence and main results
| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Strongest evaluated HIDE average | SEEK **62.9%**, SAM2Act+ **51.2%**, SAM2Act **42.7%** success; 15 jointly trained tasks, 100 training demonstrations and 25 held-out episodes per task | Table 1; §5.1 |
| Gains span hidden-state categories | SEEK: counting **61.6%**, recall **59.2%**, progress **68.0%**; strongest category baselines: **46.4%**, **49.6%**, **60.8%**, respectively | Table 1; §5.2 |
| Visual memory outperforms proprioceptive memory | HIDE average success **62.9% vs. 42.5%**, with matched encoding dimensionality and memory architecture | Table 2; §5.3 |
| Longer tested memory improves average success | HIDE average success **46.7%** at length 0 versus **62.9%** at length 6; counting initially declines from **46.4%** to **44.2%** at length 2 | Table 2 |
| Components have different strengths | SCM leads individual variants on counting, PAM on recall, WCM on progress; their combination leads all categories | Figure 4; §5.3 |
| Small gains on standard tasks and perturbations | RLBench: memory **84.7%** versus authors’ memory-free policy **84.1%**; Colosseum perturbation average **61.9% vs. 61.5%**, excluding All-Mixed | Tables 3, 8–9 |
| Larger physical-robot gains | Four-task unweighted average: SEEK **89%**, SAM2Act+ **47%**, π0.5 **13%**; 50 demonstrations and 25 trials per task, separately trained physical policies | Table 4; Appendix B.4 |
| Mixed perturbations remain difficult | Colosseum All-Mixed success **26.3%** with memory versus **25.3%** without memory | Table 9 |

These results support improved task completion under the tested hidden-state conditions and complementary component effects. They do not directly establish accurate latent-state reconstruction, zero-shot simulation-to-real transfer, or statistically reliable superiority for the small standard-benchmark gains.

## Limitations and validity risks
- **Author-stated scope:** HIDE covers controlled, interpretable hidden states; richer real-world settings and broader partial observability remain future work (§6).
- **Analyst inference—limited generalization evidence:** Held-out episodes contain scene and task variations, but the text does not establish held-out task templates or systematic extrapolation to unseen repetition counts (Appendix B.1).
- **Analyst inference—uncertainty:** HIDE and physical results lack reported confidence intervals or training-seed variation. Table 8 includes ± values but does not explain their statistical meaning.
- **Analyst inference—progress-error sensitivity:** SCM uses annotated stages during training and predicted boundaries during inference; no dedicated boundary-error or counter-recovery experiment is reported (§4.4).
- **Comparison qualification:** External benchmark tables mix published results, official-weight evaluations, and reproductions; Table 9 explicitly identifies differing task subsets for legacy RVT results.
- **Efficiency qualification:** Attention reads are bounded, but older entries remain in an episode archive. Archive storage growth and retrieval latency are not measured (§§4.1–4.2).

## Open research questions
- **Does memory extrapolate beyond trained counts and horizons?** Tested history lengths are limited, and count extrapolation is not established. Train on restricted counts and evaluate larger counts with longer evidence-to-decision delays.
- **How robust is SCM to incorrect stage transitions?** Online counter updates depend on predictions without a dedicated error analysis. Inject missed and spurious transitions and measure recovery and task success.
- **Does visual similarity retrieve the decision-relevant evidence?** PAM selects an older entry by similarity, but retrieval correctness is not evaluated directly. Annotate critical historical frames and compare similarity retrieval with oracle anchors.
- **What is the cost of long episodes?** Bounded attention does not establish bounded archive costs. Measure storage, retrieval latency, and success as archive length grows, including capped-archive variants.

## Confidence and missing information
**Confidence: high** in the reported benchmark averages and method description; lower in broad generalization and causal explanations.

Material missing information includes verified artifact availability, HIDE baseline adaptation and training details, HIDE and physical-run uncertainty, direct hidden-state or retrieval-accuracy measurements, stage-boundary error rates, archive runtime costs, and unseen-task/count evaluation.
