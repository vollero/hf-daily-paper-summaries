# Same Output, Different Gold: Measuring How Reference Choice Moves a Multilingual Benchmark Score

> [← Daily summary](../2026-10-13.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.03825) · [arXiv](https://arxiv.org/abs/2610.03825)


## One-sentence takeaway
On one multilingual PII benchmark, exchanging the reference while fixing human annotation outputs reduced pooled Strict F₁ by 4.95 points for one pass and 2.00 for the other, exposing sensitivity partly driven by gold labels copied from the outputs being scored (§§4.2–4.4).

## Problem and motivation
Benchmark scores depend on both predictions and reference construction, but evaluation typically treats the reference as fixed. The authors ask whether defensible alternatives from the same annotation pipeline materially change scores and comparisons. Their identified gap is direct measurement of this uncertainty in multilingual span extraction, where boundary conventions affect exact-match scoring (§1).

## Approach and contributions
- **Reference-substitution procedure:** Hold each annotation pass fixed and score it against delivered gold and independent expert re-annotation on identical prompts. Use Strict exact-boundary-and-type F₁ and Relaxed exact-boundary F₁, with paired prompt-level bootstrap intervals and a reference-by-output interaction test (§3).
- **Pipeline audit:** Measure how often each reference copies each annotation pass, revealing an undocumented default favouring pass A when adjudication did not occur (§§2.2, 4.1).
- **Empirical sensitivity measurement:** Quantify score movement, comparison changes, and a descriptive reference-sensitivity band; check self-scoring and duplicate-handling effects (§§4.2–4.5; Appendix D).

The record contains 24,939 prompts across six languages; reference-choice measurements use the 2,628-prompt audited subset. The scored outputs are human annotation passes, not model predictions (§§2–3).

## Evidence and main results
| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Unadjudicated disagreements overwhelmingly retain A | Delivered gold copies A in 98.7% of cases where A and B disagree and no third pass occurs; this branch accounts for 10.6% of corpus prompts. | §2.2; Table 1 caption/reference |
| Delivered gold systematically favours A | On audited prompts, exact agreement with A is 83.4%, versus 76.1% with B; reviewer agreement is 70.55% versus 70.51%, with language-level variation. | §4.1; Table 3 reference |
| Reference swaps reduce pooled scores | Audited subset, Strict micro-F₁: A falls from 91.62 to 86.67, a 4.95-point difference (95% CI [3.23, 6.27]); B’s difference is 2.00 points ([0.26, 3.37]). | §4.2; Table 2 caption/reference |
| Score movement varies by language | A’s Strict reference-swap difference is 7.55 points in Hindi ([4.90, 10.91]), versus 0.78 in Swedish ([-7.42, 6.58]). | §4.2; Table 4 reference |
| Reference choice changes the pooled comparison | Strict interaction—A-minus-B margin under delivered gold minus that under reviewer gold—is +2.95 F₁ points ([+1.97, +3.87]); Holm-adjusted p < 0.01 across 14 tests. | §4.3; Tables 6–7 references |
| Hindi’s estimated margin changes sign | Strict A-minus-B margin changes from +3.97 points ([+0.65, +7.14]) to −1.30 ([-4.39, +1.55]); interaction is +5.27 ([+2.64, +8.05]). | §4.3 |
| Decontamination is inconclusive | On 135 prompts where delivered gold copies neither output, the pooled interaction is +0.10 points ([-2.81, +2.94]). | §4.4 |
| Proposed band depends strongly on output choice | Upper confidence-bound bands are 6.3 pooled Strict F₁ points and 5.2 Relaxed points; using B’s Strict delta instead yields 3.4 points. These are descriptive, selection-uncorrected quantities. | §4.5 |

The paired design establishes that reference choice changes measured scores and comparisons for these fixed human outputs. It does **not** establish that B is better in Hindi: the reviewer-reference margin includes zero. Nor does it establish model-ranking effects, reference accuracy, or persistence under neutral aggregation. The sensitivity band is not a significance threshold or a general bound (§§4.3–4.5).

## Limitations and validity risks
- **Authors’ scope limits:** One benchmark and one pipeline; both outputs share annotation guidelines and vendor, so transfer to independently developed models remains untested (§5.3).
- **Sampling uncertainty:** Reviewer selection was documented as random but could not be verified. Audited prompts have higher pooled Strict annotator agreement than the corpus, 84.5 versus 79.6; the authors suggest this may understate sensitivity, but its direction is not demonstrated (§5.3).
- **Circular scoring:** Delivered gold often copies the evaluated outputs. The small, selected decontamination subset cannot separate residual reference sensitivity from self-scoring (§4.4).
- **Incomplete attribution:** Missing annotator identifiers prevent separating skill from convention. Both matching rules require exact boundaries, so boundary drift cannot be separated from missed detections (§§3.1, 5.3).
- **Analyst inference—reproducibility:** With confidential corpus text withheld and no executable release identified in the supplied text, independent reproduction of the numerical results is constrained (§2).
- **Reporting ambiguity:** §4.5 describes selecting the “largest pooled” delta while also referring to selection among 24 deltas; the exact selection universe is unclear in the supplied text.

## Open research questions
- **Do model outputs show comparable sensitivity?** Only human passes were scored. Next experiment: evaluate several fixed model outputs against both references on the same audited prompts (§5.3).
- **How much sensitivity remains after neutral aggregation?** Decontamination is too small and selected to answer this. Next experiment: construct an independently adjudicated reference without positional defaults and repeat the paired comparison (§4.4).
- **Does the reviewer subset represent the corpus?** Random selection is unverifiable and agreement differs. Next experiment: independently re-annotate a verifiably random sample and compare sensitivity by language and disagreement stratum (§5.3).
- **Which span errors drive reference effects?** Exact-boundary metrics cannot distinguish boundary drift from missed entities. Next experiment: add overlap-based matching and manual error categorisation (§3.1).

## Confidence and missing information
**Confidence: high** for the reported within-record effects; **low** for transfer to models or other pipelines.

Material missing information includes the actual rows of Tables 1–8, verifiable reviewer sampling, annotator identities, the adjudication selection rule, accessible underlying annotations, an identified code release and seed value, and any evaluation of model predictions.
