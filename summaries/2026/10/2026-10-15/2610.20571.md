# Any Time, Any Space: A World-State-Centric Framework for Agentic Video Generation

> [← Daily summary](../2026-10-15.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.20571) · [arXiv](https://arxiv.org/abs/2610.20571)


## One-sentence takeaway

ATAS combines persistent scene geometry, time-indexed event evidence, and validated memory updates to improve continuity across generated video shots, with reported gains in revisits and event replay at increased compute cost (§§3–4).

## Problem and motivation

Multi-shot video generation must preserve locations, objects, and events across intervening shots and camera changes. The authors argue that recent frames, textual summaries, and retrieved images support local continuity but lack shared spatial coordinates, event-time addressing, and safeguards against incorporating erroneous generations into future context (Introduction).

The target gap is persistent, queryable evidence: returning to an earlier room should recover its layout, while replaying an earlier event should preserve its actions and temporal progression under a new camera.

## Approach and contributions

- **World-state compilation:** ATAS recursively decomposes a screenplay into bounded requests specifying description, scene, spatial anchor, camera, time interval, and optional event identifier. Subsequent requests consume validated state from earlier generations (§3.2; Appendix B).
- **Complementary persistent memories:** Scene memory stores registered static point-cloud evidence, excluding dynamic regions. Event memory retains frame-level RGB-D, masks, and dynamic point clouds indexed by scene, event, source observation, and time (§3.3; Appendix C).
- **Controlled state admission:** Film acceptance, geometric registration, and state admission are separate decisions. A deliverable clip can remain in the film without becoming evidence for later shots; admission also checks provenance, scene scope, and parent-state version (§3.5, Eqs. 9–11).

The contribution is the integrated orchestration and memory interface around short-video generators; the supplied text does not establish a new underlying video generator.

The evidence supports improved continuity in the reported settings and complementary roles for spatial memory, event memory, and compilation. It does not establish exact reconstruction of unseen event views: recapture is judged against source evidence without synchronized target video. Human agreement provides supporting evidence, but statistical significance cannot be assessed from the supplied summaries. The separate runtime and retry-adjusted delivery measures also do not support a general claim of faster generation.

## Limitations and validity risks

- **Author-stated capability limits:** Event memory contains frame-local dynamic evidence rather than an identity-resolved motion model (§3.3). Exact action-state reproduction remains difficult, and background consistency and narrative coherence receive lower human ratings (§4.2).
- **Author-stated evaluation limits:** The event judge cannot establish pixel-level agreement with an unobserved target video. Automatic-to-human agreement remains below human–human agreement (Appendices A and E).
- **Author-stated scope limits:** The memory profile is a short-rollout operating measurement, not a scaling law. The qualitative long-horizon gallery demonstrates generated continuity rather than physical simulation of unobserved intervals (Appendices C and G).
- **Analyst inference—evaluation coverage:** Excluding requests without source-event evidence restricts event results to evidence-supported requests; performance on unavailable or ambiguous historical events is unestablished (Appendix A).
- **Analyst inference—causal attribution:** Cumulative component ablations support incremental benefits but do not fully isolate component interactions (§4.3).
- **Analyst inference—reporting ambiguity:** The Introduction claims the highest aggregate score in every backbone block, while §4.2 explicitly reports a Wan 2.7 VBench exception. The narrower results statement is better supported.
- **Reproducibility gap:** Table bodies, sample counts, uncertainty values, and several implementation choices are unavailable in the supplied extraction, limiting independent assessment.

## Open research questions

1. **Can event replay preserve precise action states?** ATAS trails the reported action-state comparator and lacks an identity-resolved motion model. A next experiment could compare frame-local event memory with tracked dynamic representations using synchronized target views (§§3.3, 4.2).
2. **How does state behave over substantially longer stories?** Memory grows, and quality declines with stale observations; the authors caution against interpreting the measured profile as a scaling law. Test longer rollouts while separately varying scene count, event density, and update frequency (Appendices C–D).
3. **Can admission decisions adapt to changing reconstruction reliability?** Both permissive and strict checks reduce downstream quality. Compare fixed checks with uncertainty-aware admission under controlled registration corruption (Appendix D, Tab. H).
4. **How reliable are recapture scores across judges and camera changes?** Evaluation uses one fixed VLM judge and no synchronized target video. Test multiple judges against expert ratings and synchronized multiview events (Appendices A and E).
