# HABIT-Bench: Evaluating Habit Induction from Longitudinal Weak Evidence in Agent Memory

> [← Daily summary](../2026-10-28.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.24520) · [arXiv](https://arxiv.org/abs/2610.24520)


## One-sentence takeaway
HABIT-Bench finds that tested agent-memory pipelines struggle to infer and correctly apply habits from synthetic longitudinal histories, with the best memory method reaching 33.61% four-domain macro accuracy versus 33.21% for dense retrieval under GLM-5.3-Flash (Table 3).

## Problem and motivation
Personalized agents must infer behavioral defaults from incomplete observations and determine when those defaults apply. Relevant history may contain temporary exceptions, outdated workflows, unresolved choices, or assistant suggestions that the user never accepted.

The authors identify a gap in jointly evaluating habit induction, contextual scope, temporal validity, endorsement, and subsequent action selection. Their target is justified use of remembered behavior rather than recall alone (§1; Table 1).

## Approach and contributions
- **Capability definition:** Habit memory combines recovering behavioral defaults with deciding whether the available evidence supports applying them to a particular request (§§1, 3.1).
- **Controlled benchmark:** HABIT-Bench contains 114 synthetic users, 37,152 sessions, and 3,328 four-choice probes across food, finance, software, and travel. Dialogue datasets supply seeds; controlled habit graphs establish continuity, evidence relationships, and labels (§3.2; Table 2).
- **Evaluation and diagnostics:** Chronological, user-isolated memory pipelines supply context to a shared answerer within each model setting. Eight memory methods are compared with retrieval and compressed-history controls; private-information oracles and evidence-attribution metrics examine remaining difficulties (§§3.3, 4.1–4.3).
- **Human validation:** Independent, gold-blind reviewers assess sampled evidence packets and candidate actions, followed by adjudication and targeted review of revisions (§3.4; Appendix B).

The contribution is primarily an evaluation asset and capability formulation, rather than a new memory architecture.

## Evidence and main results

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Best memory pipelines remain close to retrieval | Four-domain macro exact-choice accuracy: Qwen3-235B-A22B A-MEM **33.06%**, BM25 **32.50%**; GLM-5.3-Flash A-MEM **33.61%**, dense retrieval **33.21%**. Uniform random choice is **25%**. | Table 3; §3.3 |
| Compressed history can outperform memory methods | GLM Full Memory reaches **41.98%** macro accuracy, versus **33.61%** for the best of eight memory methods. Full Memory combines a persistent summary with recent history. | Table 3; Appendix E.3 |
| Memory benefits vary substantially by domain | With Qwen3-235B-A22B, every memory method scores below the Finance No Memory point estimate of **23.54%**; on Food, A-MEM reaches **42.70%**, versus **22.38%** without memory. | Table 3 |
| Relevant evidence alone does not resolve decisions | Qwen3-235B-A22B Oracle Evidence domain accuracies span **39.26–58.25%**; Oracle Habit State spans **98.41–99.26%**, but additionally supplies the private active state and required action. | Table 4; §4.3 |
| Partial retrieval differs from supported answering | Across six source-attributed Qwen3-32B methods, Hit@5 is **37.77–41.44%**, evidence recall **11.17–13.89%**, and correct-answer-plus-evidence-hit accuracy **12.92–16.20%**; metrics use their eligible probe subsets. | Table 13; Appendix E.5 |
| Reviewed evidence generally supports recoverable choices | Pre-adjudication A/B agreement is **99.50%**, **100.00%**, **99.68%**, and **92.84%** for Food, Finance, Software, and Travel, respectively, over **200**, **336**, **309**, and **545** jointly valid choices. | Table 6 |

These results support the authors’ conclusion that evidence access and appropriate habit use remain difficult for the tested pipelines. They do not isolate memory architecture effects, establish statistically significant superiority for the small leading-score differences, or demonstrate performance in interactive deployment. The habit-state oracle exposes the required action, so its near-ceiling score is not an independent measure of habit inference.

## Limitations and validity risks
- **Author-stated scope:** Histories are synthetic, source-grounded constructions rather than longitudinal records of real participants. Domains also differ in evidence mechanisms; Finance and Software emphasize explicit decision reconstruction and policy maintenance, so the benchmark is not exclusively statistical induction from unratified behavior (Appendices A.1–A.5).
- **Author-stated comparison limits:** Methods differ in context construction and effective budgets. Most memory systems use retrieval-only benchmark adapters rather than native end-to-end execution (§4.2; Appendix C).
- **Author-stated diagnostic limits:** Human review measures recovery from selected evidence packets, not retrieval from full histories. Evidence metrics use different eligible subsets and cannot provide a causal error decomposition (§3.4; Appendix E.5).
- **Author-stated scaling limits:** Model-size comparisons change both memory-stage and answer models, with reader-protocol differences for the largest model (§4.4; Appendix E.3).
- **Analyst inference:** Fixed-choice decisions leave transfer to free-form assistance and actual tool execution unresolved. Travel’s explicitly non-sequestered status further limits claims about independent generalization (§2; Appendix A.4).

## Open research questions
1. **Would explicit provenance and validity links improve decisions?** Oracle Evidence still leaves substantial errors (§4.3). A next experiment could compare linked habit–evidence–exception representations with existing pipelines under matched input and compute budgets.
2. **Which requirements cause the Finance and Software failures?** Their probes combine temporal resolution, endorsement, and multiple workflows, preventing attribution from domain scores alone (§4.2). Matched probes could vary one requirement at a time.
3. **Do improvements transfer beyond synthetic multiple choice?** The current evaluation uses constructed histories and non-interactive action selection (§§2–3). A next experiment could use independently collected, consented histories and evaluate both choice selection and executable actions.
