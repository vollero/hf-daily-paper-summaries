# ACCRUE: Continual Off-Policy Reinforcement Learning for Robot Foundation Models

> [← Daily summary](../2026-10-14.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.18596) · [arXiv](https://arxiv.org/abs/2610.18596)


## One-sentence takeaway
ACCRUE carries a lightweight actor–critic across sequential robot assembly tasks and preserves prior behavior through actor distillation, with reported hardware RL interaction-time savings of 31.0%–68.5% versus restarting each task (§5.3).

## Problem and motivation
Robot foundation models need to improve on newly encountered tasks without repeatedly paying the full RL interaction cost or forgetting earlier skills. The authors identify a gap between continual on-policy methods with limited forward transfer and efficient off-policy methods designed for individual tasks (§§1–2).

Continual off-policy learning also creates a tension: small replay memories may preserve behavior but provide insufficient coverage for reliable prior-task value estimates, while updates to the base model can change the inherited learner’s inputs (§1).

## Approach and contributions
- **Actor–critic carryover:** Inherit both lightweight networks between stages to transfer behavioral and value knowledge. At each stage, separately fine-tune the base policy on accumulated demonstrations, then freeze it during RL (§§4.1–4.2).
- **Asymmetric learning and preservation:** Train the critic and RL actor objective only on current-task transitions. Preserve earlier refinements by distilling the actor toward cached preceding-stage outputs on retained episodes, avoiding prior-task actor updates driven by potentially unreliable critic estimates (§4.3).
- **Stable conditioning interface:** Use a frozen external visual encoder and condition both networks on base-policy reference action chunks. Historical references remain fixed in replay; deployment uses the updated base policy (§§4.1–4.3).

The contribution is this continual-learning combination; action chunking, off-policy actor–critic learning, and reference-guided refinement build on existing methods.

## Limitations and validity risks
- **Author-stated scope:** Experiments cover at most five stages of contact-rich assembly. Longer sequences, fixed total memory, less-related tasks, and different embodiments/action spaces remain future work (§6).
- **Memory scaling:** Replay is bounded per task, not globally: retained episode count grows with completed tasks. Base-policy fine-tuning also uses accumulated demonstrations (§§3.2, 4.3).
- **Confounded encoder ablation:** The authors acknowledge that replacing frozen DINOv3 features with updated GR00T features changes encoder identity as well as representation stability; it does not isolate drift (§5.4).
- **Limited hardware comparison:** Hardware experiments compare only against Single-task RL; the authors state that a full baseline sweep is infeasible (§5.3).
- **Analyst inference:** Distillation constrains historical state/reference inputs, so retention under substantially changed base-policy proposals is not guaranteed. The paper tests the updated policy jointly and reports a reduced-demonstration ablation, but does not establish robustness to arbitrary reference shifts (§§4.3, 5.4).
- **Evidence availability:** All seven tables lack numerical bodies in the supplied text. Hardware repetition counts and uncertainty estimates are unspecified.

## Open research questions
- **Can retention survive a fixed total memory budget over longer sequences?** Current memory grows per task. Compare retention policies on longer sequences while holding total stored transitions constant (§6).
- **When does inherited value knowledge cause negative transfer?** Critic carryover helps in the reported assembly settings, but less-related tasks remain untested. Compare inherited and reset critics across task sequences with increasing behavioral differences (§§5.4, 6).
- **How much reference-policy change can cached-target distillation tolerate?** Historical references remain unchanged while deployment references evolve. Vary base-policy update magnitude and compare historical-reference versus refreshed-reference preservation (§4.3).
- **Does freezing features help independently of encoder quality?** The existing ablation changes both factors. Compare frozen and stage-updated versions of the same encoder (§5.4).

## Confidence and missing information
