# Video-Arena: A Scalable Agentic Video Benchmark for Spatiotemporal Capability

> [← Daily summary](../2026-10-14.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.14158) · [arXiv](https://arxiv.org/abs/2610.14158)


## One-sentence takeaway
Video-Arena evaluates event perception, state interpretation, and tracking across nine games, finding substantial tool-assisted gains but persistent state-assessment failures under strict tuple-level scoring (§§3–4).

## Problem and motivation
The authors argue that existing video benchmarks often permit answers from static cues or language priors without requiring coherent tracking of changing world states. Real-world videos complicate verification because underlying states can be partially observable and expensive to annotate. Game records offer recoverable events and state variables, enabling automated evaluation of whether models connect observed events to updates and resulting states (§1).

## Approach and contributions
- **Coupled evaluation framework:** Each reference tuple contains an event with time and entities (T1), its associated state-update label (T2), and the resulting state label (T3). Strict F1 requires all scored fields to match, with a ±3-second timestamp tolerance (§§3.1, 3.4).
- **Automated construction pipeline:** Game-specific adapters generate synchronized videos, events, and reference states using replay parsers or evaluators. Renderers remove direct answer-bearing displays. The fixed golden set contains 180 cases, with 20 per game across nine games (§§3.2–3.3).
- **Comparative evaluation and diagnosis:** Native sampled-frame evaluation is compared with agentic video inspection, supported by tier diagnostics, frame-budget experiments, evaluator-stability checks, human audits, and sandbox controls (§4; Appendices B–C).

This is principally a benchmark and evaluation contribution; it does not introduce a trained video-understanding model.

## Evidence and main results

F1 scores below use the paper’s 0–100 scale; overall scores macro-average environment means.

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Native performance is low | GPT-5.6-Sol leads at **13.2 strict F1**, versus a **90.2 temporal oracle ceiling**, using target 1-FPS sampling capped at 256 frames. | Table 4; Appendix B.5 |
| Agentic systems perform substantially better | Claude-Opus-5.0 with Claude Code leads at **51.0 F1**, compared with its native **7.2**; agentic cases allow 200 turns and two hours. | Tables 4–5 |
| Gains vary strongly by environment | Opus achieves **92.9** on GFootball and **84.5** on CS2, versus **30.0** on DOTA 2 and **14.6** on SC2 under the agentic protocol. | Table 5 |
| Multi-turn analysis helps at fixed sampled evidence | With 256 uniform frames, GPT-5.6-Sol rises from **13.2** in single-request evaluation to **21.3** in the agentic frame-only setting; full-video agentic access scores **34.7**. | Figure 3; §4.2 |
| Perfect event recovery does not ensure correct state assessment | On shared valid diagnostic cases, Opus has **1.00 T1** for Chess, Go, Gomoku, and Doudizhu, while conditional T3 accuracies are **0.68, 0.52, 0.51, and 0.40**, respectively. | Figure 4; §4.3 |
| Reference labels are largely stable on repeat execution | Across the four evaluator-based environments, repeat runs reproduce **98.6% of T2 labels (7,622/7,726)** and **98.7% of T3 labels (7,659/7,758)**. | Appendix B.2; Table 8 |
| Human recoverability depends on the target | Two-person mean strict F1 reaches **98.6** on GFootball, while amateur Go participants score **51.6** despite **100% T1 reconstruction**, under free playback and note-taking. | Appendix B.7; Table 10 |

These results support the authors’ diagnosis that tools help recover events while evaluator-based state assessment remains difficult. They do not isolate model ability from harness effects, establish transfer to real-world videos, or show that additional interaction causally improves accuracy. Tier diagnostics are conditional on correctly localized events and therefore do not measure end-to-end tracking independently.

## Limitations and validity risks
- **Author-stated scope limits:** Nine games cannot cover all game worlds, and real-world states need not admit deterministic representations. Engine values approximate rather than define objective state quality (§5).
- **Reference-target assumptions:** Doudizhu uses uniform count-consistent hidden deals without action-history inference; borderline labels are excluded. Agreement among retained labels must be read alongside coverage (Table 7–8).
- **Analyst inference—comparison confounding:** Agentic rankings measure model–harness pairs. Native and agentic protocols also differ in visual access and interaction, so their headline difference cannot be attributed solely to tools (§4.1; Appendix B.1).
- **Repeatability is unmeasured:** Each system–case cell has one effective run. Bootstrap intervals quantify case-sampling uncertainty rather than model or harness variability (Appendix B.8).
- **Human evidence is limited:** Two participants per environment, uneven expertise, and partially qualitative T1 records support a recoverability audit rather than a formal human ceiling (Appendix B.7).
- **Reporting ambiguities:** Some Appendix B.8 environment means differ from values implied by the main tables; archived-coverage differences may contribute, but the supplied text does not fully reconcile them. Appendix B.7’s blanket statement that models average below 10 also conflicts with the reported agentic mean of 20.9 (§4.2).

## Open research questions
1. **How much do rankings depend on the harness?** Different model families use different harnesses (§4.1). A crossed model-by-harness experiment with matched visual access and budgets could separate these effects.
2. **Can explicit state memory improve reasoning after event recovery?** Perfect T1 still leaves substantial T3 errors (§4.3). Supply oracle event streams and compare explicit state accumulation with direct prediction.
3. **Do the findings transfer beyond controlled game renderings?** The authors identify real-world extension as unresolved (§5). Evaluate paired rendered and natural-video cases with independently audited state labels.
4. **How stable are agentic scores across runs?** Existing intervals exclude trajectory randomness (Appendix B.8). Repeat system–case evaluations and report score, cost, and failure-rate variation.

## Confidence and missing information
**Confidence: medium.** The supplied text provides detailed protocols, results, and validity checks, but aggregate-reporting inconsistencies limit confidence in some summaries.

Material missing information includes verified public artifact availability, raw per-case results needed to reconcile aggregates, repeated-run variance, complete numerical tier results, and controlled harness comparisons.
