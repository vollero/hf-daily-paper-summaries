# Judges Follow the Reference: The Derivation Gap in Verifying Tool-Call Arguments

> [← Daily summary](../2026-10-14.md) · [Relationship graph](relationships.md) · [Hugging Face](https://huggingface.co/papers/2610.18497) · [arXiv](https://arxiv.org/abs/2610.18497)


## One-sentence takeaway
DeRef improves tool-argument verification by supplying references derived without seeing candidates, but controlled experiments show that incorrect references can also reverse judges’ decisions (§§4–5).

## Problem and motivation
Tool-call judges can reject correct argument values when checking them requires recovering earlier evidence, applying a schema default, or deriving a value rather than matching visible text. This matters when judges score agent actions or guard calls before execution.

The authors identify a **derivation gap**: lower acceptance of correct arguments without an explicit reference than of correct arguments appearing in the visible dialogue. They distinguish missing information from failure to use information already available, particularly schema defaults (§§1, 3).

## Approach and contributions
- **Diagnostic framework:** Five ordered, text-matching categories—Visible, History-only, Format, Default, and No-source—separate argument correctness from how directly its value appears in context. The gap measures differences in acceptance among correct arguments (§§3.1–3.3; Appendix B).
- **Controlled tests:** Source relocation, source restoration, and reference substitution test whether judgments track visible values rather than independently recovering the expected argument (§3.4).
- **DeRef:** A separate Qwen3.8-27B model reads the history and schema without candidate values, then writes an expected value and source, or states that the value is undetermined. Candidates for the same argument slot share this reference; the judge reads it without retraining (§4; Appendix F).

The contribution combines derivation-path diagnosis with a separate reference generator that can access history omitted from the judge’s input; reference-guided judging itself is acknowledged prior work (§2).

## Evidence and main results

| Finding | Evidence / setting | Location in paper |
|---|---|---|
| Correct out-of-view arguments receive lower acceptance | Across seven judges, pooled gaps are 22.67–36.13 percentage points on CFB and FinTrace, with thresholds calibrated to accept 80% of correct arguments overall. All are significant. | Table 1; §3.3 |
| Defaults expose a gap without truncation | FCRB correct-default gaps span 14.40–50.51 percentage points across seven judges, although defaults remain visible in schemas. | Table 1; §3.3 |
| Hidden sources favor visible distractors | Across four judges, FCRB-Relocate AUROC falls from 91.89–99.88 with visible sources to 39.80–49.03 with buried sources; DeRef reaches 98.40–99.59. | §3.4; Table 6 |
| DeRef improves overall discrimination | All four main judges improve over Plain across all three benchmarks: argument AUROC gains of 1.44–22.14 points, each significant. Llama and Mistral also improve on every benchmark. | Tables 14, 16 |
| Advantage over the strongest prior comparator is qualified | DeRef exceeds RevisEval in 10 of 12 main settings, significantly in eight; the two losses are nonsignificant. Mean gains across four judges are 2.38, 2.07, and 1.46 AUROC points on FCRB, CFB, and FinTrace. | §5.2; Appendix H |
| Full-history derivation matters | On CFB with Qwen3.8-27B judging, using truncated history for derivation lowers AUROC from 95.09 to 85.46: a 9.63-point loss, 95% CI [7.53, 11.86]. | Table 3 |
| Incorrect references can redirect judgments | On selected CFB/FCRB arguments whose references initially name the correct value, swapping in a wrong value reduces AUROC from 92.16–99.91 to 42.63–77.92 across four judges. | §5.4; Figure 3 |

The evidence supports reference dependence and improved benchmark discrimination. It does not establish safe autonomous execution or elimination of the derivation gap. Full history alone also solves the controlled relocation task, and DeRef generally leaves FinTrace’s No-source gap unchanged (§5.2; Appendix A; Table 17). Statistical significance uses query-level bootstrap intervals (§3.2; Appendix C).

## Limitations and validity risks
- **Author-stated:** Single gold values can penalize alternative valid arguments. Audits could not confirm 3% of sampled CFB negatives and 4% of FinTrace negatives; worst-case deletion preserves significant DeRef gains over Plain. FCRB labels were not independently audited (Limitations; Appendix A).
- **Author-stated:** Main experiments use one deriver family; general-purpose frontier judges remain unevaluated. FinTrace’s No-source gap does not shrink for three of four main judges (Limitations).
- **Analyst inference:** No-source means failure of specified matching rules, so it does not by itself identify a particular reasoning requirement (Appendix B).
- **Analyst inference:** “Full history” is resource-bounded: some FinTrace deriver inputs lose oldest returns. Reference generation also adds latency (Appendices A/F).
- **Author-discussed risk:** Deriver errors or misleading tool returns could induce incorrect acceptance; the swap experiment demonstrates susceptibility, but does not evaluate an adversarial deployment (Ethical Considerations; §5.4).

## Open research questions
- **Can judges detect faulty references?** Swaps redirect judgments (§5.4). Next experiment: introduce controlled reference errors and measure rejection or escalation.
- **Does DeRef generalize across model families?** The main deriver is fixed (Limitations). Next experiment: cross multiple deriver families with existing and frontier judges under matched budgets.
- **Can references preserve multiple valid answers?** Single-gold evaluation leaves this unresolved (Limitations). Next experiment: evaluate set-valued references against human-validated alternative arguments.
- **Why does the No-source gap persist?** FinTrace retains it despite overall AUROC improvements (Table 17). Next experiment: balance correctness base rates and annotate derivation requirements within that category.

## Confidence and missing information
**Confidence: high** in the reported benchmark findings; broader deployment conclusions remain uncertain.

Material missing evidence includes adversarial tool-return evaluation, multiple-valid-answer evaluation, broader deriver/frontier-judge coverage, and end-to-end execution outcomes. Artifact availability is ambiguous: the abstract says code is available, while Artifact Use and Licensing describes release after review.
